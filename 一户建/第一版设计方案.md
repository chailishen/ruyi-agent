# 第一版设计方案

## 方案定位

方案名称：东入中庭一层合院方案

这是基于当前宅基地条件做的第一版概念平面。重点解决三个问题：

- 东侧临 5 米道路，大门开在东偏南方向。
- 北、南、西三侧均有邻居，单靠外墙开窗会影响采光、通风和隐私。
- 单层内需要同时容纳车位、老人房套间、茶室、设备间和日常起居空间。

## 基本判断

- 宅基地：东西 14 米，南北 20 米，约 280 平方米。
- 建议采用：东侧入户 + 中部庭院 + 西侧/北侧卧室围合的单层布局。
- 建筑占地建议：约 165-185 平方米。
- 院落及室外空间：约 95-115 平方米，包含中庭、东南车位、入口前场及少量边角绿化。

面积为第一版估算，后续需要根据当地退界、结构墙体厚度和实际开间再细化。

## 功能分区

### 1. 东南侧：大门、车位、入户

- 大门设在东侧偏南，但门洞南侧边缘距离南侧邻居后墙至少 2 米。
- 半露天车位靠东侧道路布置，建议尺寸约 3.3-3.7 米宽、5.3-5.8 米深。
- 车位可以做轻钢雨棚、木格栅或挑檐，形成半露天停车。
- 车位北侧或西侧接玄关，避免一进门直接看到客餐厅全貌。

### 2. 中部：客餐厅与中庭

- 客厅、餐厅作为公共核心，布置在宅基地中部偏东。
- 中庭建议约 4.0-4.5 米见方，作为主要采光、通风和景观中心。
- 客厅、茶室、老人房尽量都向中庭开窗，减少对南北西三侧邻居方向的依赖。

### 3. 西南侧：老人房套间

- 老人房建议放在西南或中西侧，靠近客餐厅和茶室，日常活动路径短。
- 老人房内部设置独立卫生间，建议卫生间靠近公卫或厨房一侧，便于管线集中。
- 老人房不要主要依赖西侧外窗，可面向中庭或小内院采光。

### 4. 中南侧：茶室

- 茶室建议靠近中庭，形成“茶室看院子”的体验。
- 可以做成独立房间，也可以用推拉门与客厅、中庭形成半开放关系。
- 如果未来希望更安静，茶室可稍微靠西；如果希望接待方便，可靠近玄关和客厅。

### 5. 北侧/东北侧：厨房、设备间、卫生间

- 厨房建议靠东北侧或北侧偏东，接近餐厅，方便上菜。
- 设备间建议贴近厨房、公卫或老人房卫生间，便于储水桶、加压泵、热水设备等集中布置。
- 设备间最好预留外部或半外部检修口，避免维修人员穿过卧室区。

### 6. 西北侧：卧室区

- 第一版默认配置 3 间卧室：老人房、主卧、次卧/书房。
- 若常住人口较多，可以把次卧/书房改为正式卧室。
- 卧室区尽量通过中庭、过道端部或小采光井获得自然光，少向邻居侧大面积开窗。

## 动线设计

- 入户动线：东南大门 -> 车位/前场 -> 玄关 -> 客餐厅 -> 中庭。
- 停车动线：东侧 5 米道路 -> 东南大门 -> 半露天车位。
- 老人动线：老人房 -> 客餐厅/茶室/中庭，尽量不穿越复杂走廊。
- 家务动线：厨房 -> 餐厅，设备间 -> 厨房/卫生间，管线尽量集中。
- 访客动线：玄关 -> 客厅/茶室，尽量不直接进入卧室区。

## 这一版的优点

- 适合东侧临路、三面邻居的地块条件。
- 中庭能显著改善单层住宅的采光和通风。
- 大门和车位都放在东南侧，符合现有出入口条件。
- 老人房带独卫，并靠近公共活动区，使用方便。
- 茶室和中庭结合，空间体验比单纯塞一个房间更好。
- 设备间靠近湿区，后期施工和维护更容易。

## 需要继续确认的问题

- 家庭常住人口，以及最终需要几间卧室。
- 主卧是否需要独立卫生间。
- 茶室要独立封闭，还是半开放连接客厅/中庭。
- 当地是否要求四周退界，以及南北邻居后墙的准确位置。
- 设备间储水桶容量、是否有水泵、热水器、太阳能或空气能设备。
- 车位希望完全露天，还是做雨棚/挑檐半露天。
