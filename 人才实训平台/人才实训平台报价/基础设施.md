## 基础设施功能描述

| 功能点 | 功能描述 |
| --- | --- |
| 算力管理 | 算力管理功能面向容器化实训环境和 Kubernetes 集群资源管理场景，支持对集群、节点、项目、命名空间、工作负载、应用和存储资源进行统一管理。平台可提供集群接入、集群成员管理、节点管理、工作负载查看、应用目录部署、持久化存储管理、集群健康与容量监控等能力，并支持通过访问凭证或命令行工具连接集群，便于管理员对实训运行环境、计算资源和应用部署状态进行集中维护。 |
| 统一身份认证 | 统一身份认证功能用于构建平台统一账号、组织和应用访问体系，支持用户与组织目录管理、统一登录、单点登录、应用资源管理和基于角色的访问控制。平台可对接 OAuth 2.x、OpenID Connect、SAML 2.0、JWT、CAS、SCIM 2.0 等标准协议，支持账号生命周期管理、组织与用户同步、多因素认证、密码策略、访问策略、登录行为记录和安全审计等能力，帮助平台实现多系统统一入口、统一身份管理和访问行为可追溯。 |
| 安全服务 | 安全服务功能面向容器、镜像、节点和运行时环境的安全防护场景，支持镜像漏洞扫描、运行时漏洞扫描、合规基线检查、准入控制、运行时行为检测、威胁检测、网络访问策略、主机与容器文件/进程监控等能力。平台可对镜像仓库、节点、容器和编排平台进行安全扫描，支持基于扫描结果进行风险查看、报告生成、策略拦截、告警通知和隔离处置，并可通过日志、Webhook、数据包捕获等方式辅助安全事件追踪，提升实训平台容器环境的安全可见性和防护能力。 |
| AI网关 | AI网关功能面向大模型统一接入、模型调用治理和用量管控场景，支持以统一接口接入多类大模型服务，并通过 OpenAI 兼容格式对外提供聊天、文本生成、向量、图像、音频等调用能力，降低不同模型供应方之间的接入差异。平台可配置模型列表、模型别名、路由策略、失败重试和备用模型，实现基础模型的统一管理和稳定调用；同时支持虚拟密钥生成与分发，可按调用凭证控制可访问模型、设置预算额度和调用速率限制，并进行调用成本追踪和日志记录。平台还可通过 Guardrails 机制接入内容安全检测和策略校验，对输入输出内容进行安全检查和拦截，帮助平台在模型调用、Token 分发、费用控制和内容安全方面形成统一治理能力。 |
