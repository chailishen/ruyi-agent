# 学生端操作手册

## 1. 文档说明

本文档面向实训平台学生端用户，说明学生在平台中进行门户浏览、课程学习、考试练习、项目实训、数据集管理、学习社区互动、AI 伴学、就业指导、个人中心管理等常用操作的方法。

本文档适用于学员、培训学员、企业在岗学习人员等学生端用户。管理员、教师端、运维端相关操作不在本文档范围内。

本文档截图来源于平台门户网站与学生端界面，实际页面显示可能因账号权限、课程配置、班级安排、浏览器窗口大小或系统版本略有差异，请以实际系统页面为准。

## 2. 学生端功能概览

学生端主要包含以下功能：

1. 门户浏览：查看首页、培养方向、课程、实训课程、教师、班级、考试、练习、项目工厂、数据集、论坛和资讯。
2. 课程学习：查看课程详情、报名或加入课程、进入课程学习、下载或查看课件、记录笔记、参与评论。
3. 考试练习：进入考试、练习题库、模拟考试，查看个人试卷与考试结果。
4. 项目实训：查看项目工厂、项目详情、数据集详情，进入个人项目和在线实训环境。
5. 学习资产：管理我的课程、我的班级、我的试卷、我的证书、我的收藏、我的订单、我的报名、我的项目和我的数据集。
6. AI 学习服务：使用 AI 伴学进行课程问答与知识点辅导。
7. 就业指导：使用简历指导、职业规划、岗位分析、模拟面试、求职资料和学习成果等功能。
8. 个人账户：查看消息通知、修改资料与账号信息、查看算力账户与资源使用情况。

## 3. 访问门户首页

### 3.1 打开平台门户

操作步骤：

1. 在浏览器地址栏输入平台门户地址。
2. 进入首页后，可通过顶部导航栏访问培养方向、课程、实训课程、教师、班级、考试、练习、项目工厂、论坛、资讯等栏目。
3. 如需进入个人学习中心，请先完成登录，再进入学生端个人中心。

![图 1 门户首页](../实训项目截图/门户网站/首页.png)

### 3.2 浏览培养方向

培养方向用于帮助学生了解不同岗位或学习路线对应的课程体系。学生可在培养方向列表中查看方向名称、简介和相关课程，并进入方向详情页了解学习路径。

操作步骤：

1. 在门户导航栏选择“培养方向”。
2. 在培养方向列表中浏览可选方向。
3. 点击目标方向，进入方向详情页。
4. 根据方向详情中的课程、项目或能力要求，选择后续学习内容。

![图 2 培养方向列表](../实训项目截图/门户网站/培养方向.png)

![图 3 培养方向详情](../实训项目截图/门户网站/培养方向详情.png)

### 3.3 查看教师与班级

学生可通过教师页面了解授课教师信息，通过班级页面查看可参加或已关联的班级内容。

操作步骤：

1. 在门户导航栏进入“教师”栏目。
2. 查看教师列表，了解教师头像、姓名、简介和课程信息。
3. 进入“班级”栏目，查看班级列表及班级相关信息。
4. 如需加入班级，请按页面提示完成报名、加入或联系管理员处理。

![图 5 班级列表](../实训项目截图/门户网站/班级.png)

## 4. 课程学习

### 4.1 浏览实训课程

学生可在实训课程页面查看平台提供的课程资源。课程通常包含课程封面、课程名称、课程简介、学习人数、价格或报名状态等信息。

操作步骤：

1. 在门户导航栏选择“实训课程”或课程相关入口。
2. 根据课程分类、方向或页面筛选条件查找课程。
3. 点击课程卡片进入课程详情页。

![图 6 实训课程列表](../实训项目截图/门户网站/实训课程.png)

### 4.2 查看课程详情

课程详情页用于展示课程介绍、章节内容、讲师信息、学习要求、评论、笔记、证书等内容。

操作步骤：

1. 在课程列表中点击目标课程。
2. 在课程详情页查看课程介绍、课程目录、适用对象、学习目标等信息。
3. 如课程支持报名、购买、收藏或分享，可根据页面按钮完成对应操作。
4. 报名或加入课程后，可在“我的课程”中继续学习。

![图 7 课程详情](../实训项目截图/门户网站/课程详情.png)

### 4.3 查看我的课程

“我的课程”集中展示学生已参加或已购买的课程，并显示学习进度。

操作步骤：

1. 登录后进入学生端个人中心。
2. 在左侧菜单选择“我的课程”。
3. 查看课程列表、学习状态和学习进度。
4. 点击课程对应的继续学习、查看详情或进入学习按钮，进入课程学习页面。

![图 8 我的课程](../实训项目截图/学生端/我的课程/9704becc-f60e-4f30-8916-f17e399fb34d.png)

### 4.4 使用学习笔记

学习笔记用于记录学习过程中的重点内容、问题和个人总结。

操作步骤：

1. 在课程学习过程中，根据页面入口新增笔记。
2. 进入个人中心，选择“我的笔记”。
3. 查看已记录的笔记内容。
4. 对已有笔记进行查看、编辑或删除。

### 4.5 查看我的班级

“我的班级”用于查看学生已加入的班级、班级课程、作业、考试、公告等教学安排。

操作步骤：

1. 登录后进入学生端个人中心。
2. 点击“我的班级”。
3. 查看班级名称、课程信息、教师信息和学习安排。
4. 按班级要求完成课程学习、作业、考试或公告查看。

## 5. 考试与练习

### 5.1 查看考试

考试页面展示平台提供的考试或课程关联考试。学生可根据考试名称、时间、状态等信息进入考试。

操作步骤：

1. 在门户导航栏选择“考试”。
2. 浏览考试列表，确认考试名称、考试时间和报名或参加状态。
3. 点击目标考试，按页面提示完成报名或进入考试。
4. 考试开始前，请确认网络稳定，避免刷新、关闭页面或重复提交。

![图 12 考试列表](../实训项目截图/门户网站/考试.png)

### 5.2 进入练习

练习功能用于课前预习、课后巩固或考前刷题。

操作步骤：

1. 在门户导航栏选择“练习”。
2. 查看练习列表。
3. 根据课程、方向或题型选择目标练习。
4. 进入练习后按题目要求作答，完成后提交查看结果。

![图 13 练习列表](../实训项目截图/门户网站/练习.png)

操作步骤：

1. 登录后进入学生端个人中心。
2. 点击“我的试卷”。
3. 查看试卷名称、考试状态、成绩或提交情况。
4. 根据页面状态查看详情、继续答题或查看成绩。

“我的报名”用于查看学生已报名的考试、课程、活动或相关项目。

## 6. 项目实训与数据集

### 6.1 浏览项目工厂

项目工厂展示平台提供的实训项目。学生可按方向、难度、热度等条件查找项目，并进入项目详情查看任务说明、源码、数据集和实训要求。

操作步骤：

1. 在门户导航栏进入“项目工厂”。
2. 浏览项目列表，选择感兴趣的项目。
3. 点击项目进入详情页。
4. 如项目支持 Fork、收藏、分享或进入开发环境，可根据页面按钮操作。

![图 18 项目工厂](../实训项目截图/门户网站/项目工厂.png)

项目详情页通常展示项目介绍、任务目标、项目资源、源码、评论和相关数据集。

操作步骤：

1. 在项目工厂中选择目标项目。
2. 查看项目说明、难度、方向、资源和数据集信息。

## 8. AI 伴学

AI 伴学用于课程辅导、知识点答疑和学习建议。学生可通过对话方式提出问题，系统根据课程内容或知识库进行回答与引导。

操作步骤：

1. 登录后进入学生端个人中心或课程学习页面。
2. 点击“AI 伴学”入口。
3. 新建对话或选择已有对话。
4. 输入问题，例如课程知识点、代码报错、实验步骤或复习问题。
5. 查看 AI 回复，并根据提示继续追问或完成练习。
6. 对于涉及考试答案、个人隐私或不确定的信息，请以教师要求和课程资料为准。

## 9. 就业指导

### 9.1 简历指导

简历指导用于帮助学生优化个人经历描述、项目经历、技能描述和岗位关键词匹配。

操作步骤：

1. 进入学生端个人中心或就业指导模块。
2. 点击“简历指导”。
3. 输入或上传个人经历、项目经历、教育经历等信息。
4. 根据 AI 生成的建议优化简历内容。
5. 检查简历中的关键词覆盖、量化表达和 STAR 结构。

### 9.2 职业规划

职业规划用于根据学生兴趣、技能、简历和目标岗位生成职业方向建议和学习路线。

操作步骤：

1. 进入“职业规划”功能。
2. 按页面提示完成对话式测评或填写个人信息。
3. 上传或补充简历信息。
4. 查看系统生成的职业兴趣、技能差距和学习建议。

### 9.3 岗位分析

岗位分析用于解析招聘 JD，帮助学生了解岗位所需技能、能力差距和投递方向。

操作步骤：

1. 进入“岗位分析”功能。

## 11. 常见问题与注意事项

### 11.1 无法登录或登录后自动退出

处理建议：

1. 检查账号、密码或验证码是否正确。
2. 确认浏览器是否允许 Cookie。
3. 尝试刷新页面或重新登录。
4. 如仍无法登录，请联系教师或平台管理员核对账号状态。

### 11.2 找不到课程、班级或考试

处理建议：

1. 确认是否已报名课程或加入班级。
2. 检查课程、班级或考试是否已到开放时间。
3. 在“我的课程”“我的班级”“我的报名”“我的试卷”中分别查看。
4. 如仍未显示，请联系教师或教务管理员确认是否已分配权限。

### 11.3 无法进入实训项目或在线环境

处理建议：

1. 确认项目是否已 Fork 到个人空间。
2. 检查数据集是否已关联或具备访问权限。
3. 查看算力账户是否有可用配额。
4. 若页面提示镜像、权限或资源异常，请将错误信息反馈给教师或运维人员。

### 11.4 考试或练习提交异常

处理建议：

1. 提交前确认网络连接稳定。
2. 不要重复点击提交按钮。
3. 不要随意关闭浏览器或刷新考试页面。
4. 如已提交但成绩未显示，请在“我的试卷”中查看记录，必要时联系教师处理。

### 11.5 AI 伴学回答与课程要求不一致

处理建议：

1. 优先以课程资料、教师要求和考试规则为准。
2. 使用 AI 伴学时尽量说明课程名称、章节和具体问题。
3. 对关键结论进行二次核对，避免直接照搬 AI 输出内容。

### 11.6 证书未生成或无法下载

处理建议：

1. 确认课程、考试或班级结业条件是否已全部完成。
2. 在“我的证书”中刷新查看。
3. 如证书状态异常，请联系教师或教务管理员核对成绩、审核状态和证书规则。
