## 大模型实训功能描述

| 功能点 | 功能描述 |
| --- | --- |
| 模型体验 | 提供面向文本、图像、视频、语音等模型的统一体验入口，支持用户在模型广场查看并选择不同模型进行能力体验。用户可开展文本对话、图像生成、视频生成、语音处理等操作，并可在文本对话场景下配置模型参数、设置系统提示词、添加对比模型进行效果对照，便于直观体验和比较不同模型的能力表现。 |
| 数据集 | 提供数据集管理能力，支持用户查看数据集列表及对应信息，并可按不同类型创建数据集，为模型训练、模型调优和模型评测提供数据支撑。平台支持按版本对数据集进行管理，允许同一数据集下维护不同版本，便于数据持续迭代、复用和追踪。 |
| 模型调优 | 提供模型调优任务管理能力，支持查看调优任务的具体信息，并支持 SFT 微调训练、DPO 偏好训练等多种调优方式。平台支持选择 LoRA、QLoRA、全参微调等训练范式，配置 FP16、BF16 等混合精度训练方式，并可选择预置模型或从 checkpoint 续训，配置 batch_size、learning_rate、n_epochs、max_seq_length 等训练参数；同时对训练数据集格式具备一定兼容能力，支持查看训练日志、图表、环境和训练过程等信息。 |
| 模型部署 | 提供模型部署管理能力，支持查看模型名称、基础模型、训练方式、训练范式、部署状态等信息，并可对已训练模型进行在线部署、查看 API 文档和在线体验。平台支持按照 HuggingFace、GGUF 等不同格式导出微调后的模型，便于模型后续集成、交付和应用。 |
| 模型评测 | 提供模型评测任务管理能力，支持在主页面查看评测模型、测评类型、评测状态、综合得分等信息。用户可选择标准评测基准开展通用能力测试，也可选择评测数据集并配置相关评测指标，对模型输出结果进行量化评估；同时支持选择裁判员模型、测评场景和评分提示词，通过 AI 对评测模型进行打分评估。平台对测评数据集格式具备一定兼容能力，并支持成功评测任务导出，失败任务可查看对应日志。 |
| 多模态数据标注 | 提供图像、视频、音频等多模态数据标注能力。图像标注支持 2D 边界框、立体边框、多边形、关键点等工具，满足从基础对象识别到复杂场景分析的标注需求；视频标注支持视频分割、场景分类、关键帧标注等训练场景；音频标注支持活动检测、说话人分离、事件标记等任务。标注完成后可导出 JSON、COCO、MASK 等主流格式，便于对接 TensorFlow、PyTorch、MMDetection 等训练框架。 |
| CV工具箱 | 内置目标检测等常见 CV 任务的权威数据集和常见 CV 模型基础权重，支持图像预处理与增强、训练任务配置、训练框架与数据集选择、训练参数设置和任务启动。平台支持查看训练任务状态、产出权重以及训练过程中的 Loss、mAP 等监控信息，并提供模型推理预测和模型评估对比能力，可选择模型权重、数据来源和相关参数展示预测结果，并查看指标结果及对比信息。 |
| 语音处理工具箱 | 提供面向语音实训的音频处理与分析能力，支持采集麦克风音频并实时查看波形图、频谱图及 MFCC 特征变化。平台支持加载语音模型开展语音转文字或声纹分类处理，也支持采集自定义语音命令样本进行录音即训练和测试识别；同时提供离线音频分析能力，可上传 .wav 文件开展高精度音频特征分析。 |
| 强化学习 | 提供多场景强化学习实验能力，支持在迷宫等场景下开展交互式强化学习仿真，配置算法参数、环境参数并启动学习过程，查看动作值、动作概率及学习进度变化。平台支持在 Metacar 交通环境中开展离散动作控制、连续动作控制等实验，并支持在线演示和自定义关卡配置；同时支持股票交易场景下的智能交易实验，可配置初始资金、训练起始日期、交易时间区间和算法鲁棒性参数，开展自动交易实验并查看交易日志与资产变化曲线。 |
| AI趣味学习 | 提供面向 AI 原理理解的趣味化、可视化学习工具，包括手势分类实验室、神经网络游乐场、迷你 GPT 探秘、GANs 对抗剧场、体征提取体验、Transformer 解码器、文生图扩散实验和语音特征可视化等内容。用户可在线训练 KNN 手势模型、实时观察神经网络权重与损失变化、查看 Transformer 注意力权重与 logits 生成过程、理解 GAN 生成器与判别器的博弈机制，也可通过视频特征提取、扩散去噪过程回放和语音频谱展示等方式直观理解典型 AI 模型的工作机理。 |
