# 个人知识库

本目录用于沉淀行业资料、案例与白皮书，方便日后按关键词检索、对比和复用。

## 目录约定

| 目录 | 用途 |
|------|------|
| `案例/` | 企业 AI / Agent 落地案例笔记（Markdown） |
| `白皮书/` | 行业白皮书、长报告原文（PDF 等） |
| `架构图/` | 系统架构 / 分层方案示意图 |
| `索引.md` | 全库条目清单与标签，优先从这里找 |

## 笔记写法约定

每篇 Markdown 尽量包含：

1. **元信息**：标题、来源链接、发布日期、标签
2. **一句话摘要**：方便扫一眼判断要不要细读
3. **关键要点**：数字化结果、方法路径、可复用结论
4. **正文整理**：按结构提炼，保留原文关键表述，方便日后引用

## 怎么找

- 先看 `索引.md`（按主题 / 标签）
- 或在本目录全文搜索关键词，例如：`WorkBuddy`、`Agent OS`、`国企`、`制造业`
