海尔智家把「智小能」定位为 AI 时代的企业 Agent OS：统一入口覆盖研产供销服 70+ 场景，并推动全民低代码开发；在数字化底座与权限边界之上，与腾讯云共创安全可控的规模化 Agent 落地。

## 核心观点

### 1. 制造业真正的难：不是造不出来，是打不中需求

- 用户需求更细（母婴辅食、养宠毛发、老人风感等）会传导到定义、备料、排产、库存。
- CTO 崔秀元：提前备货若不是消费者需要，会产生呆滞库存与原料积压。
- 企业不缺数据，缺的是「看懂需求 + 立刻联动研产供销服调整」。

### 2. 让 AI 成为企业的「操作系统」

- **智小能** = 员工统一入口（Agent OS）。
- 一句话查订单后，还可继续判断超时/加急；再问库存可比对紧缺并提醒补货。
- 场景例子：
  - **研发**：历史图纸识别 → BOM / 尺寸等结构化 → 进入数字化系统，变可复用资产
  - **经营分析**：日报不只推数，还能层层追因、抓核心问题
  - **采购**：经验量化 + 历史行情/定价/市场变化，辅助更理性判断
  - **服务**：进线先判故障；上门继续分层诊断

### 3. 从「等 IT 排期」到「全民开发者」

- 旧模式：业务懂现场不会开发，IT 永远排不完需求。
- 新模式：把想法说清楚 → 智小能生成应用 → 校验后发布；甚至有「写技能的技能」。
- 前提：**数字化底座先铺好**——数字化是基础，数据是养料，AI 是放大器。
  - 2022 年起建设 **H-work**：收拢研产供销服业务能力、权限与 API
  - Agent 阶段：业务 API **语义化**，大模型才知道调哪个接口、能做什么
  - 同一句「查订单」：在员工权限范围内找对应接口；市场 vs 采购可见 API 不同

### 4. 让 Agent 在企业里安全地做事

- 个人 AI 写文档质量差，顶多文档差；企业 Agent 碰采购/流程/财务，可能灾难性后果。
- 分工：海尔定义场景、数据、权限、业务入口；腾讯云基于 **ClawPro** 与全栈 AI，提供沙箱、模型、算力、智能体工程化。
- 原则：**关键指令必须人审**；AI 落地必须回到具体场景，不能泛泛谈工具。

## 对我的启发（个人笔记位）

- 「Agent OS」不是聊天入口，而是：**统一入口 + 语义化 API + 权限边界 + 场景资产沉淀**。
- 全员开发要建立在数字化与权限底座上，否则开放等于放大风险。
- 可对照自家产品：是否有 H-work 一类能力收拢层？是否有「写技能的技能」降低门槛？
- 安全共创模式可参考：客户定业务边界，云厂商补沙箱/隔离/工程化，驻场打通上线卡点。
