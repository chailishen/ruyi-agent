# 鲁信集团 × WorkBuddy：31 个场景落地

## 元信息

- **来源**：[管理七千亿资产，鲁信集团用 WorkBuddy 把 31 个场景跑通｜山东省属国企首例](https://www.chinaygj.com/news/workbuddy-lu-xin)
- **媒体**：山东云管家 / 云管家编辑部
- **发布日期**：2026-10-08
- **标签**：`国企` `金融` `WorkBuddy` `腾讯云` `场景落地` `安全合规` `FDE结对`

## 一句话摘要

管理资产超 7000 亿的山东省属金融国企鲁信集团，以「业务提需求 → 结对开发 → 真实测试 → 固化复用」推进腾讯 WorkBuddy，在 11 家直管企业、31 个场景落地 AI 员工助理，强调不越权、全程留痕，并形成「应用 → 沉淀 → 输出」能力链条。

## 关键数字

| 维度 | 结果 |
|------|------|
| 覆盖范围 | 11 家直管企业 / 部门，31 个业务场景 |
| 行业信息简报 | 约 1 小时 → 约 30 秒（提效约百倍），信息附来源 |
| 尽调报告 | 数周 → 数天；多章节并行 + 三道合规校验 |
| 周报撰写 | 约 1 小时 → 数分钟 |
| 财务核对 | 4 人近 1 天 → 约 10 分钟，输出差异标注表 |
| 包装企业月度对账 | 半天 → 几分钟（AI 自动匹配） |
| 光伏运维数据修复 | 人工整理 → 分钟级 |

## 可复用方法路径

### 落地四步

1. **业务提需求**：先摆真实痛点，不先买工具再找场景
2. **结对开发**：腾讯云 FDE 与鲁信业务/技术骨干「结对子」共建原型
3. **真实测试**：用真实材料喂养与迭代
4. **固化复用**：跑通后沉淀到集团 AI 资产库，一键复用

### 安全合规底线（国企敢规模化的前提）

- AI 执行不超出使用者权限
- 操作全程留痕
- 风险动作实时拦截
- 数据在企业安全边界内流转

### 组织能力生长链

1. **集团应用**：AI 助手服务具体业务、组织提效
2. **能力沉淀**：集团内公司具备场景化落地能力
3. **能力输出**：旗下公司成为 WorkBuddy 合作伙伴，对外提供转型服务

## 场景分类速览

### 1. 投研尽调（提效最直观）

- 行业简报：搜集慢 → 秒级出稿 + 来源标注
- 尽调报告：人工长周期 → AI 分工并行 + 合规校验

### 2. 日常办公（高频重复劳动）

- 周报：业务记录 → 规范公文
- 财务核对：人工对表 → 分钟级差异表

### 3. 实业一线

- 对账结算（包装）
- 光伏电站瑕疵数据识别与修复

## 关于 WorkBuddy（原文定位）

腾讯云企业级 AI 助手与智能体平台：在数据安全边界内调用文档、邮件、企业微信等能力；可按场景快速搭建「AI 员工助理」，并沉淀为可复用企业 AI 资产。

## 对我的启发（个人笔记位）

- 「先场景后工具」+ FDE 结对，比「先买平台再找场景」更适合受监管行业。
- 安全模型要产品化：权限继承、留痕、风险拦截，不是事后补丁。
- 价值不止单点提效，还要能沉淀成集团可复用资产，并具备对外输出可能。
- 可对照自家 Agent OS：场景资产库、结对交付、合规审计这三条是否齐备。

## 原文要点摘录

> 大型国企上 AI，最怕三件事：不安全、不合规，以及 AI 看不懂自己的业务。

> 一个场景跑通的典型流程：业务提需求 → 联合开发 → 真实测试 → 固化复用。

> 从提效工具，到可对外输出的组织能力——鲁信的探索，为更多大型集团的 AI 转型提供了一条可参考的路径。
