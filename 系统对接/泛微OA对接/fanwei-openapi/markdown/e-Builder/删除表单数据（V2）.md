# 删除表单数据（V2）

- **文档 ID**: `281164696529141760`
- **业务模块**: e-Builder / 应用建模 / 表单数据操作
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/ebuilder/form/dataset/v2/deleteData`
- **Content-Type**: `application/json`

## 备注

- POSTContent-Type : application/json

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | String | 操作人id |
| datajson | 是 | Object | 数据信息 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| header | Map | eb表单信息 |
| - objId | Long | eb表单id |
| operationinfo | Map | 操作信息 |
| - fieldNoFindIgnore | String | 传入字段不存在是否忽略(默认忽略; n/false不忽略) |
| mainTable | Map | 删除条件(多个条件之间且的关系) |
| - dxwb | String | 字段值, k-v结构, key: dataKey, value: dataValue |
| datajson | Map | 返回数据 |
| - dataIds | String | 成功删除的数据ids |
| - status | String | 数据操作状态(true:成功;false:失败) |
| - message | String | 请求异常信息 |
