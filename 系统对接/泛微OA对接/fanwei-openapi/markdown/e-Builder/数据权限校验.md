# 数据权限校验

- **文档 ID**: `840721775176982529`
- **业务模块**: e-Builder / 应用建模
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/ebuilder/form/dataset/v1/getDetail`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| dataId | 是 | Long | 数据id |
| objId | 是 | Long | 表单id |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| isQuickEdit | Boolean | 是否快速编辑 |
| objId | Long | 表单id |
| hasRight | Boolean | 是否有默认共享权限 |
| autoSave | int | 自动保存 0否/1是 |
| title | String | 数据标题 |
| isExist | Boolean | 数据是否存在 |
