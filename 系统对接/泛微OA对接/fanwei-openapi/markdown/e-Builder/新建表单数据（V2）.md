# 新建表单数据（V2）

- **文档 ID**: `281164209327177728`
- **业务模块**: e-Builder / 应用建模 / 表单数据操作
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/ebuilder/form/dataset/v2/saveFormData`
- **Content-Type**: `application/json`

## 备注

- POSTContent-Type : application/json

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | String | 操作人id |
| datajson | 是 | Object | 数据信息 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| header | Map | eb表单信息 |
| - objId | Long | eb表单id |
| operationinfo | Map | 操作信息 |
| - doAction | String | 执行当前操作数据对应action动作(默认不执行; y/true执行) |
| datas | List | 请求数据 |
| - mainTable | Map | 主表数据 |
| - dxwb | String | 字段值(浏览框字段多个值逗号分隔), k-v结构, key: dataKey, value: dataValue |
| - detail+明细表顺序 | List | 明细表数据，detail+明细表的顺序，比如detail1代表明细表1，detail2代表明细表2 |
| datajson | Map | 返回数据 |
| - dataIds | List | 本次操作数据ids |
| - status | String | 数据操作状态(true:成功;false:失败) |
| - message | String | 请求异常信息 |
