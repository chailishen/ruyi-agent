# 获取列表数据

- **文档 ID**: `840722243203465216`
- **业务模块**: e-Builder / 页面
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/ebuilder/coms/list/getData`
- **请求方式**: `POST`

## 备注

- 备注：

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| pageId | 是 | Long | 页面id |
| compId | 是 | String | 组件id |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | Number | 状态码 |
| msg | String | 返回信息 |
| status | Boolean | 接口是否请求成功 |
| data | Object | 组件配置信息 |
| data.count | Number | 总数 |
| data.pageSize | Number | 每页大小 |
| data.statisticsResult | json | 列表字段统计信息 |
| data.list | List | 数据列表 |
