# 获取图表数据

- **文档 ID**: `840722397788733441`
- **业务模块**: e-Builder / 页面
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/ebuilder/coms/chart/getData`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| pageId | 是 | Long | 页面id |
| compId | 是 | String | 组件id |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | Number | 状态码 |
| msg | String | 返回信息 |
| status | Boolean | 接口是否请求成功 |
| data | Object | 组件配置信息 |
| data[0].fe505d9_id | String | 图表维度值id |
| data[0].fe505d9 | String | 图表维度值 |
| data[0].ffb68e7 | String | 维度统计项值 |
