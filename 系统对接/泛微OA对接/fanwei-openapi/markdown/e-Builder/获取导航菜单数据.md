# 获取导航菜单数据

- **文档 ID**: `840722466566930432`
- **业务模块**: e-Builder / 页面
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/ebuilder/coms/navmenu/getData`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| pageId | 是 | Long | 页面id |
| compId | 是 | String | 组件id |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | Number | 状态码 |
| msg | String | 返回信息 |
| status | Boolean | 接口是否请求成功 |
| data | List | 菜单数据 |
| data[0].id | String | 菜单id |
| data[0].name | String | 菜单名称 |
| data[0].pid | String | 父菜单id |
| data[0].page | json | 菜单跳转地址信息 |
| data[0].openMode | String | 菜单打开方式 |
| data[0].isHomePage | Boolean | 是否默认选中 |
