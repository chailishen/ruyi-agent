# 获取数据详情（V2）

- **文档 ID**: `281164833481555968`
- **业务模块**: e-Builder / 应用建模 / 表单数据操作
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/ebuilder/form/dataset/v2/getDataById`
- **Content-Type**: `application/json`

## 备注

- POSTContent-Type : application/json

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | String | 操作人id |
| datajson | 是 | Object | 数据信息 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| header | Map | eb表单信息 |
| - objId | Long | eb表单id |
| operationinfo | Map | 操作信息 |
| - isReturnDetail | String | 是否返回明细表(默认不返回; y/true返回) |
| - fieldNoFindIgnore | String | 传入字段不存在是否忽略(默认忽略; n/false不忽略) |
| mainTable | Map | 过滤条件(多个条件之间且的关系) |
| - id | String | 字段值, k-v结构, key: dataKey, value: dataValue |
| datajson | Map | 返回数据 |
| - datas | String | 返回数据 |
| - mainTable | Map | 主表数据 |
| - detail+明细表顺序 | List | 明细表数据，detail+明细表的顺序，比如detail1代表明细表1，detail2代表明细表2 |
| - status | String | 数据操作状态(true:成功;false:失败) |
| - message | String | 请求异常信息 |
| fieldId | String | 字段id |
| fieldType | String | 返回数据 |
| fieldValue | String | 主表数据 |
| fieldOptionId | String | 选择框/浏览框 类型字段 数据库存储值 |
| fieldOptionName | String | 选择框/浏览框 类型字段 回显值 |
| dataIndex | Long | 明细表数据，detail+明细表的顺序，比如detail1代表明细表1，detail2代表明细表2 |
| subFormId | String | 明细表id |
