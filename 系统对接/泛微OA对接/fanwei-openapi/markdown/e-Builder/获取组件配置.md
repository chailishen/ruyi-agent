# 获取组件配置

- **文档 ID**: `840722144393175040`
- **业务模块**: e-Builder / 页面
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/ebuilder/coms/common/getConfig`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| pageId | 是 | Long | 页面id |
| compId | 是 | String | 组件id |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | Number | 状态码 |
| msg | String | 返回信息 |
| status | Boolean | 接口是否请求成功 |
| data | Object | 组件配置信息 |
| data.id | String | 组件id |
| data.pid | String | 父组件id |
| data.refCompId | String | 关联组件id |
| data.tenantKey | String | 租户id |
| data.config | json | 组件详细配置 |
