# 获取表单字段信息

- **文档 ID**: `840721689261735936`
- **业务模块**: e-Builder / 应用建模
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/ebuilder/form/dataset/v1/getFields`
- **请求方式**: `POST`

## 备注

- 备注：

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| objId | 是 | Long | 表单 id |
| isReturnDetail | 否 | String | 是否需要返回明细(默认不返回; y返回; n不返回； ) |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| fieldId | String | 字段id |
| fieldName | String | 字段名 |
| fieldType | String | 字段类型 |
| fieldKey | String | 实际字段类型 |
| number | Integer | 字段顺序 |
| multiSelect | Boolean | 是否多选 |
| objId | Long | 表单id |
| subFormIndex | String | 明细表下标 |
| subFormName | String | 明细表名 |
| mainFields | List | 主表字段 |
| detailFields | List | 明细字段 |
