# 获取表格基本信息

- **文档 ID**: `840721410013364225`
- **业务模块**: e-Builder / 应用建模
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/ebuilder/form/formcfg/list/v1/listInit`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| listId | 是 | Long | 表格 id |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| viewType | String | 展示方式 |
| name | String | 名称 |
| appId | String | 应用 id |
| pageSize | String | 分页大小 |
| listBaseInfo | Map | 列表基础配置信息 |
