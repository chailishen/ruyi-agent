# 获取表格查看权限

- **文档 ID**: `840721474344722433`
- **业务模块**: e-Builder / 应用建模
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/ebuilder/form/formcfg/list/permission/v1/getList`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| listId | 是 | Long | 表格 id |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| id | String | 权限 id |
| dataid | String | 数据 id |
| selectedType | String | 权限类型 |
| containExtra | String | 包含兼岗 |
| minShowlevel | String | 最小安全级别 |
| maxShowlevel | String | 最大安全级别 |
| jobLevel | String | 岗位级别 |
