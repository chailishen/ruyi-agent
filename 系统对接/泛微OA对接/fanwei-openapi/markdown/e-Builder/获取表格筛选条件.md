# 获取表格筛选条件

- **文档 ID**: `840721156559085568`
- **业务模块**: e-Builder / 应用建模
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/ebuilder/form/formcfg/list/listFilter/v1/getSearchFilters`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| listId | 是 | Long | 表格 id |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| commonFilters | List | 常用搜索 |
| quickFilters | List | 快捷搜索 |
| groupFilters | List | 分类搜索 |
| id | String | 配置id |
| fieldId | String | 字段id |
| fieldName | String | 字段显示名 |
| fieldType | String | 字段类型 |
| showOrder | int | 显示顺序 |
| componentKey | String | 字段组件类型 |
| isQuick | String | 是否快捷搜索 0不是/1是 |
| isAdvance | String | 是否高级搜索 0不是/1是 |
| startValue | String | 默认条件起始值 |
| endValue | String | 默认条件结束值 |
