# 表单数据保存

- **文档 ID**: `840721908229570561`
- **业务模块**: e-Builder / 应用建模 / 表单数据操作
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/ebuilder/form/dataset/v1/saveFormData`
- **请求方式**: `POST`

## 备注

- 备注：

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| datajson | 是 | Object | 数据信息 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| objId | Long | 表单id |
| datas | Object | 数据信息 |
| mainTable | Object | 主表数据信息 |
| id | String | 主表数据id;为空默认走新增逻辑;有对应数据id即为更新逻辑 |
| optionNoFindIgnore | String | 选项找不到是否忽略(默认忽略; false不忽略; true忽略;) |
| doAction | String | 是否执行action动作(默认不执行; y执行; n不执行) |
| detail+明细表顺序 | Object | 明细表数据，detail+明细表的顺序，比如detail1代表明细表1，detail2代表明细表2 |
| operateType | String | 明细表操作类型(传入明细数据detail时必填)，覆盖:save[默认明细覆盖]、追加:append、更新:update(若是更新则必须加上明细行号dataIndex属性[String类型]) |
| dataIndex | String | 明细行号，只有明细操作类型为更新时，需要传入明细行号，只会更新匹配的行号 |
| code | String | 返回码 |
| msg | String | 返回信息 |
| dataDetails | List | 数据明细 |
| dataId | String | 数据id |
| status | String | 数据保存状态 |
