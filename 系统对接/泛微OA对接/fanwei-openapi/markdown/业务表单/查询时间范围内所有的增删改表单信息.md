# 查询时间范围内所有的增删改表单信息

- **文档 ID**: `840717179428634624`
- **业务模块**: 业务表单
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/form/v2/queryChangedForms`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 |
| userid | 是 | Long | 用户ID 获取用户ID |
| datamap | 是 | String | 查询日期区间 |
| pageNo | 否 | Int | 页码 |
| pageSize | 否 | Int | 每页显示条数 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| delList | List | 删除的表单列表 |
| updateList | List | 更新的表单列表 |
| addList | List | 新增的表单列表 |
| id | Long | 表单ID |
| name | String | 表单名称 |
