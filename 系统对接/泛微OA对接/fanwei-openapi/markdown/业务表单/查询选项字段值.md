# 查询选项字段值

- **文档 ID**: `840717531792113664`
- **业务模块**: 业务表单
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/formdatareport/v2/getFieldOption`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | string | 用户ID 获取用户ID |
| formId | 是 | string | 表单ID 获取表单ID |
| fieldId | 否 | string | 字段ID 字段ID |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| userid | String | 用户ID |
| fieldId | String | 字段ID |
| fieldOptionList | List | 字段选项集合 |
| delete | Boolean | 是否删除 |
| id | String | 选项值ID |
| name | String | 选项名称 |
| order | String | 选项顺序值 |
| children | List | 子选项集合 |
