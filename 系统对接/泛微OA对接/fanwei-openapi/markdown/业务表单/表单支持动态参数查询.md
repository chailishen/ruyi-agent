# 表单支持动态参数查询

- **文档 ID**: `840716866071306240`
- **业务模块**: 业务表单
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/form/v2/getInfoByIDAndParam`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| id | 是 | Long | 表单ID 获取表单ID |
| pageNo | 是 | Int | 分页页码 |
| pageSize | 是 | Int | 分页展示数据数，默认最大20 |
| datamap | 是 | String | 表单名称names，提交时间createTimes，提交人operators，部分自定义字段 表单查询datamap传值说明 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| createTime | String | 表单数据提交时间 |
| id | String | 表单数据ID |
| reporter | String | 提交人信息 |
| status | String | 状态 |
