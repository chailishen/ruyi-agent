# 产品获取自定义表单

- **文档 ID**: `840719348412284928`
- **业务模块**: 产品
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/crm/v2/getCustomForms`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| module | 是 | String | 模块固定取值：production |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| name | String | 自定义表单名称 |
| id | String | 自定义表单ID |
