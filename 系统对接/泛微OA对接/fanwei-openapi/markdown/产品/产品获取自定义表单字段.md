# 产品获取自定义表单字段

- **文档 ID**: `840719404272025601`
- **业务模块**: 产品
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/crm/v2/getCustomFields`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| module | 是 | String | 模块固定取值：production |
| formId | 是 | Long | 表单ID 获取自定义表单ID |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| title | String | 字段名称 |
| componentKey | String | 字段类型 |
| required | Bool | 是否必填 |
| delete | Bool | 是否删除 |
| id | String | 字段ID |
