# 新增产品

- **文档 ID**: `840718979144884224`
- **业务模块**: 产品
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/crm/v2/create`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| module | 是 | String | 模块固定为： production |
| entity | 是 | Object | 产品信息 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |

| productionPrice | String | 单价 |
| productionUnit | String | 规格 |
| productionType | String | 类型 |
| productionStatus | String | 状态 |
| productionCurrency | String | 货币单位 |
| productionCount | String | 库存 |

| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | Object | 产品信息（JSON格式） |
