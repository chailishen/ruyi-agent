# 人员编制-编制校验

- **文档 ID**: `365948145936367616`
- **业务模块**: 人事档案
- **是否 API 接口**: 是
- **请求 URL**: `/api/hr/hrapi/est/validate`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| userid | 是 | long | 操作人员id |
| empList | 是 | array | 新增的人员数据 |
| source | 是 | string | 新增人员：addEmp，更新人员：updateEmp |
| updateEmpFieldList | 否 | array | 更新的人员字段key,empList的参数key |
| preIgnoreBusiIdList | 否 | array | 校验的时候忽略的预增数据busiId集合 |
| date | 否 | string | 校验日期 2025-10-11 这样格式的字符串，传递的话，按照这个日期的编制配置进行校验，只支持当前和未来日期【1101基线支持】 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| id | long | 人员id，新增人员不需要 |
| departmentId | long | 部门id |
| positionId | long | 岗位id |
| locationId | long | 办公地点id |
| jobcallId | long | 职称 |
| gradeId | long | 职级 |
| jobsetLevelId | long | 职等 |
| hiredate | date | 入职日期 |
| personnelStatus | string | 人员状态 |
| errmsg | string | 错误提示 |
| checkResult | boolean | 是否校验通过 |
| errContent | string | 校验不通过提示内容 |
| overCtrl | string | 超编管控 强控：STRONG，弱控：WEAK |
