# 修改人员（V3）

- **文档 ID**: `840674702276698112`
- **业务模块**: 人员
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/user/v3/updateUser`
- **请求方式**: `POST`

## 备注

- 备注：1、原有必填字段userid改为非必填，加上wechatUserId字段；2、Userid和wechatUserId传其中一个即可，userid优先，都没传则提示错误；3、若没传userid，传了wechatUserId，根据wechatUserId查询处人员信息，拿到userid再进行原有的逻辑；
