# 新增人员

- **文档 ID**: `840674629296685057`
- **业务模块**: 人员
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/user/v3/createUser`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| name | 是 | String | 用户名称 |
| mobile | 是 | String | 手机号（默认为登录账号） |
| department | 是 | List | 所属部门ID集合 获取部门ID |
| email | 否 | String | 邮箱(mobile和email不能同时为空) |
| jobNum | 否 | String | 工号 |
| telephone | 否 | String | 电话 |
| hireDate | 否 | String | 入职日期（格式：2019-08-20） |
| sex | 否 | String | 性别（male、female） |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| userId | String | 用户ID |
