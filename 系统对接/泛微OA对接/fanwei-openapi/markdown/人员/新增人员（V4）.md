# 新增人员（V4）

- **文档 ID**: `840674663731920896`
- **业务模块**: 人员
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/user/v4/createUser`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 操作人员ID |
| name | 是 | String | 用户名称 |
| mobile | 是 | String | 手机号（默认为登录账号） |
| department | 是 | List | 所属部门ID集合(只支持传递一个部门ID) 获取部门ID |
| email | 否 | String | 邮箱(mobile和email不能同时为空) |
| jobNum | 否 | String | 工号 |
| telephone | 否 | String | 电话 |
| hireDate | 否 | String | 入职日期（格式：2019-08-20） |
| sex | 否 | String | 性别（male、female） |
| position | 否 | List | 所属岗位ID集合 |
| grade | 否 | Long | 所属职级ID |
| superior | 否 | List | 上级ID集合 |
| assistant | 否 | List | 助理ID集合 |
| access | 否 | List | 权限开放ID集合 |
| idNo | 否 | String | 身份证号码 |
| birthday | 否 | String | 出生日期（格式：2019-08-20） |
| age | 否 | String | 年龄(0-120) |
| maritalStatus | 否 | String | 婚姻状况(married（已婚）,unmarried（未婚）,divorced（离异）) |
| education | 否 | String | 学历(senior(高中及以下),technicalSecondary(中技,中专,技校,职高),junior(大专),regular(本科),master(硕士研究生),MBA,doctor(博士研究生)) |
| degree | 否 | String | 学位(doctor(博士),master(硕士),bachelor(学士)) |
| graduateSchool | 否 | String | 毕业院校 |
| graduateDate | 否 | String | 毕业日期（格式：2019-08-20） |
| nativePlace | 否 | String | 籍贯 |
| nation | 否 | String | 民族(汉族，壮族等) |
| householdType | 否 | String | 户口类型（thisCityTown(本市城镇)，thisCityRural(本市农村)，otherCityTown(外埠城镇)，otherCityRural(外埠农村)） |
| politicsStatus | 否 | String | 政治面貌（partyMember(党员,预备党员)，groupMember(团员)，democraticParty(民主党派)，nonparty(无党派人士,群众)，other(其他)） |
| residencePlace | 否 | String | 现居住地 |
| familyContact | 否 | String | 家庭联系方式 |
| firstWorkDate | 否 | String | 首次工作时间（格式：2019-08-20） |
| workYear | 否 | String | 工龄 |
| alias | 否 | String | 别名 |
| childStatus | 否 | String | 子女状态 |
| formDataMap | 否 | String | 人事档案自定义字段 获取自定义表单字段 传值说明 |
| otherSuperior | 否 | List | 其他上级 |
| password | 否 | String | 密码 （只有云上手机或者邮箱没有注册过，才有效果；例如在其他租户已经注册了该手机号码，当前租户创建，则密码无效） |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| userId | String | 用户ID |
