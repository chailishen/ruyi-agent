# 查询人员-高级搜索

- **文档 ID**: `949490563329605633`
- **业务模块**: 人员
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/hrm/restful/queryEmployee`
- **请求方式**: `POST`
- **Content-Type**: `application/json`

## 备注

- 备注:
- Body 参数格式(application/json)

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| jobNumList | 否 | Array[String] | 工号 |
| subcompanyIds | 否 | Array[String] | 分部id |
| departmentIds | 否 | Array[String] | 岗位id |
| ids | 否 | Array[String] | 人员id |
| containUserInfo | 否 | boolean | 加载个人信息 |
| containEmployeeExtend | 否 | boolean | 加载基本信息自定义 |
| containUserInfoExtend | 否 | boolean | 加载个人信息自定义（这个参数为true；必然提供个人信息内容） |
| current | 否 | Integer | 分页-当前页 |
| pageSize | 否 | Integer | 分页-页大小（最大1000） |
| userStatusList | 否 | Array[String] | 人员状态（人员状态支持：normal 在职；unavailable 离职。如果不提供默认在职） |
| nameLikeList | 否 | Array[String] | 名称模糊查询 |
| returnFieldList | 否 | Array[String] | 指定返回字段内容（指定employee表中的字段；默认全字段返回。示例：["id"] 仅返回人员id；["id","username"] 仅返回人员id、人员名称） |
| multiFieldList | 否 | Array[String] | 需要返回的多语言字段列表（支持： username 人员名称） |
| account | 否 | String | 账号（支持： 卡片-账号信息中 账号、绑定手机、绑定邮箱、登录名（weaver-hrm-service 1.14后支持）） |
| needAccountInfo | 否 | boolean | 是否查询账号 |
