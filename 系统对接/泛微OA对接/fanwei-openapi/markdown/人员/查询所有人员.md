# 查询所有人员

- **文档 ID**: `840674921396404224`
- **业务模块**: 人员
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/user/v3/findAllUsers`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| page | 否 | Int | 分页页码，从1开始（不传值则默认为1，每页1000条数据） |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| userid | String | 用户ID |
| name | String | 用户名 |
| department | List | 部门列表 |
| mobile | String | 手机号码 |
| email | String | 邮箱 |
| jobNum | String | 工号 |
| hireDdate | String | 入职日期 |
| sex | String | 性别 |
| status | String | 成员状态：在职normal、离职unavailable、已邀请invited |
