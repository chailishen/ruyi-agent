# 获取部门成员信息

- **文档 ID**: `840675002832134145`
- **业务模块**: 人员
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/user/v3/departmentUsers`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| depid | 是 | Long | 部门ID 获取部门ID |
| status | 是 | String | 成员状态：在职normal、离职unavailable、已邀请invited、所有ALL |
| fetch_child | 是 | String | 是否递归子部门：0非递归、1递归 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| user | Object | 成员信息 |
| userid | String | 用户ID |
| username | String | 用户名 |
| department | List | 部门列表 |
| mobile | String | 手机号码 |
| email | String | 邮箱号码 |
| status | String | 成员状态：在职normal、离职unavailable、已邀请invited |
