# 任务可变更状态列表查询接口（支持批量）

- **文档 ID**: `840679057390313473`
- **业务模块**: 任务
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/task/v3/status/changeableList`
- **请求方式**: `POST`
- **Content-Type**: `application/json`

## 备注

- 备注
- 参数格式为Content-Type: “application/json”

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 当前操作人ID 获取用户ID |
| propertyDataList | 是 | List | 任务属性集合，支持多个map对象 |
| id | 是 | Long | 任务ID 获取任务ID |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| resultList | Object | 接口返回结果 |
| id | Long | 当前查询任务的ID |
| name | String | 当前查询任务的名称 |
| status | String | 当前查询执行状态（success成功、fail失败） |
| data | Object | 接口返回 |
| currentStatus | Object | 任务当前的状态 |
| changeableStatusList | List | 任务可变更的状态列表 |
