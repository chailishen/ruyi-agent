# 任务新建接口（支持批量）

- **文档 ID**: `840678975643328512`
- **业务模块**: 任务
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/task/v3/create`
- **请求方式**: `POST`
- **Content-Type**: `application/json`

## 备注

- 备注
- 参数格式为Content-Type: “application/json”
- 备注：
- 使用Content-Type:application/json 格式传递，任务更新接口（支持批量）接口也一致propertyDataList 示例：

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 当前操作人ID 获取用户ID |
| propertyDataList | 是 | List | 任务属性集合，支持多个map对象 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| name | String | 任务名称 |
| content | String | 任务详情 |
| status | String | 任务状态（todo(未完成)） |
| beginDate | String | 任务起始时间（格式：yyyy-MM-dd或者yyyy-MM-dd hh:mm ） |
| dueDate | String | 任务到期时间（格式：yyyy-MM-dd或者yyyy-MM-dd hh:mm ） |
| progress | Float | 任务进度（范围0-1，支持一位小数，如0.5） |
| priority | String | 任务紧急程度（urgency(非常紧急), high(紧急), normal(正常)） |
| parentId | Long | 上级任务ID（传了此参数表示当前为新建子任务） |
| taskTypeForm | Long | 任务类型ID（taskTypeForm不传，formId不传，就是“其他”类型） |
| manager | Long | 任务负责人ID |
| participanterIds | List | 参与人ID（Long型集合） |
| sharerIds | List | 共享人集合（map型），key支持sid和entryType。sid: Long型；entryType: 取值范围（user(人员)、department(部门)、group(群组)、all(所有人)、external(外部联系人)） |
| mainlineId | Long | 所属项目ID |
| stageId | Long | 项目下任务分组ID（stageId要生效必传mainlineId） |
| group | String | 任务分组 （暂默认为“today”） |
| attachments | List | 附件ID（Long型集合） |
| locked | Boolean | 是否锁定 |
| milestone | Boolean | 是否里程碑任务 |
| entityRemind | Map | 提醒（字段说明见下） |
| entityRepeatWeb | Map | 周期创建（字段说明见下） |
| formId | String | 自定义字段表单ID 查询表单ID |
| commonFormData | String | 通用字段数据 传参说明 |
| taskTypeFormData | String | 自定义字段数据 传参说明 |
| entityId | Long | 任务ID（任务修改时必传） |
| type | String | 提醒类型（”cancel”不提醒、”minute”分钟、”hour”小时、”day”天） |
| time | Integer | 提醒时间（type为”cancel”时可不传此项；type为”minute”时仅支持10、30；type为”hour”时仅支持1；type为”day”时仅支持1、2、3、4、5；） |
| remindEntryList | List | 提醒人员类型（取值范围：”create”创建人, “primary”负责人,”participants”参与人） |
| entityId | Long | 任务ID（任务修改时必传） |
| repeatType | String | 重复类型（”cancel”不重复、”day”天、”week”周、”month”月、”season”季、”year”年） |
| frequency | Integer | 频率 |
| orderType | String | 计数顺序（顺数”ASC”、倒数”DESC”）） |
| countDays | Integer | 频率为按年、按季、按月时，第几天 |
| weekRepeatDate | List | 频率为“按周”时，选择生效的时间（取值范围：”monday”、”tuesday”、”wednesday”、”thursday”、”friday”、”saturday”、”sunday”） |
| endRepeatType | String | 结束类型（”never”永不，”number”次数、”date”日期） |
| repeatCount | Integer | 结束类型为“次数”时，结束次数 |
| endRepeatTime | String | 结束类型为“日期”时，结束日期（格式：yyyy-MM-dd或者yyyy-MM-dd hh:mm） |
| dateModel | String | 基准（””createTime”创建日、”beginTime”起始日” |
| includeSubTask | 是否包含子任务 | 是否包含子任务 |
| includeRelatedMatter | Boolean | 是否包含关联事项 |
| code | String | 返回码 |
| msg | String | 返回信息 |
| status | Boolean | 状态 |
| data | String | 执行结果 |
