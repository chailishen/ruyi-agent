# 修改任务

- **文档 ID**: `840678520561344513`
- **业务模块**: 任务
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/task/v2/update`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| id | 是 | Long | 任务ID 获取任务ID |
| propertyName | 是 | String | 需要修改的参数名 |
| propertyValue | 是 | String | 参数值 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| name | String | 任务名 |
| status | String | 状态 todo(未完成)、doing(进行中)、finished(已完成) |
| dueDate | String | 结束日期 格式：2021-05-11 15:00 或者2021-05-11 |
| beginDate | String | 开始日期 格式：2021-05-11 15:00 或者2021-05-11 |
| priority | String | 紧急程度 urgency(非常紧急), high(紧急), normal(正常) |
| content | String | 内容 |
| locked | String | 是否锁定 true、false（”true”就是true，其他情况均为false） |
| progress | String | 进度（小数） |
| manager | String | 任务负责人（propertyValue为负责人ID） |
| stage | String | 项目的计划任务分组信息 （propertyValue为mainlineId**_stageId（项目Id_**任务分组Id） |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
