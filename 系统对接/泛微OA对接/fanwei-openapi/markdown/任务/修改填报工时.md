# 修改填报工时

- **文档 ID**: `840678889912631296`
- **业务模块**: 任务
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/task/v2/updateRealWorkingTimes`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userId | 是 | String | 用户id |
| fillRecords | 是 | List<Object> | 参数List, 单个元素包含如下字段 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| id | String | 任务工时填报记录id |
| workingTime | String | 工时量, 最多保留两位小数 |
| description | String | 填报备注 |
| message | Object | 提示信息 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
