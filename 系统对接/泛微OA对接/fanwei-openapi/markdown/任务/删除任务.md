# 删除任务

- **文档 ID**: `840678477662879744`
- **业务模块**: 任务
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/task/v2/delete`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| id | 是 | Long | 任务ID 获取任务ID |
| deleteType | 否 | String | 删除类型（CURRENT_ONLY：只删除当前任务（默认）、SUBTASK_ONLY：只删除当前任务的子任务、CURRENT_AND_SUBTASK：删除当前任务和子任务） |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
