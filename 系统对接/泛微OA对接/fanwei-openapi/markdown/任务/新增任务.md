# 新增任务

- **文档 ID**: `840678438974619649`
- **业务模块**: 任务
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/task/v2/create`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| name | 是 | String | 任务名称 |
| content | 是 | String | 任务内容 |
| group | 是 | String | 任务分组 （暂默认为“today”） |
| commonFormData | 否 | String | 通用字段数据 传值说明 |
| formId | 否 | Long | 自定义字段表单ID 查询表单ID（注意：单表单团队此参数不生效） |
| taskTypeFormData | 否 | String | 自定义字段数据 传值说明 |
| parentId | 否 | Long | 父任务ID，传了此参数表示当前为新建子任务 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| taskid | Long | 任务ID |
