# 新增填报工时

- **文档 ID**: `840678855469006849`
- **业务模块**: 任务
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/task/v2/fillRealWorkingTimes`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| fillRecords | 是 | List<Object> | 参数List, 单个元素包含如下字段 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| taskId | String | 任务id |
| userId | String | 用户id |
| workingTime | String | 工时量, 最多保留两位小数 |
| workingTimeDate | String | 填报日期，精度为天，例如：’2021-10-21’ |
| description | String | 填报备注 |
| message | Object | 提示信息 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | List<Object> | 返回工时信息集合 |
| updateUser | Object | 更新人 |
| updateTime | Date | 更新时间 |
| description | String | 工时描述信息 |
| workingTime | Float | 实际工时 |
| workingTimeDate | Date | 实际工时选择的日期 |
| userName | String | 用户姓名 |
| userId | Long | 用户ID |
| createUser | Object | 创建人 |
| createTime | Date | 创建时间 |
| id | Long | 实际工时ID |
| taskId | String | 任务ID |
