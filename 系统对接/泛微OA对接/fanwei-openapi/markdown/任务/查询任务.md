# 查询任务

- **文档 ID**: `840678567714586624`
- **业务模块**: 任务
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/task/v2/info`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| id | 是 | Long | 任务ID 获取任务ID |
| containsSub | 否 | Boolean | 是否查询子任务（true是，false否） |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| task | Object | 任务对象 |
| name | String | 任务名称 |
| content | String | 任务内容 |
| locked | Boolean | 是否锁定 |
| commonForm | Object | 表单通用模板 |
| taskTypeForm | Object | 任务类型（属表单） |
| module | String | 模块名 |
| lockable | Boolean | 是否可锁定 |
| parent | Object | 父任务 |
| dueDate | Date | 到期日 |
| finishTime | Date | 结束时间 |
| priority | String | 优先级 |
| manager | Object | 负责人 |
| sn | Long | 排序序号 |
| isDelete | Boolean | 是否已删除 |
| progress | Float | 进度 |
| parentIndex | Int | 父任务下的排序 |
| status | String | 状态 |
| tailnum | String | 流水号 |
| creator | Object | 创建者 |
| commonFormData | Object | 通用字段数据 |
| taskTypeFormData | Object | 自定义字段数据 |
| lastUpdateTime | Date | 最后修改时间 |
| lastCommentTime | Date | 最后评论时间 |
| tenantKey | String | 团队key |
| id | Long | 任务ID |
