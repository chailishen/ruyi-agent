# 查询团队实际工时

- **文档 ID**: `840678816755580929`
- **业务模块**: 任务
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/task/v2/queryRealWorkingTimes`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| startTime | 否 | Date | 开始时间，格式 (yyyy-MM-dd HH:mm:ss) |
| endTime | 否 | Date | 结束时间，格式(yyyy-MM-dd HH:mm:ss) |
| dateType | 否 | String | 当值为“update”时，开始时间和结束时间表示更新时间，否则表示创建时间 |
| bmFollowParent | 否 | String | 当值为“T”时，表示子任务所属项目跟随父任务 |
| workingTimeDate | 否 | String | 工时填报日期, 精度为天，例如：’2021-10-21’ |
| taskId | 否 | String | 任务id |
| userId | 否 | String | 填报人id |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| message | Object | 提示信息 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| realWorkingTimes | List<Object> | 返回工时信息集合 |
| id | Long | 实际工时ID |
| workingTime | Float | 实际工时 |
| workingTimeDate | Date | 实际工时选择的日期 |
| description | String | 工时描述信息 |
| userId | Long | 用户ID |
| userName | String | 用户姓名 |
| taskId | String | 任务ID |
| taskName | String | 任务名称 |
| parentId | Long | 父任务ID |
| parentName | String | 父任务名称 |
| mainlineId | Long | 所属项目ID |
| mainlineName | String | 所属项目名称 |
| createUser | Object | 创建人 |
| createTime | Date | 创建时间 |
| updateUser | Object | 更新人 |
| updateTime | Date | 更新时间 |
