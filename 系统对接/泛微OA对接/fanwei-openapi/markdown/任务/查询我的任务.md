# 查询我的任务

- **文档 ID**: `840678649250979841`
- **业务模块**: 任务
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/task/v2/mineInfo`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| type | 否 | string | 查询类型 mine: 我负责和参与的任务、mineCreate: 我创建的任务、mineManager：我负责的任务、mineParticipants：我参与的任务 |
| queryParams | 否 | Object | 查询条件参数Map, 包含如下参数 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| beginDate | Object | 开始时间，参数值格式为{“value”: “2021-08-12”} |
| dueDate | Object | 到期时间，参数值格式为{“value”: “2021-09-12”} |
| taskTypeId | Object | 任务类型id，参数值格式为{“value”: “8993376296724213239”} |
| pageNo | number | 分页页码，参数格式："pageNo":1,默认值1 |
| pageSize | number | 分页容量，参数格式："pageSize":10,默认值50000 |
| taskStatus | Object | 任务状态, 参数格式为{"value":"ﬁnished"} |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| task | Object | 任务对象 |
| name | String | 任务名称 |
| content | String | 任务内容 |
| locked | Boolean | 是否锁定 |
| commonForm | Object | 表单通用模板 |
| taskTypeForm | Object | 任务类型（属表单） |
| module | String | 模块名 |
| lockable | Boolean | 是否可锁定 |
| parent | Object | 父任务 |
| dueDate | Date | 到期日 |
| finishTime | Date | 结束时间 |
| priority | String | 优先级 |
| manager | Object | 负责人 |
| sn | Long | 排序序号 |
| isDelete | Boolean | 是否已删除 |
| progress | Float | 进度 |
| parentIndex | Int | 父任务下的排序 |
| status | String | 状态 |
| tailnum | String | 流水号 |
| creator | Object | 创建者 |
| commonFormData | Object | 通用字段数据 |
| taskTypeFormData | Object | 自定义字段数据 |
| lastUpdateTime | Date | 最后修改时间 |
| lastCommentTime | Date | 最后评论时间 |
| tenantKey | String | 团队key |
| id | Long | 任务ID |
