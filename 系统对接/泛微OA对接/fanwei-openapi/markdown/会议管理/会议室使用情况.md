# 会议室使用情况

- **文档 ID**: `840720606778982401`
- **业务模块**: 会议管理
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/room/v2/queryEvents`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| start | 是 | Date | 开始时间，格式为（yy-MM-dd HH:mm:ss） |
| end | 是 | Date | 结束时间，格式为（yy-MM-dd HH:mm:ss） |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| room.name | String | 会议室名称 |
| room.id | String | 会议室ID |
| agenda.name | String | 日程名称 |
| agenda.id | String | 日程ID |
| agenda.startDate | String | 开始时间 |
| agenda.endDate | String | 结束时间 |
| agenda.allDay | Boolean | 是否全天 |
| agenda.repeat | Boolean | 是否重复 |
| agenda.repeatNum | String | 重复次数 |
| agenda.secret | String | 公开程度 |
