# 会议室使用情况（V2）

- **文档 ID**: `241292137675620352`
- **业务模块**: 会议管理
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/meeting/meetingOpenApi/getRoomUsageEvents`
- **Content-Type**: `application/json`

## 备注

- POST （Content_Type: application/json）

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| id | 否 | String | 会议室ID（多个地点以”,”分隔） |
| start | 是 | Date | 开始时间，格式为（yy-MM-dd HH:mm:ss） |
| end | 是 | Date | 结束时间，格式为（yy-MM-dd HH:mm:ss） |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| status | Boolean | 状态 |
| room.name | String | 会议室名称 |
| room.id | String | 会议室ID |
| id | String | 会议id |
| title | String | 会议名称 |
| start | Date | 开始时间 |
| end | Date | 结束时间 |
| creator | String | 创建人 |
