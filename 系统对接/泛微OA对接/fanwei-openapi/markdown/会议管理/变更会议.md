# 变更会议

- **文档 ID**: `871465099483553793`
- **业务模块**: 会议管理
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/meeting/meetingOpenApi/changeMeeting`
- **Content-Type**: `application/json`

## 备注

- POST（Content_Type: application/json）

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| id | 是 | Long | 会议id |
| creator | 是 | Long | 创建人id 获取用户ID |
| name | 是 | String | 会议名称 |
| beginDatetime | 是 | Date | 开始日期时间(格式：yyyy-MM-dd HH:mm) |
| endDatetime | 是 | Date | 结束日期时间(格式：yyyy-MM-dd HH:mm) |
| mtDesc | 否 | String | 会议内容 |
| hrmMembers | 否 | String | 参会人员（多个人员以”,”分隔） |
| address | 否 | String | 会议地点 |
| customizeAddress | 否 | String | 自定义会议地点 |
| caller | 否 | Long | 召集人 |
| contacter | 否 | Long | 联系人 |
| orgMembers | 否 | String | 参会部门（多个人员以”,”分隔） |
| remindType | 否 | String | 提醒方式(2:短信提醒,3:邮件提醒,6:立即提醒;多个以”,”分隔) |
| remindImmediately | 否 | Integer | 0:不开启立即提醒；1:开启立即提醒 |
| remindBeforeStart | 否 | Integer | 0:不开启开始前提醒；1:开启开始前提醒 |
| remindBeforeEnd | 否 | Integer | 0:不开启结束前提醒；1:开启结束前提醒 |
| remindHoursBeforeStart | 否 | Integer | 开始前提醒小时 |
| remindTimesBeforeStart | 否 | Integer | 开始前提醒分钟 |
| remindHoursBeforeEnd | 否 | Integer | 结束前提醒小时 |
| remindTimesBeforeEnd | 否 | Integer | 结束前提醒分钟 |
| customParams | 否 | Map<String,Object> | 自定义参数（key：表单字段管理中数据key；vlue：表单自定义字段的值） |
| 备注：customParams支持传递表单自定义参数（20250801基线开始支持）；表单主表自定义字段传参格式为：key-value（key：表单字段管理中数据key；vlue：表单自定义字段的值）；明细表自定义字段传参格式为：key(明细表名)、value（value为json数组）; |  |  |  |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| status | String | 执行状态 |
