# 智能推荐会议室

- **文档 ID**: `324293802497933312`
- **业务模块**: 会议管理
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/meeting/meetingOpenApi/getRecommendRoomEvents`
- **请求方式**: `POST`
- **Content-Type**: `application/json`

## 备注

- 备注:
- Body 参数格式(application/json)

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID |
| totalMember | 否 | int | 参会人数 |
| start | 否 | String | 开始时间，格式为（yy-MM-dd HH:mm:ss） |
| end | 否 | String | 结束时间，格式为（yy-MM-dd HH:mm:ss） |
| size | 是 | int | 推荐的数据个数（最多只能返回10个） |
| keyWords | 否 | List<String> | 模糊查询得关键词数组["泛微"，“的”，“茶室”] |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| status | String | 返回状态 |
| data | object | 返回数据 |
| start | String | 开始日期时间 |
| end | String | 结束日期时间 |
| permission | int | 权限级别（默认0） |
| room | object | 会议室信息 |
| id | String | 会议室id |
| name | String | 会议室名称 |
| roomDesc | String | 会议室备注 |
| status | int | 会议室状态（1为正常，2为封存） |
| equipments | String | 会议室设备 |
