# 查询会议列表

- **文档 ID**: `871464725802074112`
- **业务模块**: 会议管理
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/meeting/meetingOpenApi/getMeetingInfoList`
- **Content-Type**: `application/json`

## 备注

- POST（Content_Type: application/json）

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 当前人员ID 获取用户ID |
| name | 否 | String | 会议名称 |
| mtStatus | 否 | Integer | 0：草稿  1：待审批 2：未开始 3：退回 4：取消 7：锁定 8：结束（普通会议决议时更新）9：进行中 |
| beginDate | 否 | String | 会议开始日期（格式：yyyy-MM-dd） |
| endDate | 否 | String | 会议结束日期（格式：yyyy-MM-dd） |
| current | 否 | String | 当前页 |
| pageSize | 否 | String | 当前页展示数量 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| id | String | 会议id |
