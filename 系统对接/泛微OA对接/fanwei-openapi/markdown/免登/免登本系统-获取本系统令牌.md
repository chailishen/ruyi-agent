# 免登本系统-获取本系统令牌

- **文档 ID**: `840673469570752513`
- **业务模块**: 免登
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/oauth2/get_logintoken`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| app_key | 是 | string | 应用app_key |
| app_security | 是 | string | 应用app_secret |
| account | 是 | string | 登录账号 |
| authType | 否 | string | 认证类型（默认是登录账号account） |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| etLoginToken | String | 本系统令牌 |
| singleToken | string | 本系统令牌（etLoginToken） |
| redirect_uri | string | 免登本系统后的本系统重定向地址 |
| oauthType | string | 固定值（singlesign） |
| langType | string | 语言类型 |
