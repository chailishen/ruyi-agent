# 全文检索接口

- **文档 ID**: `367839216941400064`
- **业务模块**: 全文搜索
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/esearch/search/fullsearch/searchByModule`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| pageNo | 是 | Integer | 页码, 注意: 是从0开始的，0为第一页 |
| pageSize | 是 | Integer | 每页展示的数量，默认为20 |
| searchModule | 是 | String | 查询模块全部模块使用ALL |
| type | 是 | Integer | 搜索类型。0: 搜索内容（默认）；1：搜索标题；2：搜索图片 |
| keyword | 是 | String | 查询关键词 |
| searchTagId | 否 | String | 页面定制搜索标签ID |
| tenantKey | 是 | String | 租户key 开放平台接口使用 |
| employeeId | 是 | String | 人员id 开放平台接口使用 |
| orderByFileds | 否 | Map | 排序字段 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | http返回码 |
| msg | String | 返回信息 |
| pageNo | Integer | 当前页码 |
| pageSize | Integer | 每页数据量 |
| module | String | 查询模块 |
| keyword | String | 查询关键词 |
| took | Integer | es查询耗时 |
| totalTook | Integer | 查询总耗时 |
| hasNext | boolen | 是否有下一页 |
| total | Integer | 命中总数 |
| totalPage | Integer | 命中总页数 |
| result | Object | 查询结果 |
| id | String | 数据id |
| module | String | 数据所属的模块 |
| title | String | 数据标题 |
| titleLink | String | 数据标题跳转地址 |
| titleLinkOpenNewTab | boolen | 新标签页打开数据 |
| footInfo | Object | 数据角标信息 |
| highLightName | String | 标题命中高亮 |
| highLightContent | String | 内容命中高亮 |
