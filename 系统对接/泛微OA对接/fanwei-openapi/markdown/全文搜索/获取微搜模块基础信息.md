# 获取微搜模块基础信息

- **文档 ID**: `367839494658850816`
- **业务模块**: 全文搜索
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/esearch/search/xiaoe/getBaseInfoForXE`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| tenantKey | 是 | String | 租户编码 |
| employeeId | 是 | String | 人员ID |
| page_uuid | 是 | String | 页面编码 |
| fromApp | 是 | boolean | 是否是移动端 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| moduleInfo | Object | 模块信息 |
| moduleInfo.id | String | 模块编码 |
| moduleInfo.content | String | 模块名 |
| module.children | Object | 子模块 |
| page_uuid | String | 页面编码 |
| sortInfoList | Object | 结果排序信息 |
