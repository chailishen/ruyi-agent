# 获取微搜配置信息

- **文档 ID**: `367843401627860992`
- **业务模块**: 全文搜索
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/esearch/search/xiaoe/getSearchSetForXE`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| tenantKey | 是 | String | 租户编码 |
| employeeId | 是 | String | 人员ID |
| fromSystem | 否 | String | 是否来源于后台页面 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| groups | Object | 配置项分组信息 |
| groups.id | String | 分组id |
| groups.title | String | 分组标题 |
| groups.visible | boolen | 分组可见性 |
| groups.order | integer | 分组排序 |
| layout | Object | 分组下的配置的布局信息 |
| layout.label | String | 配置标题 |
| layout.groupId | String | 关联的分组ID |
| layout.items | List<String> | 关联的配置详细信息Key |
| items | Object | 配置的详细信息 |
| items.itemType | String | 配置类型如下拉框、选择框等等 |
| items.visible | boolen | 配置可见性 |
| items.disable | boolen | 配置是禁用 |
| items.required | boolen | 配置是否必填 |
| items.readOnly | boolen | 配置只读 |
