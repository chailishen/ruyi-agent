# 获取公文列表数据

- **文档 ID**: `874508788146118656`
- **业务模块**: 公文管理
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/odoc/list/getCustomlistData`
- **请求方式**: `POST`
- **Content-Type**: `application/json`

## 备注

- **备注：**Content-Type格式为application/json

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户id，对应系统内employeeid |
| listId | 否 | Long | 列表listId（系统内列表listId） |
| tabId | 是 | Long | 列表页签tabId（系统内列表页签tabId) |
| pageNum | 否 | Integer | 页码 |
| pageSize | 否 | Integer | 页数据量（建议不超过10） |
| searchParams | 否 | Map<String,Object> | 高级搜索条件参数，保持和内部列表getCustomPageList请求中searchParams参数一致即可。 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| status | String | 接口状态 |
| data | JSON | 数据结果集合(datas:数据结果，column：列信息，total：总数) |
