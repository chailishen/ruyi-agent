## datamap传值说明
- 单个控件传单个值{"控件id":"控件值"}
- 控件传多个值，用逗号分隔{"控件id":"控件值A,控件值B"}
- 明细表中的控件，不同行用 _*分隔 (一个下划线+星号){"控件A的id":"第一行控件值_*第二行控件值_*第N行控件值","控件B的id":"第一行控件值_*第二行控件值_*第N行控件值"}
- 选项用逗号分隔，明细表中不同行用_*分隔
##### 第一类：文本输入框（Text）、多行文本框(Textarea)、单选框(RadioBox)、下拉菜单(Select)、日期(DateComponent)、数字输入框(NumberComponent)、金额(Money)、邮箱(Email)、电话(Phone)、手机(Mobile)、运算控件(Monitor)、评分控件(Raty)、进度条(ProgressBar)、身份证(IDCard)、地理位置(PositionComponent)
- 例1：单选框# 普通布局的单选框
# {"控件id":"控件值"}
{"8745859598518169947":"选项1"}
# 明细表中的单选框 
# {"控件id":"第一行控件值_*第二行控件值"}
{"8745859598518169947":"选项1_*选项2"}
- 例2：日期控件# 普通布局中的日期控件
# {"控件id":"控件值"}
{"2175859602838099975":"2019-05-25"}
# 明细表中的日期控件
# {"控件id":"第一行控件值_*第二行控件值","控件id":"第一行控件值_*第二行控件值"}
{"2175859602838099974":"2019-05-23_*2019-05-24","2175859602838099975":"2019-05-25_*2019-05-26"}
- 例3：人员控件# 普通布局中的人员控件
# {"控件id":"姓名","控件ID":"##工号"}
{"2175859602838099975":"姓名A", "2175859602838099976":"##A3385",}
# 明细表中的人员控件
# {"控件id":"第一行控件值_*第二行控件值","控件id":"第一行控件值_*第二行控件值"}
{"2175859602838099974":"姓名A_*姓名B","2175859602838099975":"##A3385_*##A3386"}
##### 第二类：复选框(CheckBox)、日期区间(DateInterval)、多级下拉框(ComboSelect)、关联项目(Mainline)、关联任务(Task)、关联文档(Document)、关联审批(Workflow)、关联日程(AgendaComponent)、关联表单数据(FormComponent)、关联客户(CustomerComponent)、关联线索(ClueComponent)、关联订单(OrderComponent)、客户联系人(ContactComponent)、关联商机(ChanceComponent)、关联产品(ProductionComponent)、关联合同(ContractComponent)、人员(Employee)、部门(Department)
- 例1：复选框# 普通布局中的复选框
# {"控件id":"选项1,选项2"} 选项用逗号分隔
{"8745859625727369995":"选项1,选项2"}
# 明细表中的复选框
# {"控件id":"选项1,选项2_*选项1"} 选项用逗号分隔，不同行用_*分隔
{"8745859625727369995":"选项1,选项2_*选项1"}
- 例2：多级下拉框# 普通布局中的多级下拉框
# {"控件id":"一级选项,二级选项"}
{"8745859598518169950":"选项1,选项11"}
# 明细表中多级下拉框
# {"控件id":"一级选项,二级选项_*一级选项,二级选项"}
{"8745859598518169950":"选项1,选项11_*选项2,选项21"}
- 例3：关联任务# 普通布局中的关联任务,关联单个任务
# {"控件id":"任务名称"}
{"8745859625727369995":"任务A"}
# 普通布局中的关联任务,关联多个任务用逗号分隔
# {"控件id":"任务A,任务B"}
{"8745859625727369995":"任务1,任务2"}
# 明细表中的关联任务
# {"控件id":"任务A,任务B_*任务C,任务D"}
{"8745859625727369995":"任务A,任务B_*任务C,任务D"}
- 例4：日期区间# 普通布局中的日期区间
# {"日期区间控件id":"开始时间,结束时间"}
{"2175859602838099976":"2019-05-22,2019-05-26"}
- 例5：关联审批# 审批未开启流水号
# {"审批控件ID":"审批名称"}
{"2175859602838099979":"审批A"}
# 审批开启流水号，需要将审批名称和审批流水号拼接，str字符串拼接即可
# {"审批控件ID":"审批名称审批流水号"}
{"2175859602838099979":"审批A审批流水号"}
