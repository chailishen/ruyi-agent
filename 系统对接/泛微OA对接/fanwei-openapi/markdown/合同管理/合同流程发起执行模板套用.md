# 合同流程发起执行模板套用

- **文档 ID**: `404068526836416512`
- **业务模块**: 合同管理 / 模板管理
- **是否 API 接口**: 否（说明文档）

## 正文

如何实现合同流程发起执行模板套用
1. 通过新增流程接口，发起流程。
2. 给流程创建套用模板、合同模板执行生成模板套用接口。
3. 使用更新表单字段将套用后文件更新流程
示例：
第一步：发起流程。
调用流程新建接口，生成一条合同流程数据，得到流程数据的requestid。
第二步：模板创建
调用模板创建接口，生成指定模板，获取到模板id（data）。
第三步：模板套用
调用生成模板套用接口，根据书签名称更新文档中书签对应内容，生成所需合同文件数据
第四步：更新流程
调用更新流程接口，将二、三步骤中套用生成合同文件数据更新至第一步创建的流程数据内。
