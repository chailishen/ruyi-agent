# 商机新增评论

- **文档 ID**: `197073733465145344`
- **业务模块**: 商机
- **是否 API 接口**: 否（说明文档）
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 |
| attachments | 否 | String | 评论对应的附件信息 |
| comment.targetId | 是 | Long | 评论对应的事项ID |
| comment.disableMessage | 否 | Boolean | 是否禁用发送评论消息，默认为false |
| comment.relevanceList | 否 | Object | 评论的事项关联信息列表relevanceList：[ "targetId": "5118242497465889431" ,"targetModule": "task" "targetName": "1"]targetId 关联的事项的id，targetModule 关联的事项的module，targetName关联的事项的名 |
| comment.atLinkList | 否 | Object | 评论的艾特信息列表 |
| comment.content | 是 | String | 评论内容，富文本评论需要以_weaverMte_开头 |
| comment.module | 是 | String | 评论所属模块，例如商机模块为saleChance，客户模块为customer |
| currentUser.id | 是 | String | 评论人的人员id |
| currentUser.tenantKey | 是 | String | 评论人的租户key |
| currentUser.username | 是 | String | 评论人的名称 |
| client | 否 | String | 评论发送来源，默认pc，移动端mobile 区分大小写 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| data | String | 评论信息（JSON格式）内容说明和请求中的comment一致 |
