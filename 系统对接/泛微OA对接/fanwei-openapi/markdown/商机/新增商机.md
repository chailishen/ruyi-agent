# 新增商机

- **文档 ID**: `946536914417385472`
- **业务模块**: 商机
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/crm/v2/create`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| module | 是 | String | 模块固定为：saleChance |
| entity | 是 | Object | 商机信息 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| name | String | 名称 |
| manager | String | 负责人 |
| saleBelongCustomer | String | 客户 |
| saleStage | String | 阶段 |
| saleMoney | String | 销售金额 |
| saleWinRate | String | 赢率 |
| saleSource | String | 来源 |
| saleType | String | 类型 |
| saleOrderDate | String | 结单时间 |
| saleDescription | String | 备注 |
| dataMap | String | 自定义字段 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | Object | 商机信息（JSON格式） |
