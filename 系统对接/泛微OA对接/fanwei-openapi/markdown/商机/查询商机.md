# 查询商机

- **文档 ID**: `946544112848494592`
- **业务模块**: 商机
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/crm/v2/get`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| module | 是 | String | 模块固定为：saleChance |
| id | 是 | Long | 商机ID |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| name | String | 名称 |
| creator | Object | 创建人 |
| saleMoney | Double | 销售金额 |
| saleWinRate | Int | 赢率 |
| saleType | Object | 商机类型 |
| saleOrderDate | Object | 结单时间 |
| saleBelongCustomer | Object | 客户 |
| saleDescription | String | 备注 |
| saleProcess | Object | 销售过程 |
| saleStage | Object | 商机阶段 |
