# 获取实时汇率

- **文档 ID**: `249279927545757696`
- **业务模块**: 国际化 / 汇率
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/i18n/rate/v1/getCurrentFXRate`
- **请求方式**: `POST`

## 备注

- 备注：

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| sourceCurrency | 否 | long | 原币种ID |
| targetCurrency | 否 | long | 目标币种ID |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 状态码 200：成功 , 500：系统异常 |
| msg | String | 响应信息 |
| status | boolean | 状态 |
| data | Object | 汇率信息 |
| data.rate | String | 汇率 |
| code | String | 状态码 200：成功 , 500：系统异常 |
| msg | String | 响应信息 |
| status | boolean | 状态 |
| data.enableRates | String | 已启用币种汇率信息 |
| data.enableRates.unit | long | 币种ID |
| data.enableRates.isEnable | int | 是否启用 |
| data.enableRates.rate | String | 汇率 |
