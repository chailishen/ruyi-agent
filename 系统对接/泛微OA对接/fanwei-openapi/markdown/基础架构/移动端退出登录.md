# 移动端退出登录

- **文档 ID**: `249253161456369664`
- **业务模块**: 基础架构
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/basicserver/open/mobileOffline`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| type | 是 | String | userId人员id,loginName登录名,jobNum工号,account账号,mobile电话,email邮箱 |
| account | 是 | String | 账号 当type为非userId时必填 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
