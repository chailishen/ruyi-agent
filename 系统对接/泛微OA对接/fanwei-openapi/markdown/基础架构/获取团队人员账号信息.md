# 获取团队人员账号信息

- **文档 ID**: `926018837817098241`
- **业务模块**: 基础架构
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/basicserver/v1/login/findAccount`
- **Content-Type**: `application/json`

## 备注

- POST application/json

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | long | 用户ID 获取用户ID |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| loginName | String | 登录名 |
| jobNum | String | 工号 |
| account | String | 绑定的账号 |
| mobile | String | 绑定的手机号账号 |
| email | String | 绑定的邮箱账号 |
