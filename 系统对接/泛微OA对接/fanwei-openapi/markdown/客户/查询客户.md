# 查询客户

- **文档 ID**: `840675488172703745`
- **业务模块**: 客户
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/crm/v2/get`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| module | 是 | String | 模块固定取值：customer |
| id | 是 | Long | 客户ID 获取客户ID |
