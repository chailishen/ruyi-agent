## 开发者认证
- 开放平台地址：{origin}/info/custom_openapi/openapi/backend/home	注：如提示登录就去登录，需要后台管理员账号，地址为：e10系统 -> 后台管理中心 -> 开放平台 -> 开发者认证栏目
- 使用本系统的系统管理员账号登录开放平台。
- 登录开放平台之后
1. 确认登录的团队是否是需要对接的团队。若发现不是需要对接的团队，可点击【切换】切换团队。
2. 可以看到登录之后是未认证的状态，只有通过认证之后，才能对接。
3. 点【编辑】进行开发者认证。完善信息之后点击保存信息即可完成认证。认证信息可要求确保真实有效，也可无需那么精确，看项目要求。
4. 认证之后，开发者资料后的状态会变为已认证。认证之后会显示Corpid，后续调用接口会用到。
