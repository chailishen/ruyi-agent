# 开放平台几种认证方式使用说明

- **文档 ID**: `907515938228486144`
- **业务模块**: 对接说明
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/user/v3/findAllUsers`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_name | 是 | String | 用户名 |
| access_pwd | 是 | String | 密码 |
| corpid | 是 | String | 开放平台开发者资料中获取 |
| secret_key | 否 | String | 签名校验 |
| page | 否 | Int | 分页页码，从1开始（不传值则默认为1，每页1000条数据） |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| access_name | String | 用户名 |
| access_pwd | String | 按照指定加密方式进行加密后的密码 |
| corpid | String | 开放平台开发者资料中获取 |
| secret_key | String | 签名校验 |
| page | Int | 分页页码，从1开始（不传值则默认为1，每页1000条数据） |
