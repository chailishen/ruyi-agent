# 查询岗位列表（V2）

- **文档 ID**: `840674418775302144`
- **业务模块**: 岗位
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/position/v2/list`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| posnid | 否 | Long | 岗位ID（不传时，获取企业整个岗位列表） |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| position | List | 岗位信息 |
| name | String | 岗位名称 |
| rank | Int | 层级 |
| parent | Object | 父岗位信息 |
| id | String | 岗位ID |
