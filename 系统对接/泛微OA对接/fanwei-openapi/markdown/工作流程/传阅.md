# 传阅

- **文档 ID**: `874489190302621697`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/circulate`
- **Content-Type**: `application/json`

## 备注

- POST （Content_Type: application/json），备注：access_token放在params中

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userId | 是 | Long | 用户ID 获取用户ID |
| requestId | 是 | long | 流程ID 获取审批数据ID |
| receiveOperators | 是 | list | 接收人是个数组，数组内的元素有id和entityType. |
| receiveOperators[0].id | 是 | long | 用户ID、群组ID、部门ID |
| receiveOperators[0].entityType | 是 | String | user:id代表人员ID；dept：id代表部门ID；group：id代表群组ID。 |
| remark | 否 | String | 意见 |
| otherParam | 否 | obj | 额外参数：包含下面几个参数。 |
| otherParam.allowAnnotation | 否 | int | 接收人是否可提交意见：0不可提交，1可提交。 |
| otherParam.allowCirculate | 否 | int | 接收人是否可发起传阅：0不可发起，1可发起。 |
| otherParam.circulateNeedBack | 否 | int | 接收人阅读后是否反馈我：0不反馈，1反馈。 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
