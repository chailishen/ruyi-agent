# 传阅收回

- **文档 ID**: `874489928886001665`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/doCirculateBack`
- **Content-Type**: `application/json`

## 备注

- POST （Content_Type: application/json），备注：access_token放在params中

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userId | 是 | Long | 用户ID 获取用户ID |
| requestId | 是 | long | 流程ID |
| backParam | 是 | list | 需要收回的转发操作集合 |
| batch | 否 | boolean | 是否收回同批次所有传阅操作 |
| requestLogId | 是 | long | 传阅日志ID |
| targetCId | 否 | long | （batch=false或batch不传时必填） |
| targetUserId | 否 | long | 传阅目标用户ID（batch=false或batch不传时必填） |
| isMonitor | 否 | int | 是否监控权限 0：否 1：是 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
