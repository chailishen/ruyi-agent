# 保存流程

- **文档 ID**: `408004180041531392`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/saveRequest`
- **Content-Type**: `application/json`

## 备注

- POST （Content_Type: application/json），备注：access_token放在params中

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token |  | String |  |
| userid |  | long | 用户ID |
| requestId |  | long | 流程请求ID |
| formData |  | json | 表单数据，表单数据传递可以参考【新增流程】接口； |
| requestName |  | String | 流程名称 |
| userCurrentNodeId |  | long | 当前节点ID |
| requestSecLevel |  | int | 密级（系统开启密级才使用这个参数），值大于0 才生效。且开启了密级，则获取创建人能获取的最大密级。 |
| requestSecValidity |  | String | 保密期限（传递密级时才传递该参数） |
| requestName |  | String | 流程标题 |
| requestLevel |  | int | 紧急程度 0：正常； 1：重要； 2：紧急。默认值：0 |
| isNewFormData |  | boolean | true：可以传递表单高级参数（seniorFormParam生效）。false：仅仅传递表达数据（默认值）。 |
| seniorFormParam |  | json | 表单高级参数，isNewFormData=true时才生效 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| dataId | long | 业务数据Id，外部表单需要传dataId |
| dataDetails | list | 表单数据（传递了dataId就不用传递表单数据了） |
| formId | long | 表单ID |
| module | String | 模块标识，默认workflow |
| dataKeyNoFindIgnore | boolean | true：忽略dataKey传错的情况。false：若是dataKey传错会提示错误的dataKey。 |
| fieldId | long | 字段ID |
| dataKey | String | 字段数据key(与fieldId二选一传递即可) |
| content | String | 字段内容（单行文本、多行文本等） |
| dataOptions | list | 浏览按钮数据，默认为null，有值的时候，以这个值为准，忽略content的内容。 |
| subFormId | long | 明细表ID，当传递明细数据且字段传递的dataKey则该值必填。 |
| subFormDataKey | String | 明细表dataKey，与subFormId二选一传递。 |
| dataIndex | long | 明细行序号(主表字段该值不用传递)。1：就代表是明细行第一行。 |
| optionId | long | 选项ID |
| targetId | long | 图片单选多选的选项的图片ID。 |
| content | long | 选项名称 |
| type | String | 选项类型 |
| needDefaultValue | boolean | true：给表单赋值默认值，false：默认值 |
| execRelate | boolean | 是否执行数据砖取；true：执行。false：默认值。 |
| execMonitor | boolean | 是否执行运算：true：执行；false：默认值。 |
| validate | boolean | 是否开启数据查重校验；true：开启。false：默认值。 |
| needValidateInfo | boolean | validate=true时生效，查重结果是否返回具体信息；true：返回；false：不返回。 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
