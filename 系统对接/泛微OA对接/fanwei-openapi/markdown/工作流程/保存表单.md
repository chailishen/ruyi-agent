# 保存表单

- **文档 ID**: `908574153818660864`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/saveFormData`
- **Content-Type**: `application/json`

## 备注

- POST （Content_Type: application/json），备注：access_token放在params中

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | long | 用户ID 获取用户ID |
| requestId | 是 | long | 流程ID |
| workflowId | 否 | long | 工作流ID |
| userCurrentNodeId | 否 | long | 当前节点 |
| formData | 是 | json | 表单数据 |
| isNewFormData | 否 | boolean | true：可以传递表单高级参数（seniorFormParam生效）。false：仅仅传递表达数据（默认值）。 |
| seniorFormParam | 否 | json | 表单高级参数，isNewFormData=true时才生效 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| formId | long | 表单ID |
| dataDetails | list | 表单字段数据 |
| module | String | 模块标识workflow |
| content | String | 文本内容 |
| dataKey | String | 字段数据库名，与fieldId二选一必填。 |
| fieldId | long | 字段ID，与dataKey二选一必填。 |
| dataIndex | long | 明细数据时，填写行数。 |
| matchByName | boolean | 选项控件根据名称匹配，目前只支持以下字段（非数据源模版的时候）Select，CheckBox，RadioBox，ImageCheckBox，ImageRadioBox，ComboSelect,MatrixComponent。注：仅针对私有化环境 |
| dataOptions | list | 浏览按钮数据，默认为null，有值的时候，以这个值为准，忽略content的内容。 |
| subFormId | long | 明细表ID，当传递明细数据且字段传递的dataKey则该值必填。 |
| subFormDataKey | String | 明细表dataKey，与subFormId二选一传递。 |
| needDefaultValue | boolean | true：给表单赋值默认值，false：默认值 |
| execRelate | boolean | 是否执行数据砖取；true：执行。false：默认值。 |
| execMonitor | boolean | 是否执行运算：true：执行；false：默认值。 |
| validate | boolean | 是否开启数据查重校验；true：开启。false：默认值。 |
| needValidateInfo | boolean | validate=true时生效，查重结果是否返回具体信息；true：返回；false：不返回。 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
