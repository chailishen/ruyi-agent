# 催办

- **文档 ID**: `874488966922379265`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/requestSupervise`
- **Content-Type**: `application/json`

## 备注

- POST （Content_Type: application/json），备注：access_token放在params中

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userId | 是 | Long | 用户ID 获取用户ID |
| requestId | 是 | long | 流程ID 获取审批数据ID |
| remark | 否 | String | 意见 |
| otherParam | 是 | obj | 额外参数,是个对象，下级属性看示例（下级属性非提醒方式的5个属性必须填1个）。 |
| otherParam.otherReminder | 否 | String | 其他提醒人（userId），多个ID用逗号隔开。 |
| otherParam.currentOperator | 否 | int | 当前审批人是否需要提醒，0不提醒；1提醒。 |
| otherParam.messageRemind | 否 | int | 是否短信提醒：0不提醒；1提醒。（提醒方式） |
| otherParam.doneOperator | 否 | int | 已办审批人是否需要提醒，0不提醒；1提醒。 |
| otherParam.submitOperator | 否 | int | 流程提交人是否需要提醒，0不提醒；1提醒。 |
| otherParam.ccOperator | 否 | int | 流程抄送人是否需要提醒，0不提醒；1提醒。 |
| otherParam.emailRemind | 否 | int | 是否邮件提醒：0不提醒；1提醒。（提醒方式） |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | Map | 流程数据 |
