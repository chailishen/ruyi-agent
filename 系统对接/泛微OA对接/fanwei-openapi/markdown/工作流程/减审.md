# 减审

- **文档 ID**: `279100563348520960`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/minusOperator`
- **请求方式**: `POST`
- **Content-Type**: `application/json`

## 备注

- package com.weaver.core.demo;

import cn.hutool.http.HttpRequest;
import cn.hutool.json.JSONUtil;
import com.alibaba.fastjson.JSONArray;
import com.alibaba.fastjson.JSONObject;
import com.weaver.core.constant.TestConstant;

/**
 * 减审
 *
 * @author:chenwh
 */
public class MinusOperatorDemo extends DemoBase {
    public static void main(String[] args) {
        String response = new MinusOperatorDemo().minusOperator(959492872273477633L);
        System.out.println(response);
    }

    /**
     *
     * @param requestId
     * @return
     */
    public String minusOperator(long requestId) {
        String url = HOST + "/api/workflow/core/paService/v1/addSignOperator?access_token=" + TOKEN;
        JSONObject param = new JSONObject();
        param.put("userid", TestConstant.USER_CHENWH);
        param.put("requestId", requestId);
        param.put("remark", "减审");
        // 减审接收人
        JSONArray receiveOperators = new JSONArray();
        param.put("minusOperators", receiveOperators);
        JSONObject receive1 = new JSONObject();
        receive1.put("id", TestConstant.USER_YDY_B);
        receiveOperators.add(receive1);

        // 发送请求
        return HttpRequest.post(url)
                .header("Content-Type", "application/json")
                .body(JSONUtil.toJsonStr(param))
                .execute()
                .body();
    }
}

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| requestId | 是 | long | 流程ID |
| userCurrentNodeId | 否 | long | 减审操作者人操作所在节点，不传的话默认计算一个操作节点 |
| remark | 否 | String | 签字意见 |
| src | 否 | String | 操作类型；minus：减审（默认）、minusAndSubmit：减审并批准 |
| minusOperators | 是 | list | 需要减审的人员 |
| addMinusNodeId | 否 | long | 指定减审哪个节点的操作人 |
| addMinusOperateRound | 否 | int | 减审节点哪个轮次的数据，配合addMinusNodeId使用 |
| canMinusDoneOperate | 否 | int | 是否能减审已操作的数据：默认是不能；传1代表可以减审已办的数据（仅只删除操作者数据，签字意见等数据不做删除） |
| isMonitor | 否 | int | 是否是监控操作，默认是否，传1的话取监控权限（会校验是否有监控的减审权限） |
| mailAndSmsMsgParam | 否 | json | 节点允许修改提醒方式时，减审并批准时，可以选择是否发送短信邮件提醒 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| userChooseMailRemind | boolean | false(默认值)：不发邮件；true：发邮件 |
| userChooseSmsRemind | boolean | false(默认值)：不发邮件；true：发邮件 |
| userChooseReceiver | list | 提醒人人员ID，设置要允许修改操作者才生效 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
