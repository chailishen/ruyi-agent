# 删除流程

- **文档 ID**: `840714465000914945`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/deleteRequest`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| requestId | 是 | Int | 审批数据ID 获取审批数据ID |
| otherParams | 否 | Object | 如果以监控权限删除流程则需要传该参数在body中传入，否则以流程权限判断{“ismonitor”:”1”} |
| deleteType | 否 | int | 1：当流程在回收站时，将流程彻底删除，若流程不在回收站，也只能删除到回收站；0（默认值）：将流程删除到回收站； |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
