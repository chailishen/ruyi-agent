# 判断子流程是否全部归档

- **文档 ID**: `236694426301235200`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/judgeSubRequestAllEnd`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userIdStr | 是 | Long | 用户ID 获取用户ID |
| mainRequestId | 是 | Long | 主流程的唯一标识 |
| subRequestIds | 否 | List | 子流程的唯一标识，如果不传该参数则校验当前主流程下的所有子流程 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 状态码 0：成功 , 500：系统异常 100001：参数异常 |
| errmsg | String | 错误信息 |
| isAllArrived | Boolean | true:代表所有子流程全部到达该节点。false:代表还有子流程未归档 |
| requestIdList | List | 如果有未到达该节点的子流程，则返回未到达该节点的子流程requestid。如果全部都到达该节点了，该参数为空 |
