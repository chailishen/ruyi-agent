# 判断流程能否流转下去

- **文档 ID**: `408012847977594880`
- **业务模块**: 工作流程 / 校验流程信息
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/canFlowNextNode?access_token=`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token |  | String |  |
| userid |  | long | 用户ID |
| requestId |  | long | 流程请求ID |
| userCurrentNodeId |  | long | 用户当前节点id，没传的话会根据权重自动算一个用户所在节点id |
| needVerifySelectFlow |  | int | 是否需要校验能否弹出指定流转窗口  1：需要；0:不需要 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | int | 200 代表成功 |
| msg | String | 执行结果信息描述 |
| data | JSONArray | 响应数据 |
