# 前台可发起工作流列表

- **文档 ID**: `840714112855539713`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/list/paService/v1/getCreateWorkflowList`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| wfpCode | 是 | Int | 0：个人审批 1：团队审批 |
| filterHide | 否 | String | 是否过滤“新建流程默认隐藏”设置，为1时过滤 |
| mergeShow | 否 | Int | 主次账号是否统一显示"mergeShow":1/0（参数传递为1，才会读取用户个人设置-偏好设置-其他设置：多身份数据显示 设置，否则默认不包含次账号数据 ） |
| inCludePTJob | 否 | Int | 是否包含兼职岗位数据，0：否 1：是 |
| loadOfsFlow | 否 | Int | 是否加载异构流程数据，0：否 1：是 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| id | string | 审批ID |
| workflowName | string | 审批名称 |
| workflowDesc | string | 审批流描述 |
| creatorName | string | 审批流创建人名称 |
| workflowType | string | 审批流类型ID |
| belongType | string | 团队：company 个人：personal |
| orderId | float | 显示顺序 |
| versionId | string | 版本（V1 V2 V3） |
| curAccountCreateAble | boolean | 当前账号是否可创建（当传入参数mergeShow=1或inCludePTJob=1才会有此属性） |
| identityList | list | 可创建流程的身份列表（当传入参数mergeShow=1或inCludePTJob=1才会有此属性） |
| datasrc | string | 数据来源,异构系统数据为3 |
| pcUrl | string | 自定义pc打开链接 |
| mUrl | string | 自定义mobile打开链接 |
| sysCode | string | 统一待办数据系统标识 |
