# 前台可发起工作流类型列表

- **文档 ID**: `921617900761571328`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/list/paService/v1/getCreateWorkflowTypeList`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| wfpCode | 是 | Int | 0：个人审批 1：团队审批 2：云商店 传入其他数字返回data数据为空 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| workflowTypeId | string | 审批ID |
| workflowTypeName | string | 审批流类型名称 |
