# 动态加签

- **文档 ID**: `874488747728052224`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/dynamicCreateFreeNode`
- **Content-Type**: `application/json`

## 备注

- POST （Content_Type: application/json），备注：access_token放在params中

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userId | 是 | Long | 用户ID 获取用户ID |
| requestId | 是 | Int | 流程ID 获取审批数据ID |
| currentNodeId | 否 | Long | 加签节点ID（只能是当前节点，仅支持一个节点） |
| workflowId | 否 | Long | 工作流ID |
| addSignAndSubmit | 否 | boolean | true：加签并批准。默认值：false。 |
| defFlowType | 否 | int | 加签节点流转后流转方式  0：流转到下一节点（默认值）；1：回到本节点； |
| remark | 否 | String | 批准意见（当addSignAndSubmit=true时该参数才生效） |
| attachments | 否 | long | 附件ID |
| signatureData | 否 | json | 手写签批 |
| signatureData.signatureImgId | 否 | long | 手写签批 |
| locationData | 否 | json | 定位 |
| locationData.address | 否 | String | 位置 |
| locationData.value | 否 | String | 经纬度 |
| userSignatureData | 否 | json | 电子签章 |
| userSignatureData.signatureImgId | 否 | long | 电子签章对应图片 |
| useMaxWeightUser | 否 | boolean | 当userid 为主身份时，是否获取主次账号所有待办数据，选取权重最大的进行操作； |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| nextNodeEditPurview | int | 下一节点编辑权限；0 不可调整 ，1 仅允许添加新节点，2 允许添加新节点且允许修改后续节点。默认值0； |
| isModifiable | int | 是否可修改流程表内容；0 不可修改，1可修改。nodeType!=9时才传递。默认值0 |
| nodeType | int | 节点类型； 9 查阅，1 批准， 2 确认。默认值：1 |
| mergeType | int | 分支合并方式；1：按比例通过合并，2：按分支数通过。并行情况必填。默认值为1； |
| mergeValue | int | 合并参数；mergeType=1时，传递的是0-100的整数；mergeType=2时，传递的是需要通过的分支数。 |
| isParallel | int | 是否并行；0 串行，1并行。addFreeNodeData为空的情况必填。默认值为0 |
| operatorIds | String | 操作者ID，多个ID用逗号隔开。一个操作人就是一个节点。addFreeNodeData为空的情况必填。 |
| signType | int | 会签方式；0 非会签，1会签，2依次逐个处理。默认值为0； |
| ccOperators | String | 抄送人ID，多个ID用逗号隔开，每个节点都会有这些抄送人。 |
| ccSignType | int | 抄送人会签关系；3 抄送不需提交，4 抄送需提交。默认值：3 |
| nextNodeEditPurview | int | 下一节点编辑权限；0 不可调整 ，1 仅允许添加新节点，2 允许添加新节点且允许修改后续节点。默认值0； |
| mergeType | int | 分支合并方式；1：按比例通过合并，2：按分支数通过。并行情况必填。默认值为1； |
| mergeValue | int | 合并参数；mergeType=1时，传递的是0-100的整数；mergeType=2时，传递的是需要通过的分支数。 |
| addFreeNodeData | list<list> | 节点对象的二维数组，一维数组就是一串节点，多个一维数组是并行。operatorIds为空的情况必填。 |
| nodeName | String | 节点名称 |
| operatorIds | String | 节点操作者ID，多个ID用英文逗号隔开。 |
| signType | int | 会签方式；0 非会签，1会签，2依次逐个处理。默认值为0. |
| nodeType | int | 节点类型； 9 查阅，1 流程， 2 确认。默认值：1 |
| isModifiable | int | 是否可修改流程表内容；0 不可修改，1可修改。nodeType!=9时才传递。默认值：0 |
| ccOperators | String | 抄送人ID，多个ID用逗号隔开 |
| ccSignType | int | 抄送人会签关系；3 抄送不需提交，4 抄送需提交。默认值：3。 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
