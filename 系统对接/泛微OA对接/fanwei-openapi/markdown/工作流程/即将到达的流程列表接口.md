# 即将到达的流程列表接口

- **文档 ID**: `973597897005481984`
- **业务模块**: 工作流程
- **是否 API 接口**: 否（说明文档）
- **Content-Type**: `application/json`

## 备注

- POST （Content_Type: application/json）

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| pageSize | 是 | StringString | 每页数据量 |
| current | 是 | int | 页码 |
| params | 是 |  |  |
| dimension | 是 | String | 维度标识，直接给'coming'即可 |
| tabid | 是 | String | 直接给1100，固定写法 |
| countKey | 是 | String | 预计今日到达传1，预计明日到达传2，预计近期总共到达传3 |
| userId | 是 | Long | 需要查询目标用户的用户ID |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| requestname | string | 流程名称 |
| currentnode | string | 当前节点 |
| arriveTime | String(yyyy-MM-dd HH:mm:ss) | 预计到达时间 |
| remainingNodeShow | string | 剩余节点数 |
| createdatetime | String(yyyy-MM-dd HH:mm:ss) | 发起时间 |
