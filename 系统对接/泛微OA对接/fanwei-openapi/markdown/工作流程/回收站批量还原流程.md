# 回收站批量还原流程

- **文档 ID**: `408047921972379648`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/recover?access_token=`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token |  | String |  |
| userid |  | long | 用户ID |
| requestIds |  | String | 流程请求id，多个请求ID用英文逗号隔开； |
| resendMsg |  | boolean | true：对未操作者发送新到达消息（草稿数据不推送新到达流程提醒）；默认值：false； |
| isViewDelRequest |  | int | 是否可获取回收站数据  0：否（默认） 1：是 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | int | 200 代表成功 |
| msg | String | 执行结果信息描述 |
| data | JSONArray | 响应数据 |
| successRequest | list | 还原成功的流程ID集合 |
| failRequest | Map | 还原失败的流程ID以及还原失败的原因； |
