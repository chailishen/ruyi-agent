# 委托收回

- **文档 ID**: `278277587518619648`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/recoverAgent`
- **请求方式**: `POST`
- **Content-Type**: `application/json`

## 备注

- 备注：限制条件之间是and关系，所以workflowTypes、workflowIds、nodeIds只传一个即可，否则会查不出需要收回的委托数据
- package com.weaver.core.demo;

import cn.hutool.http.HttpRequest;
import cn.hutool.json.JSONUtil;
import com.alibaba.fastjson.JSONObject;
import com.weaver.core.constant.TestConstant;

/**
 * 委托收回
 *
 * @author:chenwh
 */
public class RecoverAgentDemo extends DemoBase {
    public static void main(String[] args) {
        String response = new RecoverAgentDemo().recoverAgent();
        System.out.println(response);
    }

    /**
     * 委托收回
     * {"message":{"errcode":"200","errmsg":"接口返回成功","otherData":{}},"data":{"access_token":"ef282f98fb0cec759c88cde8dca0032f","beAgentUserId":5116374622026176523,"userid":5116374622026176523,"agentUserId":763199432279900161,"agentIds":"959476254980808713"}}
     *
     * @return
     */
    public String recoverAgent() {
        String url = HOST + "/api/workflow/core/paService/v1/recoverAgent?access_token=" + TOKEN;

        JSONObject param = new JSONObject();
        param.put("userid", TestConstant.USER_CHENWH);
        param.put("agentUserId", TestConstant.USER_ZMM);
        param.put("beAgentUserId", TestConstant.USER_CHENWH);

        return HttpRequest.post(url)
                .header("Content-Type", "application/json")
                // 参数放入body
                .body(JSONUtil.toJsonStr(param))
                .execute()
                .body();
    }
}

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| beAgentUserId | 是 | long | 委托人用户id |
| agentUserId | 否 | long | 被委托人用户id |
| recoverPendingWf | 否 | int | 是否收回流转中的委托；默认不收回，1:收回 |
| workflowTypes | 否 | list[Long] | 路径类型id限制条件 |
| workflowIds | 否 | list[Long] | 路径id限制条件 |
| nodeIds | 否 | list[Long] | 节点id限制条件 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | json | 数据 |
| userid | long | 用户ID |
| beAgentUserId | long | 被代理人ID |
| agentUserId | long | 代理人ID |
| agentIds | string | 根据条件收回的代理设置ids |
