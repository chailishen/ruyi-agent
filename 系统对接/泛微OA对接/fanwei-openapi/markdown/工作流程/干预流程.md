# 干预流程

- **文档 ID**: `840714679900274689`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/doIntervenor`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| requestId | 是 | Int | 审批数据ID 获取审批数据ID |
| Intervenorid | 是 | Int | 干预节点接收人，多个人以”,”号隔开 |
| submitNodeId | 是 | Int | 目标节点ID |
| remark | 否 | String | 签字意见 |
| SignType | 否 | Int | 会签类型 0 ：非会签 1：会签 2：依次逐个处理，不传代表会签 |
| enableIntervenor | 否 | String | 干预是否执行节点前附加操作 true：执行 false：不执行，默认执行 |
| interveneFinishBranch | 否 | int | 干预结束分支 0：否(默认)、1：是该参数只对分叉中间点有效该参数传入1时，干预接受人Intervenorid和会签关系SignType都不需要传递 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| requestId | String | 审批ID |
