# 强制结束流程

- **文档 ID**: `840714615333158912`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/doForceOver`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| requestId | 是 | Int | 审批数据ID 获取审批数据ID |
| otherParams | 否 | Object | 如果以监控权限删除流程则需要传该参数在body中传入，否则以流程权限判断{“ismonitor”:”1”} |
| remark | 否 | String | 签字意见 |
| useMaxWeightUser | 否 | boolean | 当userid 为主身份时，是否获取主次账号所有待办数据，选取权重最大的身份进行强制结束流程；true：是；false：否（默认值）。举例：节点操作者是次账号，userid传递主账号ID，useMaxWeightUser=true，此时也能强制结束流程。 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
