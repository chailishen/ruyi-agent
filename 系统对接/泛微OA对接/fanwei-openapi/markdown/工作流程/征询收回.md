# 征询收回

- **文档 ID**: `874490319933874177`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/consulBack`
- **Content-Type**: `application/json`

## 备注

- POST （Content_Type: application/json），备注：access_token放在params中

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userId | 是 | Long | 用户ID 获取用户ID |
| requestId | 是 | long | 流程ID |
| backConsulType | 是 | int | 收回类型 1 收回传递的这一行数据，2收回batchId对应的所有行数据。 |
| backConsulParam | 是 | list | 需要收回的征询记录 |
| batchId | 是 | long | 征询的批次号 |
| userId | 否 | long | 发起意见征询的用户ID（backConsulType=1时必填） |
| targetUserIds | 否 | list | 征询接收人ID集合（backConsulType=1时必填） |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
