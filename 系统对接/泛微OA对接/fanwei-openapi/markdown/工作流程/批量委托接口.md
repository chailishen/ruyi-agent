# 批量委托接口

- **文档 ID**: `944343423028191232`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/batchManualAgent`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token |  | String | 接口调用凭证 获取accessToken |
| userid |  | long | 用户ID 获取用户ID |
| agentUserId |  | long | 委托接收人ID |
| requestIds |  | array | 委托流程requestId数组 |
| remark |  | String | 签字意见 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| total | int | 本次委托总流程数 |
| batchResult | String | 批量委托结果，每条结果见单条委托接口 |
