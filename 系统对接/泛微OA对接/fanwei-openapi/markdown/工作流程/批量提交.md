# 批量提交

- **文档 ID**: `278276247069392896`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/batchSubmit`
- **请求方式**: `POST`
- **Content-Type**: `application/json`

## 备注

- package com.weaver.core.demo;

import cn.hutool.http.HttpRequest;
import cn.hutool.json.JSONUtil;
import com.alibaba.fastjson.JSONObject;
import com.weaver.core.constant.TestConstant;
import com.weaver.core.utils.RequestUtil;

/**
 * 批量提交
 */
public class BatchSubmitDemo extends DemoBase {

    public static void main(String[] args) {
        String response = new BatchSubmitDemo().batchSubmit();
        System.out.println(response);
    }

    /**
     * 批量提交
     * {"message":{"errcode":"0","errmsg":"success","otherData":{}},"data":{"successRequest":[],"isAsync":true,"failRequest":{}}}
     * {"message":{"errcode":"0","errmsg":"success","otherData":{}},"data":{"successRequest":["959474781853327360","959474876288966657"],"isAsync":false,"failRequest":{}}}
     *
     * @return
     */
    public String batchSubmit() {
        String url = HOST + "/api/workflow/core/paService/v1/batchSubmit?access_token=" + TOKEN;

        JSONObject param = new JSONObject();
        param.put("userid", TestConstant.USER_CHENWH);
        param.put("remark", "批量提交");
        param.put("isAsync", false);
        param.put("requestIds", "959474781853327360,959474876288966657");

        return HttpRequest.post(url)
                .header("Content-Type", "application/json")
                // 参数放入body
                .body(JSONUtil.toJsonStr(param))
                .execute()
                .body();
    }
}

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access _token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | long | 用户ID 获取用户id |
| requestIds | 是 | String | 需要提交的流程ID；多个流程ID用英文逗号隔开；若传递有重复的requestId，程序中会过滤掉； |
| isAsync | 否 | boolean | 是否异步：true；异步执行；false：同步；默认值：读取后台配置； |
| remark | 否 | String | 签字意见 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | json | 返回数据 |
| isAsync | boolean | true：流程异步提交中；false：同步提交； |
| successRequest | list | 提交成功流程Id集合； |
| failRequest | map | 提交失败的流程以及失败原因；KEY：流程ID；VALUE：提交失败原因； |
