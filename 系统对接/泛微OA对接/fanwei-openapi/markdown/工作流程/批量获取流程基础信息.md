# 批量获取流程基础信息

- **文档 ID**: `279102228558512128`
- **业务模块**: 工作流程 / 获取流程信息
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/batchGetRequestInfo`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | long | 用户ID 获取用户ID |
| requestIds | 是 | String | 流程ID，多个ID用英文逗号隔开；最多传递100个，多余100的流程ID将被忽略； |
| isGetOperator | 否 | boolean | true：额外获取当前节点操作者，默认值：false； |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| data | JSON | 响应数据 |
| failRequest | json | 查询失败的流程信息以及提示信息 |
| requestBaseInfo | json | 查询成功的流程信息 |
