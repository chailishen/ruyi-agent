# 批量获取流程未操作者

- **文档 ID**: `280947303118798848`
- **业务模块**: 工作流程 / 获取流程信息
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/batchGetRequestUnOperator`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| requestIds | 是 | String | 流程ID，多个ID用英文逗号隔开；最多传递100个，多余100的流程ID将被忽略； |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | int | 200 代表成功 |
| msg | String | 执行结果信息描述 |
| data | JSON | 响应数据 |
| failRequest | json | 查询失败的流程信息以及提示信息 |
| requestBaseInfo | json | 查询成功的流程信息 |
