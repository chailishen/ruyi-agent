# 抄送收回

- **文档 ID**: `408049776752328704`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/doCcBack?access_token=`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token |  | String |  |
| userid |  | long | 用户ID |
| requestId |  | long | 流程请求ID |
| backParam |  | json | 要收回的数据 |
| afterAllowBack |  | int | 0 能收回所有数据；2：只能收回未批注；默认值：0 |
| viewBack |  | int | 0：不允许收回；1：只能收回未查看数据；2：查看前，查看后的都可以收回。默认值：2 |
| backParam[n].batch |  | boolean | 是否收回同批次所有抄送数据（默认值：false） |
| backParam[n].requestLogId |  | long | 抄送意见ID |
| backParam[n].targetCId |  | long |  |
| backParam[n].targetUserId |  | long | 转发目标用户ID（batch=false或batch不传时必填） |
| isMonitor |  | int | 是否监控权限 0：否 1：是 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | int | 200 代表成功 |
| msg | String | 执行结果信息描述 |
| data | JSONArray | 响应数据 |
