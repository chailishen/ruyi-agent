# 提交/同意流程

- **文档 ID**: `840714396263784448`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/submitRequest`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| requestId | 是 | Long | 审批数据ID 获取审批数据ID |
| remark | 否 | String | 签字意见，默认值流程默认意见若未设置则为空 |
| userCurrentNodeId | 否 | Long | 当前节点 |
| requestName | 否 | String | 流程标题 |
| selectFlowParam | 否 | JSON | 指定流转相关参数：若节点未开启指定流转，则会提示无流程权限； |
| exceptionHandleInfo | 否 | map | 异常处理由用户选择操作者参数；若节点异常处理未设置由用户选择操作者，传递了也不会生效；KEY：节点ID；VALUE：异常处理操作者数据； |
| formdata | 否 | Object | 表单数据 |
| otherParams | 否 | String | 其他参数在body中传入，比如src （动作类型 save表示只保存 ，submit 为提交 ，默认为提交）{“src”:”save”} |
| isFlowToFreePath | 否 | int | 0：流转到下一节点；1：流转到加签节点（默认值）；当前节点后有加签节点时才生效。 |
| useMaxWeightUser | 否 | boolean | 当userid 为主身份时，是否获取主次账号所有待办数据，选取权重最大的进行操作； |
| formSaveFailInterdictFlow | 否 | boolean | 表单保存失败时是否阻断提交 |
| submitToRejectNodeType | 否 | int | 提交至退回节点的方式  0: 逐级审批；1: 直达退回节点 |
| mailAndSmsMsgParam | 否 | json | 节点允许修改提醒方式时，批准时，可以选择是否发送短信邮件提醒 |
| nodeAddOperators | 否 | list | 自由选择批次指定选择人员 |
| customLogType | 否 | int | 自定义意见类型（未传递自动计算默认意见类型） |
| skipFlowPointVerify | 否 | int | 默认值：0；1：跳过要点校验； |
| isVerifyFormRequired | 否 | boolean | true：要校验表单必填。false：不校验表单必填。默认值：true |
| isNewFormData | 否 | boolean | true：可以传递表单高级参数（seniorFormParam生效）。false：仅仅传递表达数据（默认值）。 |
| seniorFormParam | 否 | json | 表单高级参数，isNewFormData=true时才生效 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| needDefaultValue | boolean | true：给表单赋值默认值，false：默认值 |
| execRelate | boolean | 是否执行数据砖取；true：执行。false：默认值。 |
| execMonitor | boolean | 是否执行运算：true：执行；false：默认值。 |
| validate | boolean | 是否开启数据查重校验；true：开启。false：默认值。 |
| needValidateInfo | boolean | validate=true时生效，查重结果是否返回具体信息；true：返回；false：不返回。 |
| selectNextFlowData | list | 指定流转节点数据 |
| submitToDone | boolean | 是否提交到已办；默认值：true |
| nodeId | long | 指定流转节点ID |
| nodeOperators | list | 节点操作者 |
| signOrder | int | 会签属性；会签：1；非会签：0；依次逐个处理：2；并行分流：9；默认值：0； |
| nodeCCOperators | list | 节点抄送人 |
| ccType | int | 抄送设置: 用户选择：0； 不启用：1； 抄送需提交：2； 抄送不需提交：3； 操作者设置：4;默认值：0 |
| needSubmit | boolean | 当ccType=0时该属性需要传递；true：节点抄送人可提交；false：节点抄送人不可提交；默认值：false； |
| modifyOperator | boolean | 是否允许修改节点操作者；true：允许；false：不允许；默认值：true； |
| ehSignType | int | 会签关系；0：非会签；1：会签；2：依次逐个处理；默认值：0； |
| ehSetOperator | String | 操作人ID，多个ID用英文逗号隔开； |
| userChooseMailRemind | boolean | false(默认值)：不发邮件；true：发邮件 |
| userChooseSmsRemind | boolean | false(默认值)：不发邮件；true：发邮件 |
| content | String | 内容 |
| fieldId | String | 字段id |
| dataOptions | String | 关联数据 |
| content | String | 关联数据名称 |
| targetId | String | 关联数据id |
| optionId | String | 选项id |
| type | String | 类型 |
| dataIndex | String | 明细标志。1就是第一行 |
| formId | String | 表单id |
| layoutMultiId | String | 布局id |
| id | String | dataid |
| module | String | 模块 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| requestId | long | 审批ID |
