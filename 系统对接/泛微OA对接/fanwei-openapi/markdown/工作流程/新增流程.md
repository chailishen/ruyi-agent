## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| requestname | 否 | String | 创建的流程实例标题（不输入按照默认标题组成生成标题） |
| workflowId | 是 | String | 工作流ID 获取工作流ID |
| remark | 否 | String | 签字意见 |
| isnextflow | 否 | Int | 是否流转到下一节点：0 否，1 是。默认值：0 |
| requestSecLevel | 否 | int | 密级（系统开启密级才使用这个参数），值大于0 才生效。且开启了密级，则获取创建人能获取的最大密级。 |
| requestSecValidity | 否 | String | 保密期限（传递密级时才传递该参数） |
| isVerifyFormRequired | 否 | boolean | isnextflow=1时，true：要校验表单必填。false：不校验表单必填。默认值：false |
| isExecuteCreateAddAction | 否 | boolean | true：执行创建节点前附加操作，false：不执行创建节点前附加操作。默认值：false |
| isVerifyPer | 否 | int | 是否验证用户创建流程权限；0：不验证。1：验证。默认值：0； |
| requestId | 否 | long | 可以自定义流程ID |
| delReqFlowFaild | 否 | boolean | 创建并流转失败的流程是否要删除掉；true：删除。false：不删除。默认值：false |
| businessData | 否 | String | 数据来源 |
| moduleDataId | 否 | long | 关联模块数据ID（默认值0） |
| formData | 否 | String | 表单数据 |
| requestlevel | 否 | Int | 紧急程度 0：正常； 1：重要； 2：紧急。默认值：0 |
| otherParams | 否 | String | 比如isnextflow(是否进行流转1：是，其他否),requestSecLevel（密级，系统开启密级才使用这个参数） |
| identityId | 否 | long | 代理人ID，此时userid 传被代理人ID；举例：A委托给B，userid传B，identityId传A； |
| identityType | 否 | int | 1：兼岗，2：委托 |
| selectFlowParam | 否 | JSON | 指定流转相关参数 |
| exceptionHandleInfo | 否 | map | 异常处理由用户选择操作者参数；若节点异常处理未设置由用户选择操作者，传递了也不会生效；KEY：节点ID；VALUE：异常处理操作者数据； |
| imRemind | 否 | boolean | isnextflow=0时，给发起人发送IM提醒 |
| emailRemind | 否 | boolean | isnextflow=0时，给发起人发送邮件提醒 |
| smsRemind | 否 | boolean | isnextflow=0时，给发起人发送短信提醒 |
| mailAndSmsMsgParam | 否 | json | 节点允许修改提醒方式时，流时，可以选择是否发送短信邮件提醒 |
| nodeAddOperators | 否 | list | 自由选择批次指定选择人员，isnextflow = 1时才需要传递。 |
| customLogType | 否 | int | 自定义意见类型（isnextflow=1时，才有效；未传递自动计算默认意见类型）从工作流设置→应用设置→操作菜单及意见类型设置→意见类型自定义设置→意见类型code值 取值。 |
| skipFlowPointVerify | 否 | int | 默认值：0；1：跳过要点校验； |
| odocId | 否 | long | 公文流程才需要的正文文档ID； |
| isNewFormData | 否 | boolean | true：可以传递表单高级参数（seniorFormParam生效）。false：仅仅传递表达数据（默认值）。 |
| seniorFormParam | 否 | json | 表单高级参数，isNewFormData=true时才生效 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| dataId | long | 业务数据Id |
| dataDetails | list | 表单字段数据 |
| formId | long | 表单ID。 |
| module | String | 模块，默认workflow |
| content | String | 文本内容 |
| dataKey | String | 字段数据库名，与fieldId二选一必填。 |
| fieldId | long | 字段ID，与dataKey二选一必填。 |
| dataIndex | long | 明细行序号(主表字段该值不用传递)。1：就代表是明细行第一行。从1开始填写。 |
| dataOptions | list | 浏览按钮数据，默认为null，有值的时候，以这个值为准，忽略content的内容。 |
| subFormId | long | 明细表ID，当传递明细数据且字段传递的dataKey则该值必填。获取明细表ID |
| subFormDataKey | String | 明细表dataKey，与subFormId二选一传递。 |
| optionId | long | 选项ID |
| targetId | long | 图片单选多选的选项的图片ID。 |
| content | long | 选项名称 |
| type | String | 选项类型 |
| needDefaultValue | boolean | true：给表单赋值默认值，false：默认值 |
| execRelate | boolean | 是否执行数据砖取；true：执行。false：默认值。 |
| execMonitor | boolean | 是否执行运算：true：执行；false：默认值。 |
| validate | boolean | 是否开启数据查重校验；true：开启。false：默认值。 |
| needValidateInfo | boolean | validate=true时生效，查重结果是否返回具体信息；true：返回；false：不返回。 |
| selectNextFlowData | list | 指定流转节点数据 |
| submitToDone | boolean | 是否提交到已办；默认值：true |
| nodeId | long | 指定流转节点ID |
| nodeOperators | list | 节点操作者 |
| signOrder | int | 会签属性；会签：1；非会签：0；依次逐个处理：2；并行分流：9；默认值：0； |
| nodeCCOperators | list | 节点抄送人 |
| ccType | int | 抄送设置: 用户选择：0； 不启用：1； 抄送需提交：2； 抄送不需提交：3； 操作者设置：4;默认值：0 |
| needSubmit | boolean | 当ccType=0时该属性需要传递；true：节点抄送人可提交；false：节点抄送人不可提交；默认值：false； |
| modifyOperator | boolean | 是否允许修改节点操作者；true：允许；false：不允许；默认值：true； |
| ehSignType | int | 会签关系；0：非会签；1：会签；2：依次逐个处理；默认值：0； |
| ehSetOperator | String | 操作人ID，多个ID用英文逗号隔开； |
| userChooseMailRemind | boolean | false(默认值)：不发邮件；true：发邮件 |
| userChooseSmsRemind | boolean | false(默认值)：不发邮件；true：发邮件 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| requestId | long | 流程ID |
