# 新建委托接口

- **文档 ID**: `944321385584549889`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/newAgent`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token |  | String | 调用接口凭证 获取accessToken信息 |
| userid |  | long | 用户ID 获取用户ID |
| agentUserId |  | long | 委托接收人ID |
| agentExplain |  | string | 委托说明 |
| beginDateTime |  | LocalDateTime | 委托开始时间 |
| endDateTime |  | LocalDateTime | 委托结束时间 |
| rangeType |  | int | 委托范围 1：全部 2：选择审批流类型 3：选择审批流 4：选择节点 |
| rangeObjects |  | String | 委托范围对象 审批流类型或者审批流或者节点的具体值，多个以,分割 |
| isAgentCreate |  | int | 委托流程发起 0：否 1：是 |
| isAgentCreateSubWf |  | int | 委托发起子流程 0：否 1：是 |
| isAgentDeal |  | int | 委托流程处理 0：否 1：是 |
| isAgentPendingWf |  | int | 委托已有待办流程 0：否 1：是 |
| operateType |  | int | 委托指定操作类型 0：全部 1：选择 |
| operateObjects |  | String | 委托指定操作类型对象(多个,分割) 0：节点操作者 1：转发接收人2：抄送接收人 3：传阅接收人 4：意见征询接收人 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| agentId | string | 新建代理id |
| workflowInfo | array | 流程信息 |
| workflowInfo[0].workflowId | String | 工作流id |
| workflowInfo[0].workflowName | String | 工作流名称 |
