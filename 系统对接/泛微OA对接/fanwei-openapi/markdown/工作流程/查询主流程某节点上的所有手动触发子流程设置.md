# 查询主流程某节点上的所有手动触发子流程设置

- **文档 ID**: `236699392474611712`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/getTriSubRequestMenuSet`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userIdStr | 是 | Long | 用户ID 获取用户ID |
| mainRequestId | 是 | Long | 主流程的唯一标识 |
| nodeIds | 否 | Long | 外部表单ID，如果传了该参数就触发外部表单子流程，如果没有传则触发内部表单子流程 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 状态码 0：成功 , 500：系统异常 100001：参数异常 |
| errmsg | String | 错误信息 |
| id | Long | 触发按钮ID |
| workflowId | Long | 工作流程ID |
| nodeId | Long | 节点ID |
| requestId | Long | 流程ID |
| title | String | 名称 |
| createTime | DateTime | 创建时间 |
| creator | Long | 创建人ID |
| tenantKey | String | 租户Key |
| orderid | int | 排序 |
| menutype | String | “TRIGGER_SUBWF”固定值 |
| logtype | int | 签署意见类型 |
| useable | int | 是否启用 |
| istop | int | 是否顶部快捷菜单 |
| defaultSign | String | 默认审批意见 |
| feedbackControl | int | 反馈控制 |
| cusFeedbackTitle | String | 反馈控制的自定义名称 |
| datasrc | int | 数据来源 |
| pcIcon | String | PC端菜单按钮 |
| mobileIcon | String | 移动端菜单按钮 |
| menuKey | int | 按钮唯一key值 |
| subwfsetid | Long | 子流程设置ID |
| addStepMode | int | 流转设定属性 |
| doneTriSubWf | int | 已办中允许手动触发 |
| archiveTriSubWf | int | 结束后允许手动触发 |
