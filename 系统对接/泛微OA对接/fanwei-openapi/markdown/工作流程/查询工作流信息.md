# 查询工作流信息

- **文档 ID**: `215674251800215552`
- **业务模块**: 工作流程 / 工作流管理
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/pathdef/openapi/getBaseInfoByCondition`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| workflowType | 是 | Int | 工作流类型id，数字类型，可以不传，传了则会根据指定的类型过滤，若是想过滤"其它类型”，传-1 |
| workflowName | 否 | String | 工作流名称，传了则只会根据指定的名称过滤 |
| status | 否 | String | 工作流状态，默认只查活动版本的数据：包括停用和启用的，传了则只会查询指定状态的工作流，取值含义如下：1启用  2历史版本  5停用  9工作流模板 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| baseInfoList | String | 工作流信息列表，是个对象数组，内部包合了工作流的基础信息，比如工作流id、工作流名称等等，具体见接口返回值 |
