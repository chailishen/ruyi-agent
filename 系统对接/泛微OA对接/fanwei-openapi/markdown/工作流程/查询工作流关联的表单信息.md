# 查询工作流关联的表单信息

- **文档 ID**: `370433517147914240`
- **业务模块**: 工作流程 / 工作流管理
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/pathdef/openapi/getFormInfo`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID  获取用户ID |
| workflowId | 是 | Int | 工作流id |
| needMainFormInfo | 否 | boolean | 是否需要主表信息，默认false |
| needDetailFormInfo | 否 | boolean | 是否需要明细表信息，默认false |
| needMainFieldInfo | 否 | boolean | 是否需要主表字段信息，默认false |
| needDetailFieldInfo | 否 | boolean | 是否需要明细表字段信息，默认false |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| mainFormList | List<WfFormEntity> | 主表信息 |
| subFormList | List<WfSubFormEntity> | 明细表信息 |
| mainFieldList | List<WfFormFieldEntity> | 主表字段信息 |
| detailFieldList | List<WfFormFieldEntity> | 明细表字段信息 |
