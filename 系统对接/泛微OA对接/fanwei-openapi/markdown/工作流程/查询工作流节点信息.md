# 查询工作流节点信息

- **文档 ID**: `215678129975328768`
- **业务模块**: 工作流程 / 工作流管理
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/pathdef/openapi/getNodeInfoByCondition`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| workflowId | 是 | Int | 工作流id |
| needNextNode | 否 | boolean | 是否需要计算下-节点信息，可以不传默认是false，如果传了true则会计算每个节点的下个节点信息(在返回值的nextNodeList属性中) |
| needRejectLink | 否 | boolean | 是否需要退回出口，可以不传默认是false，如果传了true则当计算节点的下一个节点时，会返回退回出口 |
| nodeId | 否 | Int | 节点id，数字类型，可以不传，如果传了，则只查指定节点的数据，发起节点的数据始终返回 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| startNodeld | String | 工作流开始节点id |
| nodelnfoList | String | 工作流节点列表，包含节点的基础信息，比如节点id、节点名称等等，具体见接口返回值注意，在节点对象中，有个nextNodeList属性，包含了当前节点所有的下一个节点id |
