# 查询时间段内新增、更新、删除三种类型的的工作流列表

- **文档 ID**: `840712420755865600`
- **业务模块**: 工作流程 / 工作流管理
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/workflow/v2/queryChangedFormsAllType`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| datamap | 是 | Object | 时间参数 |
| pageNo | 否 | Integer | 当前页数 |
| pageSize | 否 | Integer | 每页数量，最大:200 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| startTime | String | 开始时间(年-月-日) |
| endTime | String | 结束时间(年-月-日) |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| id | Long | 工作流ID |
| name | String | 工作流名称 |
| status | String | 工作流状态(enable启用,disable禁用) |
