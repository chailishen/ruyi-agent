# 根据工作流类型查询工作流和表单

- **文档 ID**: `840693728847601665`
- **业务模块**: 工作流程 / 工作流管理
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/workflow/v2/getFormByCategoryId`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| categoryId | 是 | Long | 工作流类型ID 获取工作流类型ID |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| forms | object | 表单列表 |
| id | String | 表单ID |
| workflowId | String | 工作流ID |
| name | String | 工作流名称 |
