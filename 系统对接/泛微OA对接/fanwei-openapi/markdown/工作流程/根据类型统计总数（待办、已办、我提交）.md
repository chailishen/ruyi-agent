# 根据类型统计总数（待办、已办、我提交）

- **文档 ID**: `840713081979502592`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/workflow/v2/queryStatCountByType`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| formIds | 是 | List<Long> | 审批表ID列表 获取审批表ID |
| type | 是 | String | 查询类型：todo(待办)、finshed(已办)、minecreate(我提交)、drafts(草稿) |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| todo | Long | 待办数量 |
| finshed | Long | 已办数量 |
| minecreate | Long | 我提交的数量 |
| drafts | Long | 草稿数量 |
