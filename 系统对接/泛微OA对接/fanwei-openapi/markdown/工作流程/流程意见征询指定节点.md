# 流程意见征询指定节点

- **文档 ID**: `275793183118458880`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/consulWithNode`
- **请求方式**: `POST`
- **Content-Type**: `application/json`

## 备注

- package com.weaver.core.demo;

import cn.hutool.http.HttpRequest;
import cn.hutool.json.JSONUtil;
import com.alibaba.fastjson.JSONArray;
import com.alibaba.fastjson.JSONObject;
import com.weaver.core.constant.TestConstant;
import com.weaver.core.utils.RequestUtil;

/**
 * 意见征询指定节点
 *
 * @author:chenwh
 */
public class ConsulWithNodeDemo extends DemoBase {
    public static void main(String[] args) {
        String response = new ConsulWithNodeDemo().consulWithNode(TOKEN, RequestUtil.createRequest());
        System.out.println(response);
    }

    /**
     * 意见征询指定节点
     * {"message":{"errcode":"0","errmsg":"成功","requestId":"","otherData":{}}}
     *
     * @param token
     * @param requestId
     * @return
     */
    public String consulWithNode(String token, long requestId) {
        String url = HOST + "/api/workflow/core/paService/v1/consulWithNode?access_token=" + token;
        JSONObject param = new JSONObject();
        param.put("userid", TestConstant.USER_CHENWH);
        param.put("requestId", requestId);
        param.put("consulNodeId", TestConstant.WORKFLOW_YBLC_NODE1);
        param.put("remark", "意见征询");
        JSONArray receiveOperators = new JSONArray();
        param.put("receiveOperators", receiveOperators);
        JSONObject receive1 = new JSONObject();
        receive1.put("id", TestConstant.USER_ZMM);
        receive1.put("entityType", "user");
        receiveOperators.add(receive1);

        JSONObject receive2 = new JSONObject();
        receive2.put("id", TestConstant.DEPT_ZMM);
        receive2.put("entityType", "dept");
        receiveOperators.add(receive2);

        // 发送请求
        return HttpRequest.post(url)
                .header("Content-Type", "application/json")
                .body(JSONUtil.toJsonStr(param))
                .execute()
                .body();
    }
}

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userId | 是 | Long | 用户ID 获取用户ID |
| requestId | 是 | long | 流程ID |
| userCurrentNodeId | 否 | Long | 用户当前节点；用于存在多个当前节点，可传入该参数指定以哪个节点取征询。 |
| consulNodeId | 否 | long | 传了征询该节点，没传则征询用户所在节点 |
| consulLogType | 否 | Integer | 自定义意见类型，传了征询consulNodeId时，如果还传了该值，签字意见类型则以该值为准 |
| receiveOperators | 否 | list | 接收人是个数组，数组内的元素有id和entityType. |
| receiveOperators[0].id | 是 | long | 用户ID、群组ID、部门ID |
| receiveOperators[0].entityType | 是 | String | user:id代表人员ID；dept：id代表部门ID；group：id代表群组ID。 |
| nodeReceiveOperators | 否 | Map | 节点征询接收人；支持征询多人多节点；key：节点id，value：接收人（与receiveOperators格式相同） |
| consulLogType | 否 | int | 意见类型，传了该值意见类型则以该值为准。 |
| remark | 否 | String | 意见内容 |
| comment | 否 | obj | 意见对象，包含关联事项等。 |
| attachments | 否 | String | 附件 |
| signatureData | 否 | Map | 手写签批 |
| userSignatureData | 否 | Map | 电子签章 |
| locationData | 否 | Map | 位置 |
| fullTextAnnotationData | 否 | List | 全文批注 |
| otherParam | 否 | obj | 额外参数：包含下面几个参数。 |
| otherParam.isOpenTimeLimit | 否 | int | 限时征询是否开启：0关闭，1开启。 |
| otherParam.limitDay | 否 | int | 征询限时：单位 天。 |
| otherParam.limitHour | 否 | int | 征询限时：单位 小时。 |
| otherParam.limitMinute | 否 | int | 征询限时：单位 分钟。 |

## 返回参数

| --- | --- | --- |
| errcode | String | 状态码 0：成功 , 500：系统异常 100001：参数异常 |
| errmsg | String | 错误信息 |
