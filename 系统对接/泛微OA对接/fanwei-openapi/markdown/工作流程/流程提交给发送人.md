# 流程提交给发送人

- **文档 ID**: `278283069658497024`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/submitToSender`
- **请求方式**: `POST`
- **Content-Type**: `application/json`

## 备注

- package com.weaver.core.demo;

import cn.hutool.http.HttpRequest;
import cn.hutool.json.JSONUtil;
import com.alibaba.fastjson.JSONObject;
import com.weaver.core.constant.TestConstant;

/**
 * 提交流程给发送人
 *
 * @author:chenwh
 */
public class SubmitToSenderDemo extends DemoBase {

    public static void main(String[] args) {
        String response = new SubmitToSenderDemo().submitToSender(959502823746453508L);
        System.out.println(response);
    }

    /**
     * 提交流程给发送人
     *
     * @param requestId
     * @return
     */
    public String submitToSender(long requestId) {
        String url = HOST + "/api/workflow/core/paService/v1/submitToSender?access_token=" + TOKEN;
        JSONObject param = new JSONObject();
        param.put("userid", TestConstant.USER_CHENWH);
        param.put("requestId", requestId);
        param.put("remark", "提交给发送人");

        // 发送请求
        return HttpRequest.post(url)
                .header("Content-Type", "application/json")
                .body(JSONUtil.toJsonStr(param))
                .execute()
                .body();
    }
}

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | long | 用户ID 获取用户ID |
| requestId | 是 | long | 流程请求ID |
| userCurrentNodeId | 否 | long | 当前节点：多个当前节点待办时调用方可指定操作当前节点，如果没有指定，则根据权重计算出一个默认操作节点 |
| customOperateTypeCode | 否 | int | 操作类型code，支持自定义；不传的话，默认批准/确认 |
| remark | 否 | string | 签字意见 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
