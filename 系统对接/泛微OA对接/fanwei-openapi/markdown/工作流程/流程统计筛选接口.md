# 流程统计筛选接口

- **文档 ID**: `840712227406839809`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/workflow/v2/queryStatFormDatasForFlow`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| formId | 是 | Long | 流程表ID 获取流程表ID |
| param | 是 | String | 参数JSON格式 |
| pageNo | 是 | Int | 当前页数 |
| pageSize | 是 | Int | 每页数量 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| flowName | String | 审批名称数组 |
| flowStatus | String | 流程状态：审批中notFinish、已结束finish |
| flowFinishTime | String | 结束时间区间(startTime、endTime) |
| flowSubmitTime | String | 提交时间区间(startTime、endTime) |
| flowCreator | Long | 申请人列表 |
| flowCreatorDepartment | Long | 申请人部门列表 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| creator | Object | 申请人信息 |
| delete | Boolean | 是否删除 |
| id | Long | 流程ID |
| name | String | 流程名称 |
| requestTime | Date | 流程提交时间 |
| finishTime | Date | 流程结束时间 |
| serNum | String | 流程流水号 |
