# 添加共享

- **文档 ID**: `919050206069391360`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/list/paService/v1/addRequestShare`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| shareSourceList | 是 | List | 共享资源集合 |
| requestid | 是 | string | 流程ID |
| shareTargetList | 是 | List | 共享对象集合下方是其中的参数 |
| shareType | 是 | int | 共享类型（人员：1；部门：2；分部：5；角色：10；群组：14；岗位：1311；所有人：11） |
| shareObjId | 是 | long | 共享目标id（对应共享类型：人员id；部门id；分部id；角色id；群组id；岗位id；所有人类型时传参为0） |
| permissionTypeList | 否 | list<Integer> | 权限项集合，传参为“1”时，可查看意见及评论开关打开，不传则开关默认关闭 |
| minSeclevel | 否 | Integer | 最小安全级别 |
| maxSeclevel | 否 | Integer | 最大安全级别 |
| shareCheckBoxList | 否 | List<Integer> | 共享选择框集合，共享类型为“部门”时，此参数有效，传参为3时 共享对象包含下级；传参为2002时 共享对象包含兼职 |
| shareTragetType | shareTragetType | int | 共享目标级别，共享类型为“角色/岗位”时，不传本参数默认是总部/全部机构；传参：总部/全部机构：0，分部/指定分部：1，部门/指定部门：2 |
| targetStationBsId | targetStationBsId | String | 共享目标级别id，共享类型为“岗位”时，此参数有效，指定分部传对应分部id，指定部门传对应部门id |
| needWriteLog | 否 | boolean | true：流程详情-操作日志中显示共享数据，false/不传本参数：操作日志中不显示共享数据 |
| needSendMsg | 否 | boolean | true：有IM消息提醒，false/不传本参数：没有IM消息提醒 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 状态码0：成功，1.接口内部异常，2.必填字段异常 |
| errmsg | String | 错误信息 |
| sourceId | String | 共享资源的id |
| result | String | 共享资源是否添加成功true:成功，false：失败 |
| msg | String | 返回信息 |
