# 获取下一节点操作者信息

- **文档 ID**: `840715457129095168`
- **业务模块**: 工作流程 / 获取流程信息
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/getRequestNextOperator`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| requestId | 是 | Int | 审批数据ID 获取审批数据ID |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | List | 下节点操作者信息 |
| requestId | String | 审批数据ID |
| workflowId | String | 审批流ID |
| linkId | String | 出口ID |
| freeLink | String | 是否自由出口 （0：否，1是） |
| linkName | String | 出口名称 |
| srcNodeId | String | 源节点 |
| nextNodeId | String | 下节点ID |
| nextNodeName | String | 下节点名称 |
| nextNodeType | String | 下节点类型 。START:发起，APPROVE：审批，COMMIT：确认,END:结束,SUB_WF：子流程节点，VOTE：投票，LOOP：循环审批,ROBOT：自动处理，WAIT：等待，LOOP_UP：查阅） |
| nextNodeAttr | String | 下节点属性。（COMMON:一般节点，FORK_START：分流节点，FORK_MIDDLE：分流中间节点，FORK_END：合流点） |
| nextOperators | List | 下节点操作者 List |
| userId | String | 操作者ID |
| userType | String | 操作者类型 (USER：系统内部用户，CUSTOM：客户) |
| agentUserId | String | 代理人ID |
| signOrder | String | 会签关系。（SIGN:会签，NO_SIGN：非会签，IN_TURN：依次逐个处理，CC_SUBMIT：抄送需提交，CC_NO_SUBMIT：抄送不需提交，OR_SIGN：或签） |
| arrivalRoundId | String | 到达轮次号 (每次同时到达的记录相同，多次到达不同) |
| formOperateLogId | String | 记录这条数据是那个操作ID产生的 |
| signGroup | String | 会签组 |
| agent | String | 是否代理 |
