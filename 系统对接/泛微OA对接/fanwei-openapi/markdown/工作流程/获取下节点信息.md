# 获取下节点信息

- **文档 ID**: `874490517275877377`
- **业务模块**: 工作流程 / 获取流程信息
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/getNextNodeInfo`
- **Content-Type**: `application/json`

## 备注

- POST （Content_Type: application/json），备注：access_token放在params中

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userId | 是 | Long | 用户ID 获取用户ID |
| requestId | 是 | long | 流程ID |
| userCurrentNodeId | 否 | long | 节点ID |
| isFlowToFreePath | 否 | int | 当节点下一节点有固定节点和自由节点时，传1获取加签节点；传0获取固定节点；默认值：1 |
| isIncludeOperate | 否 | int | 是否返回操作者数据，0：返回；1：不返回（默认值） |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | Map | 流程数据 |
