# 获取前台流程图显示数据

- **文档 ID**: `409087560665530368`
- **业务模块**: 工作流程 / 获取流程信息
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/getRequestChart`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户id |
| requestId | 是 | Int | 审批数据ID 获取审批数据ID |
| showType | 是 | Integer | 传递常量值2 |
| workflowId | 是 | Long | 路径id |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| message | Object | 响应状态对象 |
| data | Object | 响应数据对象 |
| autoProcess | Boolean | 是否存在自动处理 |
| chartFlowInfo | Object | 流程图流转信息，例如节点状态、出口状态、操作者等等 |
| groupDetail | Object | 流程图分组信息 |
| haveNewVersionAddSign | Boolean | 该流程图上，是否存在新版加签节点 |
| workflowDatas | Object | 流程图路径信息 |
| xml | String | 流程图渲染的xml串 |
