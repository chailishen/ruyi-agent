# 获取可加审减审的相关操作者数据

- **文档 ID**: `408011944323186688`
- **业务模块**: 工作流程 / 获取流程信息
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/getAddMinusOperatorInfo?access_token=`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token |  | String |  |
| userid |  | long | 用户ID |
| requestId |  | long | 流程请求ID |
| userCurrentNodeId |  | long | 减审操作者人操作所在节点，不传的话默认计算一个操作者节点 |
| canMinusDoneOperate |  | int | 是否加载可减审已办节点的数据 1:是 默认不能 |
| isMonitor |  | int | 是否是监控操作，默认是否，传1的话取监控权限（会校验是否有监控的加减审权限） |
| allNode |  | int | 是否加载所有节点数据；传1是加载所有数据，默认是只加载可加减审的节点数据 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | int | 200 代表成功 |
| msg | String | 执行结果信息描述 |
| data | JSONArray | 响应数据 |
