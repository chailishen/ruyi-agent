# 获取可退回节点

- **文档 ID**: `280943135339577344`
- **业务模块**: 工作流程 / 获取流程信息
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/getRejectNodes`
- **请求方式**: `GET`
- **Content-Type**: `application/json`

## 备注

- package com.weaver.core.demo.select;

import cn.hutool.http.HttpRequest;
import cn.hutool.json.JSONUtil;
import com.alibaba.fastjson.JSONObject;
import com.weaver.core.constant.TestConstant;
import com.weaver.core.demo.DemoBase;

/**
 * 获取可退回节点数据
 *
 * @author:chenwh
 * @date:2024/9/02 11:26
 */
public class GetRejectNodesDemo extends DemoBase {

    public static void main(String[] args) {
        String response = new GetRejectNodesDemo().getRejectNodes(TOKEN, 1039623497362194434L);
        System.out.println(response);
    }

    /**
     * 获取可退回节点数据
     *
     * @param token
     * @param requestId
     * @return
     */
    public String getRejectNodes(String token, long requestId) {

        String url = HOST + "/api/workflow/core/paService/v1/getRejectNodes?access_token=" + token;
        JSONObject param = new JSONObject();
        param.put("userid", TestConstant.USER_CHENWH);
        param.put("requestId", requestId);
        param.put("userCurrentNodeId", 801766920009482250L);

        // 发送请求
        return HttpRequest.get(url)
                .header("Content-Type", "application/json")
                .body(JSONUtil.toJsonStr(param))
                .execute()
                .body();
    }
}

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| requestId | 是 | Long | 流程ID |
| userCurrentNodeId | 否 | Long | 节点ID |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | int | 200 代表成功 |
| msg | String | 执行结果信息描述 |
| data | JSON | 响应数据 |
| rejectType | String | 退回方式 |
| rejectNodes | json | 可退回节点信息 |
