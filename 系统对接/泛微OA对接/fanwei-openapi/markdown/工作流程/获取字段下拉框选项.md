# 获取字段下拉框选项

- **文档 ID**: `908574870960758785`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/getFieldOption`
- **Content-Type**: `application/json`

## 备注

- POST （Content_Type: application/json），备注：access_token放在params中

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | long | 用户ID 获取用户ID |
| fieldId | 是 | long | 字段ID |
| pageSize | 否 | int | 每页数量 |
| pageNo | 否 | int | 页码 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| total | int | 总数 |
| maxPage | int | 最大页码 |
| data | list | 下拉框选项数据 |
| data.id | long | 选项ID |
| data.name | String | 选项名称 |
