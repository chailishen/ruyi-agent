# 获取待办流程发送人数据

- **文档 ID**: `278280754532712448`
- **业务模块**: 工作流程 / 获取流程信息
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/getTodoSenderInfo`
- **请求方式**: `POST`
- **Content-Type**: `application/json`

## 备注

- package com.weaver.core.demo;

import cn.hutool.http.HttpRequest;
import cn.hutool.json.JSONUtil;
import com.alibaba.fastjson.JSONObject;
import com.weaver.core.constant.TestConstant;

/**
 * 强制结束
 */
public class DoForceOverDemo extends DemoBase {
    public static void main(String[] args) {
        String response = new DoForceOverDemo().doForceOver(959474781853327360L);
        System.out.println(response);
    }

    /**
     * 强制归档
     * {"message":{"errcode":"0","errmsg":"流程提交成功读取后端配置","requestId":"959474781853327360","otherData":{}}}
     *
     * @return
     */
    public String doForceOver(long requestId) {
        String url = HOST + "/api/workflow/core/paService/v1/doForceOver?access_token=" + TOKEN;
        JSONObject param = new JSONObject();
        param.put("userid", TestConstant.USER_CHENWH);
        param.put("requestId", requestId);
        // 1：以监控权限强制结束；
        param.put("ismonitor", 1);

        // 发送请求
        return HttpRequest.post(url)
                .header("Content-Type", "application/json")
                .body(JSONUtil.toJsonStr(param))
                .execute()
                .body();
    }
}

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| requestIds | 是 | String | 流程ID，多个流程ID用英文逗号隔开 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | json | 数据 |
| requestId | long | 流程ID |
| isRemark | String | 操作者id |
| sendTime | String | 发送时间 |
| sendNode | obj | 发送人发送节点信息 |
| sender | obj | 发送人信息 |
