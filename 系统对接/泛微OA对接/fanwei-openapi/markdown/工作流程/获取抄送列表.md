# 获取抄送列表

- **文档 ID**: `408049279182045184`
- **业务模块**: 工作流程 / 获取流程信息
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/getCCBackListData?access_token=`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token |  | String |  |
| userid |  | long | 用户ID |
| requestId |  | long | 流程请求ID |
| current |  | int | 页码（默认值：1） |
| pageSize |  | Int | 每页数据量（默认值：10） |
| afterAllowBack |  | int | 0 获取所有数据；2：获取未批注数据；默认值：0 |
| viewBack |  | int | 0：不允许收回；1：只能收回未查看数据；2：查看前，查看后的都可以收回。默认值：2 |
| isMonitor |  | int | 是否监控权限 0：否 1：是 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | int | 200 代表成功 |
| msg | String | 执行结果信息描述 |
| data | JSONArray | 响应数据 |
