# 获取指定流转可选节点及操作者信息

- **文档 ID**: `408047245129154560`
- **业务模块**: 工作流程 / 获取流程信息
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/getSelectFlowNodeInfos?access_token=`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token |  | String |  |
| userid |  | long | 用户ID |
| requestId |  | long | 流程请求ID |
| userCurrentNodeId |  | long | 指定当前节点，不传的话会根据权限计算出一个当前节点，如果传的是未经过的节点，userId需要传一个有监控权限的userId |
| needNodeOperator |  | int | 是否需要计算节点的操作者信息0：否（默认）、1：是 |
| needCalOperatorRange |  | int | 计算节点的操作者时，是否需要排除指定流转接收人范围外的人员0：否、1：是（默认） |
| needCanSelectUser |  | int | 是否计算返回可选人员信息0：否（默认）、1：是（默认）；needNodeOperator、needCalOperatorRange必须传1 |
| orgParamMap |  | map | 浏览按钮扩展参数，支持计算范围时是否禁用分权 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | int | 200 代表成功 |
| msg | String | 执行结果信息描述 |
| data | JSONArray | 响应数据 |
