- **文档 ID**: `408011319967481856`
- **业务模块**: 工作流程 / 获取流程信息
- **是否 API 接口**: 是

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token |  | String |  |
| userid |  | long | 用户ID |
| requestId |  | long | 流程请求ID |
| menuKeys |  | String | 按钮KEY，多个KEY用英文逗号隔开；不传时获取所有有权限的按钮；{origin}/build/techdoc/wdoc/index.html#/public/doc/ae2eaeee-b434-4058-b4a3-90bb405e01d4 |
