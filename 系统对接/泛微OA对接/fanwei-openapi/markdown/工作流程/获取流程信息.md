# 获取流程信息

- **文档 ID**: `840715019067596801`
- **业务模块**: 工作流程 / 获取流程信息
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/getWorkflowRequest`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| requestId | 是 | Int | 审批数据ID 获取审批数据ID |
| pageSize | 否 | int | 签字意见条数 |
| isGetRequestBaseInfo | 否 | boolean | 是否获取流程基础数据，默认值：true |
| isGetRequestLog | 否 | boolean | 是否获取流程签字意见，默认值：true |
| isGetFormData | 否 | boolean | 是否获取表单数据，默认值：true |
