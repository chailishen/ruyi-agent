# 获取流程基础信息

- **文档 ID**: `908575278979039232`
- **业务模块**: 工作流程 / 获取流程信息
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/getRequestInfo`
- **Content-Type**: `application/json`

## 备注

- POST （Content_Type: application/json），备注：access_token放在params中

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | long | 用户ID 获取用户ID |
| requestId | 是 | long | 流程ID |
| getFormData | 否 | boolean | 是否获取表单数据，默认值：false |
| fieldIds | 否 | list | 要获取表单字段的ID，若是不传递则获取所有字段值；getFormData=true时才生效； |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| requestId | long | 流程ID |
| workflowId | long | 工作流ID |
| startNodeId | long | 创建节点ID |
| createDateTime | String | 创建时间 |
| requestName | String | 流程名称 |
| requestNameHtml | String | 流程名称（HTML） |
| lastOperator | long | 上一操作者ID |
| lastOperateDateTime | String | 上次操作时间 |
| requestLevel | int | 紧急程度 |
| requestMark | String | 流程编号 |
| secLevel | int | 流程密级 |
| secValidity | String | 流程保密期限 |
| flowStatus | Enum | 流程状态 |
| currentNodeList | list | 当前节点集合 |
| finishDateTime | String | 流程归档时间 |
