# 获取流程状态

- **文档 ID**: `840715105118814208`
- **业务模块**: 工作流程 / 获取流程信息
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/getRequestStatus`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| requestId | 是 | Int | 审批数据ID 获取审批数据ID |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | String | 审批状态数据 |
| workflowBaseInfo | String | 审批基本信息 详细说明同获取审批信息接口 |
| currentNodeType | String | “节点类型”,//START(发起),APPROVE(批准),COMMIT(提交),END(结束),SUB_WF(子流程节点),VOTE(投票节点),LOOP(循环审批),ROBOT(机器人节点),WAIT(等待节点),LOOK_UP(查阅节点 仅自由节点使用) |
| creatorId | String | 创建人id |
| currentNode | String | 节点id |
| isremark | String | 操作状态，具体可以查看数据字典 |
| status | String | 流程状态 |
