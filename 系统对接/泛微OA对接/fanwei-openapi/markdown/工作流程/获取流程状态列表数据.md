# 获取流程状态列表数据

- **文档 ID**: `418961806250213376`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/getRequestStatusData`
- **Content-Type**: `application/json`

## 备注

- POST （Content_Type: application/json），备注：access_token放在params中

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token |  | String | 调用接口凭证 |
| userId |  | long | 用户ID |
| requestId |  | long | 流程请求id |
| pageSize |  | int | 每页数量 |
| current |  | int | 当前 |
| selectAll |  | int | 是否返回所有数据：1:是，0:否 |
