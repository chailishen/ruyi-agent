# 获取流程签字意见

- **文档 ID**: `840714924662202369`
- **业务模块**: 工作流程 / 获取流程信息
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/getRequestLog`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| requestId | 是 | Int | 审批数据ID 获取审批数据ID |
| otherParams | 否 | String | 其他参数，pageSize：一页显示多少条数据，pageNumber：查询第几页数据。pageSize默认为10,pageNumber默认为1{“pageSize”:10,”pageNumber”:1} |
