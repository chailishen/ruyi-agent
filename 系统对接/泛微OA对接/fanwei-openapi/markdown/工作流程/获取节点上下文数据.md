# 获取节点上下文数据

- **文档 ID**: `275828313702793216`
- **业务模块**: 工作流程 / 获取流程信息
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/getNodeContextInfo`
- **请求方式**: `POST`
- **Content-Type**: `application/json`

## 备注

- package com.weaver.core.demo.select;

import cn.hutool.http.HttpRequest;
import cn.hutool.json.JSONUtil;
import com.alibaba.fastjson.JSONObject;
import com.weaver.core.constant.TestConstant;
import com.weaver.core.demo.DemoBase;

/**
 * 获取节点上下文数据
 *
 * @author:chenwh
 */
public class GetNodeContextInfoDemo extends DemoBase {

    public static void main(String[] args) {

        String response = new GetNodeContextInfoDemo().getNodeContextInfo(TOKEN, 959439511657390081L);
        System.out.println(response);
    }

    /**
     * 获取节点上下文数据
     *
     * @param token
     * @param requestId
     * @return
     */
    public String getNodeContextInfo(String token, long requestId) {
        String url = HOST + "/api/workflow/core/paService/v1/getNodeContextInfo?access_token=" + token;
        JSONObject param = new JSONObject();
        param.put("userid", TestConstant.USER_CHENWH);
        param.put("requestId", requestId);
        param.put("userCurrentNodeId", TestConstant.WORKFLOW_YBLC_NODE);

        // 发送请求
        return HttpRequest.post(url)
                .header("Content-Type", "application/json")
                .body(JSONUtil.toJsonStr(param))
                .execute()
                .body();
    }
}

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access _token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | long | 用户ID 获取用户id |
| requestId | 是 | long | 流程ID |
| userCurrentNodeId | 否 | long | 当前节点ID |
| onlyOperator | 否 | int | 当前节点操作者，是否只获取操作者数据。true：是。false：操作者，抄送人数据都会返回。默认值：false； |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | json |  |
| data.currentNode | list | 当前节点数据 |
| data.nextNode | list | 下一节点数据 |
| data.preNode | list | 上一个节点数据 |
| nodeName | String | 节点名称 |
| nodeId | String | 节点ID |
| nodeType | int | 节点类型 |
| operatorUsers | list | 节点操作者数据 |
