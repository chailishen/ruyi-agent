# 获取节点操作者

- **文档 ID**: `908575957688147968`
- **业务模块**: 工作流程 / 获取流程信息
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/getNodeOperator`
- **请求方式**: `POST （Content_Type: application/json），备注：access_token放在params中备注  若没传递targetNodeId，则获取当前节点未操作者（可能有多个，全部返回）；  若传递了targetNodeId，且targetNodeId为当前节点，则获取指定节点未操作者；  若传递了targetNodeId，且targetNodeId不为当前节点，若指定节点为发起节点，则获取指定节点最新轮次操作者；  若传递了targetNodeId，且targetNodeId不为当前节点和发起节点，且calculateConfigOperator=true，则获取指定节点操作组配置的操作者；  若传递了targetNodeId，且targetNodeId不为当前节点和发起节点，且calculateConfigOperator=false，则获取指定节点最新轮次操作者；`
- **Content-Type**: `application/json`

## 备注

- POST （Content_Type: application/json），备注：access_token放在params中备注  若没传递targetNodeId，则获取当前节点未操作者（可能有多个，全部返回）；  若传递了targetNodeId，且targetNodeId为当前节点，则获取指定节点未操作者；  若传递了targetNodeId，且targetNodeId不为当前节点，若指定节点为发起节点，则获取指定节点最新轮次操作者；  若传递了targetNodeId，且targetNodeId不为当前节点和发起节点，且calculateConfigOperator=true，则获取指定节点操作组配置的操作者；  若传递了targetNodeId，且targetNodeId不为当前节点和发起节点，且calculateConfigOperator=false，则获取指定节点最新轮次操作者；

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | long | 用户ID 获取用户ID |
| requestId | 是 | long | 流程ID |
| onlyOperator | 否 | boolean | 是否只获取操作者。默认值：true。true：只获取提交权限的操作者。false：获取所有操作者（提交、抄送接收人、转发接收人等）。 |
| userCurrentNodeId | 否 | long | 节点ID。 |
| targetNodeId | 否 | long | 节点ID。 |
| calculateConfigOperator | 否 | boolean | targetNodeId不为当前节点，非创建节点时；true：获取操作者设置；false：获取节点最新轮操作者；默认值false； |
