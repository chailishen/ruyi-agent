- **文档 ID**: `408008148654227456`
- **业务模块**: 工作流程 / 获取流程信息
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/getBeConsulLog`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token |  | String |  |
| userid |  | long | 用户ID |
| requestId |  | long | 流程请求ID |

| 参数名 | 类型 | 说明 |

| code | int | 200 代表成功 |

| data | JSONArray | 响应数据 |

| userDepartName | String | 征询人部门 |
| beConsulBeAgentUserId | long | 征询接收人被代理人Id |
| beConsulBeAgentUserName | String | 征询接收人被代理人 |
| beConsulUserId | long | 征询接收人ID(包含代理身份) |
