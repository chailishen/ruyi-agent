# 获取退回操作发送人

- **文档 ID**: `408042555192639488`
- **业务模块**: 工作流程 / 获取流程信息
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/getSendOperator?access_token=`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token |  | String |  |
| userid |  | long | 用户ID |
| requestId |  | long | 流程请求ID |
| isGetAllInTurnOperator |  | boolean | 当发送人有依次逐个处理的情况，传递该值为true时，可以得到所有的依次逐个处理的人，否则只会得到依次逐个处理的第一个人 |
| userCurrentNodeId |  | long | 当有多个节点时，可以传递节点ID |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | int | 200 代表成功 |
| msg | String | 执行结果信息描述 |
| data | JSONArray | 响应数据 |
| userId | long | 人员ID |
| nodeId | long | 节点ID |
| userName | String | 人员名称 |
