# 获取退回直达本节点跳过节点最新轮次操作者

- **文档 ID**: `408006533343870976`
- **业务模块**: 工作流程 / 获取流程信息
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/getToRejectNodeOperator`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token |  | String |  |
| userid |  | long | 用户ID |
| requestId |  | long | 流程请求ID |
| getFirstFlowInfo |  | boolean | true（默认值）：取最新一次流转记录，若不是直达退回节点则获取不到数据；false：取所有流转记录中最新一次直达退回节点，取这中间跳过的节点操作者； |
