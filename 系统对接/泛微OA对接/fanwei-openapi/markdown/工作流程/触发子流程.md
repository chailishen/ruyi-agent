# 触发子流程

- **文档 ID**: `236697290738237440`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/triggerSubRequest`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userIdStr | 是 | Long | 用户ID 获取用户ID |
| mainRequestId | 是 | Long | 主流程的唯一标识 |
| subWfSetIds | 是 | List | 子流程设置唯一标识，需要触发子流程的设置ID（workflow_subwfset表id字段） |
| dataId | 否 | Long | 外部表单ID，如果传了该参数就触发外部表单子流程，如果没有传则触发内部表单子流程 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 状态码 0：成功 , 500：系统异常 100001：参数异常 |
| errmsg | String | 错误信息 |
| otherData | Object | 其他信息 |
