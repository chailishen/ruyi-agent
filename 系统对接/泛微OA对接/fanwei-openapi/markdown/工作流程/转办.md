# 转办

- **文档 ID**: `874488820935434241`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/doTurnTodo`
- **Content-Type**: `application/json`

## 备注

- POST （Content_Type: application/json），备注：access_token放在params中

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userId | 是 | Long | 用户ID 获取用户ID |
| requestId | 是 | long | 流程id 获取审批数据ID |
| remark | 否 | String | 意见 |
| receiveOperators | 是 | list | 接收人是个数组，数组内的元素有id和entityType. |
| receiveOperators[0].id | 是 | long | 用户ID、群组ID、部门ID |
| receiveOperators[0].entityType | 否 | String | user:id代表人员ID（默认值）；dept：id代表部门ID；group：id代表群组ID。 |
| otherParam | 否 | obj | 额外参数,是个对象，下级属性看示例。 |
| otherParam.userCurrentNodeType | 否 | int | 用户当前节点类型：1 审批；2 确认；5 投票； |
| otherParam.isNeedBack | 否 | int | 是否需要反馈，0 否；1是。 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | Map | 流程数据 |
