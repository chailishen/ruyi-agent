# 转发

- **文档 ID**: `874489258980155393`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/forward`
- **Content-Type**: `application/json`

## 备注

- POST （Content_Type: application/json），备注：access_token放在params中

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userId | 是 | Long | 用户ID 获取用户ID |
| requestId | 是 | long | 流程ID 获取审批数据ID |
| receiveOperators | 是 | list | 接收人是个数组，数组内的元素有id和entityType. |
| receiveOperators[0].id | 是 | long | 用户ID、群组ID、部门ID |
| receiveOperators[0].entityType | 是 | String | user:id代表人员ID；dept：id代表部门ID；group：id代表群组ID。 |
| remark | 否 | String | 意见 |
| otherParam | 否 | obj | 额外参数：包含下面几个参数。 |
| otherParam.forwardNeedBack | 否 | int | 接收人批注后是否通知我：0不通知，1通知。 |
| otherParam.allowForward | 否 | int | 接收人是否可转发，0：不可转发（默认值）。1：可转发。【工作流】-【功能设置】-【转发设置】-【允许转发人设置接收人权限】开启后才生效。 |
| otherParam.ccAllowAnnotation | 否 | int | 接收人是否可批注，0：不可批注（默认值）。1：可批注。【工作流】-【功能设置】-【转发设置】-【允许转发人设置接收人权限】开启后才生效。 |
| mailAndSmsMsgParam | 否 | json | 节点允许修改提醒方式时，可以选择是否发送短信邮件提醒 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| userChooseMailRemind | boolean | false(默认值)：不发邮件；true：发邮件 |
| userChooseSmsRemind | boolean | false(默认值)：不发短信；true：发短信 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
