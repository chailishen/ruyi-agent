## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token |  | String | 调用接口凭证 获取accessToken信息 |
| userid |  | Long | 用户信息 获取用户信息 |
| requestId |  | Long | 流程实例Id，流程创建接口返回requestId |
| RejectToType |  | int | 流程退回方式：0：自由退回；1：逐级退回；2：指定范围退回；3：按出口退回；不传则获取后台设置的退回方式进行退回； |
| RejectToNodeid |  | Long | 退回到目标节点Id：当RejectToType传0或2时传递； |
| remark |  | String | 意见内容 |
| userCurrentNodeId |  | Long | 当前节点 |
| otherParams |  | json | 在body中传入，退回到指定节点。RejectToType：0，自由退回，1，逐级退回，2，指定范围退回，3，按出口退回；RejectToNodeid：在自由退回和指定范围内退回使用（节点）id，例如{“RejectToType”:0,”RejectToNodeid”:3974} |
| isSubmitDirect |  | int | 退回后提交方式：0：逐级审批，1：直达本节点。只有当节点操作菜单退回设置中的【退回后再提交到达节点】设置【操作者选择】时该参数才生效。 |
| useMaxWeightUser |  | boolean | 当userid 为主身份时，是否获取主次账号所有待办数据，选取权重最大的进行操作； |
| customLogType |  | int | 自定义意见类型（未传递自动计算默认意见类型） |
| skipFlowPointVerify |  | int | 默认值：0；1：跳过要点校验； |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| requestId | String | 审批数据ID |
