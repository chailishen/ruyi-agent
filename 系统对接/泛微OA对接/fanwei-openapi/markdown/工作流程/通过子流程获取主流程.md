# 通过子流程获取主流程

- **文档 ID**: `874490740605788161`
- **业务模块**: 工作流程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/workflow/core/paService/v1/getMainRequestBySubRequestId`
- **Content-Type**: `application/json`

## 备注

- POST （Content_Type: application/json），备注：access_token放在params中

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userIdStr | 是 | Long | 用户ID |
| subRequestId | 是 | Long | 子流程ID |
| delete | 否 | boolean | 是否查询已删除数据，false表示仅查询未删除数据，true表示查询所有数据。默认为false |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | Map | 流程数据 |
