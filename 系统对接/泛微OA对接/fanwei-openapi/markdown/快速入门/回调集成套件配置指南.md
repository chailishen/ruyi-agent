## 回调集成套件配置指南
##### 场景：
在本系统流程(报销流程、订单流程)结束后， 本系统通知第三方业务系统流程已结束。
##### 业务流：
业务人员在本系统发起报销审批 -> 审批结束 -> 本系统通知第三方业务系统审批已结束。
##### 详细操作步骤：
###### 一、本系统中新建流程表单
要求：    1.根据需要设置所需字段    2.流程表单需要设置流程    3.登录开放平台的账号是流程表单的创建人（或者具有流程表的提交、统计、维护权限）
###### 二、开放平台新建应用
新建应用类型为【回调集成套件】的应用
字段说明：
| 字段 | 类型 | 要求 |
| --- | --- | --- |
| 套件名称 | String | 必填，自定义应用名称。 |
| 应用流程 | String | 必填，该工作流程是您在本系统已经搭建好的，如步骤一里新建的流程表单。 |
| 回调通知地址 | String | 必填，您业务系统的完整地址，请确保本系统能够通过公网访问到该地址。当流程结束之后，调用此地址通知您业务系统流程已经完成。会有两个参数拼接在此地址后一起传给您业务系统，参数1：module（流程固定值"workflow"），参数2：id（流程ID）。 |
| 备注说明 | String | 选填，备注说明 |
###### 三、审核应用
应用审核通过之后，本系统会自动生成对应的回调规则。
###### 四、接收回调通知
当有步骤二"应用流程"所选相关流程结束之后，本系统会自动调用步骤二"回调通知地址"所配置的地址通知您业务系统。会有两个参数拼接在"回调通知地址"后一起传给您业务系统，参数1：module（流程固定值"workflow"），参数2：id（流程ID）。
