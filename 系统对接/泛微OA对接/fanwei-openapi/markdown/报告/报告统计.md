# 报告统计

- **文档 ID**: `840720134507864064`
- **业务模块**: 报告
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/workreport/v2/queryWorkreportSta`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userIds | 是 | List | 报告创建人ID集合 获取用户ID |
| year | 是 | String | 年份 |
| type | 是 | String | 周week、月month、季season、年year（包含了年中报告和年度报告） |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| status | String | delay延期提交、normal正常提交、none未提交 |
| serialNumber | String | 第几周、月、季等 |
| year | String | 所属年份 |
| userId | String | 用户ID |
| userName | String | 姓名 |
| type | year | 周报week、月报month、季报season、年中报告halfYear、年度报告year |
