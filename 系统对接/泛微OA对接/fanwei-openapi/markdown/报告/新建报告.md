# 新建报告

- **文档 ID**: `840719924054466561`
- **业务模块**: 报告
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/workreport/v2/createWorkreport`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| year | 是 | Int | 年份 |
| serialNumber | 是 | Int | 第几周、月、季等，季报的serialNumber只能为1或3，年中报告、年度报告的只能为1 |
| type | 是 | String | 周报week、月报month、季报season、年中报告halfYear、年度报告year |
| content | 是 | String | 工作成效 |
| summary | 是 | String | 工作成效 |
| plan | 是 | String | 计划内容 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| reportId | String | 报告ID |
