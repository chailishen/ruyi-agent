# 查询报告

- **文档 ID**: `840720065729667072`
- **业务模块**: 报告
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/workreport/v2/queryWorkreport`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userIds | 是 | List | 报告创建人ID集合 获取用户ID |
| startDate | 是 | String | 开始时间（相对创建时间而言），格式为yyyy-MM-dd |
| endDate | 是 | String | 结束时间（相对创建时间而言），格式为yyyy-MM-dd |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| summary | String | 工作成效 |
| content | String | 总结心得 |
| plan | String | 计划内容 |
| title | String | 报告标题 |
| createTime | String | 创建时间 |
| serialNumber | String | 第几周、月、季等 |
| year | String | 所属年份 |
| userId | String | 用户ID |
| userName | String | 姓名 |
