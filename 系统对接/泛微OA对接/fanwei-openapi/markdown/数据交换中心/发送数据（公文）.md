# 发送数据（公文）

- **文档 ID**: `216006633891823616`
- **业务模块**: 数据交换中心
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/odocexchange/v1/sendDocument{OpenApiOrigin}/api/odocexchange/v1/sendData`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| departmentCode | 是 | String | 单位编码，用于标识请求方所属单位 |
| platformTenant | 是 | String | 交换中心租户key，用于标识被请求的交换平台团队 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| access_token | String | 调用接口凭证 获取accessToken信息 |
| docId | String | 处理系统中公文唯一标识 |
| sendUnitCode | String | 发文单位编码 |
| receiveUnitCodes | List | 收文单位编码集合 |
| appTemplateId | String | 交换模板id，公文交换默认为1无需填写，数据交换必填对应交换模板id |
| sourceId | String | 数据交换源数据唯一标识，相同标识会覆盖处理。 |
| dataTitle | String | 数据交换数据标题 |
| plainTextMessage | JSON | 明文报文，key是在公文交换平台-字段设置模块维护，其中正文和附件的Name和Content不可更改。若数据交换，则内部结构为交换模板对应的表单json数据结构。 |
| - Document_Title | String | 公文标题 |
| - Emergency_Degree | String | 紧急程度（仅支持无、平件、平急、急件、加急、特急、特提） |
| - Issued_Number_of_Document | String | 发文字号 |
| - Main_Receiver_Department | String | 主送单位编码 |
| - Issuer_Department | String | 发文单位编码 |
| -Document_Text | String | 公文正文，调用文件上传接口返回的文件id |
| -Document_Attachments | String | 明文附件，逗号分隔的调用文件上传接口返回的文件id |
| message | JSON | 返回信息 |
| data | JSON |  |
| -sendId | Long | 公文发文标识 |
