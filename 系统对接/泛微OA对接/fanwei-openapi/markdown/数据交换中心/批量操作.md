# 批量操作

- **文档 ID**: `284140040949334016`
- **业务模块**: 数据交换中心
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/odocexchange/v1/batchReceiveData`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| departmentCode | 是 | String | 单位编码，用于标识请求方所属单位 |
| platformTenant | 是 | String | 交换中心租户key，用于标识被请求的交换平台团队 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| access_token | String | 调用接口凭证 获取accessToken信息 |
| ids | List<Long> | 公文收文标识集合 |
| operateType | String | 操作类型：批量签收(batchAccept)、批量拒收(batchReject)、批量退回(batchReturn)、发送方批量撤销(batchWithdraw) |
| opinion | String | 处理意见 |
| platform | Integer | 操作平台：1：交换平台，2：OA系统 |
| message | JSON | 返回信息 |
| data | JSON |  |
| receiveIds | List<Long> | 被作废／撤销公文收文标识集合（用于提示收文方无需后续处理） |
