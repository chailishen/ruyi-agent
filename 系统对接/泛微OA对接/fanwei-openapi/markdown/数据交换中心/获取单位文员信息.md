# 获取单位文员信息

- **文档 ID**: `284147186143330304`
- **业务模块**: 数据交换中心
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/odocexchange/v1/listUserByCode`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| departmentCode | 是 | String | 单位编码，用于标识请求方所属单位 |
| platformTenant | 是 | String | 交换中心租户key，用于标识被请求的交换平台团队 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| access_token | String | 调用接口凭证 获取accessToken信息 |
| departmentCodes | List<String> | 单位编码 |
| role | String | 角色类型：单位管理员：DEPT_ADMIN；发文员：SENDER；收文员：RECEIVER |
| message | JSON | 返回信息 |
| data | JSON |  |
