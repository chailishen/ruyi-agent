# 获取反馈意见（发送方获取接收方签收、拒收、退回反馈意见）

- **文档 ID**: `216021147634892800`
- **业务模块**: 数据交换中心
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/odocexchange/v1/receiveOperateOpinion`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| departmentCode | 是 | String | 单位编码，用于标识请求方所属单位 |
| platformTenant | 是 | String | 交换中心租户key，用于标识被请求的交换平台团队 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| access_token | String | 调用接口凭证 获取accessToken信息 |
| docId | String | 处理系统中公文唯一标识，与sendId二选一必填 |
| sendId | String | 公文发文标识，与docId二选一必填 |
| message | JSON | 返回信息 |
| data | JSON |  |
| -receiveIds | Long | 公文收文标识（收文方获取时，必须返回） |
| -receiveUnitCode | String | 收文单位编码（发文方获取时必须返回） |
| -operateType | String | 反馈类型：作废(invalid)、撤销(withdraw)、签收(accept)、拒收(reject)、退回(return) |
| -opinion | String | 意见 |
