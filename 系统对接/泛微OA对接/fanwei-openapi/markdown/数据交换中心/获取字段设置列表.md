# 获取字段设置列表

- **文档 ID**: `215992677705973760`
- **业务模块**: 数据交换中心
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/odocexchange/v1/listExchangeField`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| departmentCode | 是 | String | 单位编码，用于标识请求方所属单位 |
| platformTenant | 是 | String | 交换中心租户key，用于标识被请求的交换平台团队 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| access_token | String | 调用接口凭证 获取accessToken信息 |
| message | JSON | 返回信息 |
| data | List | 字段信息 |
| -id | String | 字段id唯一标识 |
| -fieldType | Integer | 字段类型 |
| -fieldCode | String | 字段编码 |
| -fieldName | String | 字段名称 |
| -fieldDesc | String | 字段描述 |
| -isOpen | Integer | 是否封存（0：封存，1：正常） |
