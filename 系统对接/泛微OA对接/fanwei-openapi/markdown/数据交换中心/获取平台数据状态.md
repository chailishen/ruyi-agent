# 获取平台数据状态

- **文档 ID**: `284145014399827968`
- **业务模块**: 数据交换中心
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/odocexchange/v1/getUnReceiveStatus`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| departmentCode | 是 | String | 单位编码，用于标识请求方所属单位 |
| platformTenant | 是 | String | 交换中心租户key，用于标识被请求的交换平台团队 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| access_token | String | 调用接口凭证 获取accessToken信息 |
| receiveIds | List<Long> | 公文收文标识集合 |
| message | JSON | 返回信息 |
| data | JSON |  |
| id | String | 收文数据id |
| status | String | 收文状态，未签收：7，已签收：8，已拒收：9，已退回：10，被撤销：11，被作废：12。 |
| opinion | String | 处理意见 |
