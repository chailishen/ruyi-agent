# 获取待接收数据（公文）列表

- **文档 ID**: `216013306958184448`
- **业务模块**: 数据交换中心
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/odocexchange/v1/listNotReceivedDocument数据：{OpenApiOrigin}/api/odocexchange/v1/listNotReceivedData`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| departmentCode | 是 | String | 单位编码，用于标识请求方所属单位 |
| platformTenant | 是 | String | 交换中心租户key，用于标识被请求的交换平台团队 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| access_token | String | 调用接口凭证 获取accessToken信息 |
| appTemplateId | String | 交换模板id，公文交换默认为1无需填写，数据交换必填对应交换模板id |
| message | JSON | 返回信息 |
| data | JSON |  |
| -receiveId | Long | 公文收文标识 |
| -docTitle | String | 公文标题 |
