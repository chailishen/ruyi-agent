# 按更新时间查询团队日报

- **文档 ID**: `840719795214712832`
- **业务模块**: 日报
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/blog/v2/queryDateBlog`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | string | 调用接口凭证 获取accessToken信息 |
| startDate | 是 | string | 开始时间，格式（yyyy-MM-dd HH:mm:ss） |
| endDate | 是 | string | 结束时间，格式（yyyy-MM-dd HH:mm:ss |
| queryType | 否 | string | 查询类型，默认查询日报创建时间，传入“update”则查询更新时间 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| userid | Long | 用户ID |
| name | String | 用户名 |
| blogs | List | 日报列表 |
