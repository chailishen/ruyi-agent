# 查询日报

- **文档 ID**: `840719670517178369`
- **业务模块**: 日报
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/blog/v2/queryBlog`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userIds | 是 | List | 用户ID 获取用户ID |
| startDate | 是 | Date | 开始时间，格式（yyyy-MM-dd） |
| endDate | 是 | Date | 结束时间，格式（yyyy-MM-dd） |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| userId | String | 用户ID |
| id | String | 日报ID |
| blogTime | Int | 日报时间 |
| content | String | 日报内容 |
| createTime | Int | 日报创建时间 |
