# 修改日程

- **文档 ID**: `908341955040067584`
- **业务模块**: 日程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/calendar/openapi/v1/updateById`
- **Content-Type**: `application/json`

## 备注

- POSTContent-Type：application/json

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| id | 是 | Long | 要修改的日程id |
| userId | 是 | Long | 操作人的id 获取用户ID |
| propertyName | 是 | String | 需要修改的参数名 |
| propertyValue | 是 | Object | 要修改为的参数值 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| name | String | 日程名称 |
| startDate | String | 日程开始时间 |
| endDate | String | 日程结束时间 |
| manager | String | 日程负责人 |
| secret | String | 日程公开程度（normal：上级可见， self：仅自己可见， dept：本部门可见， all：公开） |
| priority | String | 日程紧急程度 |
| receiptSwitch | String | 日程回执开关，（开启：open，关闭：close） |
| place | String | 日程地点 |
| repeatSetting | String | 重复日程设置 |
| entityRemind | String | 日程提醒设置 |
| calendarStatus | String | 日程状态 |
| signType | String | 日程签到设置。none：不签到；scan：扫码签到；position：定位签到 |
| allDay | String | 全天设置,（开启：true，关闭：false） |
| calendarType | String | 日程类型 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
