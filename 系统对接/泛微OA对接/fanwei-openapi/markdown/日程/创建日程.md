# 创建日程

- **文档 ID**: `908340825442115584`
- **业务模块**: 日程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/calendar/openapi/v1/createAgenda`
- **Content-Type**: `application/json`

## 备注

- POSTContent-Type：application/json

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| name | 是 | String | 日程标题（长度不能超过100字符 ） |
| creator | 是 | Long | 日程创建人 |
| manager | 是 | Long | 日程负责人 |
| startDate | 是 | String | 日程开始时间(yyyy-MM-dd HH:mm格式) |
| endDate | 是 | String | 日程结束时间，必须大于开始时间(yyyy-MM-dd HH:mm格式) |
| content | 否 | String | 日程详情 |
| calendarType | 否 | Long | 日程类型，不传则使用默认类型。若需要手动指定，则需要指定启用的类型 |
| priority | 否 | String | 日程紧急程度，不传递则使用默认紧急程度。若需要手动指定，则需要指定启用的紧急程度 |
| secret | 否 | String | 日程公开程度（normal：正常(上级可见)， self：仅自己可见， dept：本部门可见， all：公开） |
| allDay | 否 | Boolean | 是否全天:false、true |
| permissionEntry | 否 | JSON | 参与人3、共享人1。permissionEntry参数详情配置见下方 |
| receiptSwitch | 否 | String | 是否开启参与人回执：close（关闭）、open（开启） |
| signType | 否 | String | 签到设置：none无、scan扫码签到、position定位签到；配置了此参数为scan或者position，需要配置signConfig参数，signConfig参数详情配置见下方 |
| signConfig | 否 | JSON | {"addrs": [] ,"clientLimit": "app、h5、pc", "signRange": "0"}，signConfig参数详情配置见下方 |
| placeType | 否 | String | 地点：other、room。如果是other：需要传place参数值。如果是room：需要传 roomIds:["684137373611106305"]，placeType参数详情配置见下方 |
