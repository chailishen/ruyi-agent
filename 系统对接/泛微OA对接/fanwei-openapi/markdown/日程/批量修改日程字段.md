# 批量修改日程字段

- **文档 ID**: `925786849436794880`
- **业务模块**: 日程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/calendar/openapi/v1/batchUpdateAgenda`
- **Content-Type**: `application/json`

## 备注

- POSTContent-Type：application/json

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| id | 是 | Long | 要修改的日程id |
| userid | 是 | Long | 操作人的id 获取用户ID |
| keyValMap | 是 | Object | 修改的属性名称和值 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| name | String | 日程名称 |
| startDate | String | 日程开始时间 |
| endDate | String | 日程结束时间 |
| manager | Long | 日程负责人 |
| secret | String | 日程公开程度1, 正常(上级可见)2, 仅自己可见4, 公开5, 本部门可见 |
| priority | String | 日程紧急程度 |
| receiptSwitch | String | 日程回执开关，（开启：open，关闭：close） |
| repeatSetting | Object | 重复日程设置 |
| entityRemind | String | 日程提醒设置 |
| calendarStatus | String | 日程状态 todo、finish |
| calendarType | Long | 日程类型 |
| signType | Object | 日程签到设置。none：不签到；scan：扫码签到；position：定位签到 |
| allDay | String | 全天设置,（开启：true，关闭：false） |
| permissionEntry | String | 参与人3、共享人1。permissionEntry参数详情配置见下方 |
| placeType | List | 地点：other、room。如果是other：需要传place；如果是room：需要传 roomIds   ["684137373611106305"]，placeType参数详情配置见下方 |
| roomId | String | 会议室号列表，如："684137373611106305,23423434324235343"，placeType=room的时候必传 |
| place | String | 地点，placeType=other的时候必传 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
