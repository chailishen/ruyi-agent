# 查询我的日程

- **文档 ID**: `908326896909893633`
- **业务模块**: 日程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/calendar/openapi/v1/queryIndexAgenda`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| employeeIds | 是 | String | 人员id，多个用，隔开 |
| deptIds | 否 | String | 部门id，多个用，隔开 |
| start | 是 | Long | 开始时间，格式：yyyy-MM-dd HH:mm |
| end | 是 | Long | 结束时间 ，格式：yyyy-MM-dd HH:mm |
| simpleEmployee | 是 | JSON | 当前人员信息 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| id | Long | 当前人员ID |
| tenantKey | String | 当前人员租户 |
| data | array | 数据列表 |
| message.errcode | string | 错误代码 |
| message.errmsg | string | 错误信息 |
| allDay | boolean | 是否是全天事件 |
| creator | object | 创建者 |
| watched | boolean | 是否已关注 |
| start | number | 开始时间 |
| end | number | 结束时间 |
| calendarTypeEntity | object | 日程类型 |
| id | string | 日程ID |
| repeatNum | number | 每周重复次数 |
| title | string | 日程标题 |
| color | string | 颜色值 |
| name | string | 类型名称 |
| name | string | 创建者姓名 |
| id | string | 创建者ID |
