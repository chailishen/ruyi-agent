# 获取当前登录人有权限的日程

- **文档 ID**: `908341542684876801`
- **业务模块**: 日程
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/calendar/openapi/v1/querySearchAgenda`
- **Content-Type**: `application/json`

## 备注

- POSTContent-Type：application/json

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userId | 是 | Long | 用户id  获取用户ID |
| tenantKey | 否 | String | 租户key |
| name | 否 | String | 日程名称 |
| beginDate | 否 | Long | 开始日期，时间戳 |
| endDate | 否 | Long | 结束日期，时间戳 |
| calendarStatus | 否 | String | 日程状态：todo进行中,finished已完结 |
| page | 否 | Integer | 页码，不填默认为1 |
| pageSize | 否 | Integer | 页大小，不填默认为10 |
