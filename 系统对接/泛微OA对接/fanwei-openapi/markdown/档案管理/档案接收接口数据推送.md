# 档案接收接口数据推送

- **文档 ID**: `301546523106213888`
- **业务模块**: 档案管理
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/archive/core/openapi/dataToArchive`
- **请求方式**: `POST`
- **Content-Type**: `application/x-www-form-urlencoded`

## 备注

- 备注:
- Body 参数格式(application/x-www-form-urlencoded)

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| employeeId | 是 | Long | 操作人 |
| xml | 是 | String | xml归档报文 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | Integer | 200 成功 |
| msg | String | 描述 |
| status | boolean | 接口处理状态 |
| data | Object | 业务处理详情 |
| xmlName | String | ftp方式时执行的xml文件名称 |
| taskId | String | 任务号 |
| dealResult | Array(Object) | 处理明细 |
| data_id | String | 档案条目id |
| msg | String | 处理情况 |
| detailFormId | String | 档案表id |
| metadata_id | String | 元数据id |
| is_pre_arc | Integer | 是否预归档（0:预归档；1:收集库） |
| state | Integer | 状态（0:成功；1:失败） |
| dealType | String | 明细类型（meta-元数据；file-文件；folder-案卷；prj-项目） |
| msg | String | 处理情况 |
