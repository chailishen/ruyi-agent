# 删除消息

- **文档 ID**: `840722719994290176`
- **业务模块**: 消息中心
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/mc/msg/deleteMsg`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| operator | 是 | Object | 操作人 |
| operator.employeeId | 是 | Long | 操作人id |
| operator.tenantKey | 是 | String | 操作人团队标识 |
| msgId | 是 | Long | 消息id，调用发送接口获取 |
| recivers | 是 | Object[] | 消息接受人，支持撤回部分人员消息时传递 |
| recivers.employeeId | 是 | long | 接受人id |
| recivers.tenantKey | 是 | string | 接受人团队标识 |
| recivers.workCode | 否 | string | 接受人工号,与employeeId二选一,优先employeeId |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| status | String | 消息发送状态 |
