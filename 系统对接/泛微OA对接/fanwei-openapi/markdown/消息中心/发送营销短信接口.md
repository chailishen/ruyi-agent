# 发送营销短信接口

- **文档 ID**: `930519980790751233`
- **业务模块**: 消息中心
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/mc/msg/sendMarketingSms`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| moduleId | 是 | String | 模块ID |
| eventId | 是 | String | 事件ID |
| sender | 是 | Object | 发送人 |
| sender.employeeId | 是 | Long | 发送人id，默认人员ID 10000 |
| sender.name | 是 | String | 发送人名称 |
| sender.tenantKey | 是 | String | 发送人团队标识 默认人员可以使用system |
| dynamicParams | 否 | map | 动态参数（当邮件和短信需要支持动态参数的时候讲参数放入此处） |
| sysContent | 否 | String | 短信内容,非模板短信时使用 |
| phones | 是 | String[] | 接受人手机号码 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| data | String | 消息中心消息Id |
| status | String | 消息发送状态 |
