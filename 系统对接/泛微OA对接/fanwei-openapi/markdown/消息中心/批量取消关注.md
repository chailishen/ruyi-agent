# 批量取消关注

- **文档 ID**: `925785895970832384`
- **业务模块**: 消息中心
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/my/watch/batchCancelWatch`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| entityIds | 是 | long[] | 事项ID集合 |
| module | 是 | String | 模块 |
| userid | 是 | long | 关注人员id |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| data | boolean | true取消关注成功 false取消关注失败 |
| status | String | 状态 |
