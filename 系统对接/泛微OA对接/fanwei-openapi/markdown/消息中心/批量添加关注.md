# 批量添加关注

- **文档 ID**: `925780746332143617`
- **业务模块**: 消息中心
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/my/watch/batchAddWatch`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| entityIds | 是 | long[] | 事项ID集合 |
| module | 是 | String | 模块 |
| userid | 是 | long | 关注人员id |
| watchNodeId | 否 | long | 文件夹ID（默认是根节点） |
| title | 否 | String | 关注事项名称（不传默认为事项名称） |
| importance | 否 | Int | 重要程度（1=一般，2=关注，3=重要） |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| data | boolean | true关注成功 false关注失败 |
| status | String | 状态 |
