# 查询关注列表

- **文档 ID**: `874507985129840640`
- **业务模块**: 消息中心
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/my/watch/queryAllWatch`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| pageSize | 是 | long | 每一页展示条数 |
| pageNo | 是 | long | 页码 |
| nodeId | 否 | string | 文件夹ID（默认是根节点） |
| s_time_tamp | 否 | string | 关注时间起（时间戳） |
| e_time_tamp | 否 | string | 关注时间止（时间戳） |
| modules | 否 | string[] | 模块 |
| name | 否 | string | 事项名称 |
| orderType | 是 | int | 排序方式（排序方式 0代表按照关注时间降序 1代表按照事项标题降序 2表示按照模块降序 3按照关注日期升序 4按照名称升序 5按照模块升序,6 重要性降序，7重要性升序） |
| creater | 是 | long | 用户id |
| importances | 否 | string[] | 重要程度(1一般，2关注，3 重要) |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| type | int | type为1的时候代表当前为文件夹为2的时候代表为事项 |
| id | int | type为1的时候代表当前为文件夹id为2的时候代表为事项id |
| treeNodeId | int | 为文件夹ID |
| pid | int | 父文件夹ID |
| name | string | 事项名称或文件夹名称 |
| pcUrl | string | 打开事项的url |
| h5Url | string | 打开事项的h5url |
