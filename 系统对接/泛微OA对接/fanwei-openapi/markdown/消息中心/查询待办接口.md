# 查询待办接口

- **文档 ID**: `874508221353041921`
- **业务模块**: 消息中心
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/my/workWait/queryWorkWaitList`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| creator | 是 | long | 待办人 |
| modules | 否 | string[] | 模块 |
| statue | 否 | int | 1 未读 2 进行中 3 已延期 |
| joinType | 否 | int | 0 我参与的 1我发起的 |
| orderType | 是 | int | 排序方式:0 按接受时间降序，1 按发起时间降序，2按接受时间升序，3按发起时间升序 |
| name | 否 | string | 事项名称 |
| pageSize | 是 | int | 每一页展示条数 |
| pageNo | 是 | int | 页码 |
| dealStatue | 是 | int | 是否稍后处理（0正常，1稍后处理） |
| templateId | 否 | string | 流程模板ID |
| s_time | 否 | string | 待办生成时间起(时间戳) |
| e_time | 否 | string | 待办生成时间止(时间戳) |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| id | long | 待办ID |
| name | string | 事项名称 |
| module | string | 事项模块 |
| waitTimeTamp | string | 待办时间戳(毫秒) |
| expireTimeTamp | string | 过期时间时间戳（毫秒） |
| readStatue | int | 已读未读状态 |
| entityId | string | 待办人ID |
| entityCreatName | string | 事项创建人姓名 |
| statue | int | 状态，0正常，1稍后处理 |
| entityCreator | int | 事项创建人 |
| unDealDay | int | 未处理时间天数 |
| colorStatue | int | 显示颜色1黄色2红色其他不显示 |
| totalPage | int | 总页数 |
| pageNo | int | 页码 |
| pageSize | int | 每一页数量 |
| unReadCount | int | 未读数量 |
| doingCount | int | 正在处理数量 |
| delayCount | int | 延期处理数量 |
| initiationCount | int | 我发起的事项列表 |
| allCount | int | 全部待办 |
| requestCode | string | 统一待办模块标识 |
| exts | string | 扩展字段（用于打开统一待办组件） |
| pcUrl | string | pc端打开事项详情url |
| h5Url | string | h5打开事项详情url |
