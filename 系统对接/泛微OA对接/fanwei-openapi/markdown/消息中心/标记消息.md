# 标记消息

- **文档 ID**: `840722792891293696`
- **业务模块**: 消息中心
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/mc/msg/markMsg`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| operator | 是 | Object | 操作人 |
| operator.employeeId | 是 | Long | 操作人id |
| operator.tenantKey | 是 | String | 操作 人团队标识 |
| operator.workCode | 否 | string | 操作人工号,与employeeId二选一,优先employeeId |
| msgIds | 是 | List | 息id数组，调用发送接口获取 |
| flag | 否 | Int | 标识，默认0，标记已读/未读, 1标记已处理/未处理 |
| statue | 否 | int | 状态，标记已读时使用 |
| entityId | 否 | String | 事项id,发送消息时，entity对象的id,企业微信，钉钉标记已处理时必填 |
| markers | 是 | list | 标记人 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| status | String | 状态 |
