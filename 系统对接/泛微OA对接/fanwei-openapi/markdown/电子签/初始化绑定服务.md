# 初始化绑定服务

- **文档 ID**: `311612542768119808`
- **业务模块**: 电子签
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/signcenter/server/initServerSetting`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| tenantKey | 是 | String | 租户key |
| accessKey | 是 | String | 接口令牌 |
| accessSecret | 是 | String | 接入密钥 |
| externalUrl | 是 | String | 契约锁签署平台外网地址 |
| intranetUrl | 否 | String | 契约锁签署平台内网地址 |
| openUrl | 是 | String | 契约锁开放平台地址 |
| serverName | 新增服务时必填，编辑时非必填 | String | 服务名称 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| oa10Secret | String | 单点加密秘钥 |
| serverId | String | 绑定服务ID，新增服务时返回 |
| corpId | String | 开放平台corpId，新增服务时返回 |
| appKey | String | 开放平台appKey，新增服务时返回 |
| appSecret | String | 开放平台appSecret，新增服务时返回 |
| ec10SyncUrl | String | 开放平台地址，新增服务时返回 |
