# 获取流程信息

- **文档 ID**: `908325891736551425`
- **业务模块**: 电子费控
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/fna/workflow/core/paService/v1/getWorkflowRequest`
- **Content-Type**: `application/json`

## 备注

- GET （Content_Type: application/json），备注：access_token放在params中

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | long | 用户ID 获取用户ID |
| requestId | 是 | long | 流程数据ID |
