# 删除文档

- **文档 ID**: `908306268118474752`
- **业务模块**: 知识文档
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/doc/document/v2/destory`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | string | 用户id 获取用户ID |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| message | object | 返回结果信息 |
| message.errcode | string | 0-成功，其他-失败 |
| message.errmsg | string | 失败原因 |
| data | array | 成功时，文档删除结果 |
| data.docDelCode | string | 状态：SUCCESS-成功，NOT_FOUND-文档不存在，NO_AUTHORITY-无权限 |
| data.ids | string | 对应状态的文档id集合 |
