# 文件下载

- **文档 ID**: `220354754872606720`
- **业务模块**: 知识文档
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/file/v2/common/download/{fileId}`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| userid | 是 | string | 用户ID 获取用户ID |
| access_token | 是 | string | 调用接口凭证 获取accessToken信息 |
| module | 否 | string | 模块 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | object | 响应码 |
| errmsg | object | 响应具体信息 |
| stream | object | 文件流（直接返回文件流） |
