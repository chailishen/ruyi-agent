# 文件夹列表

- **文档 ID**: `908316571778572288`
- **业务模块**: 知识文档
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/doc/folder/list`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | string | 用户id 获取用户ID |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| message | object | 提示信息 |
| errcode | string | 错误编码 |
| errmsg | string | 错误提示 |
| data | array | 返回数据 |
| id | string | 文件夹id |
| name | string | 文件夹名称 |
| parent | object | 父级文件夹 |
| parent.id | string | 父级文件夹id |
| parent.deleted | string | 父级文件夹是否被删除 |
| parent.transformFolderName | boolean | 父级文件夹名称是否国际化 |
| parent.permissionFromChild | boolean | 父级文件夹是否继承下级文件夹的权限 |
| type | string | 文件夹类型 |
| path | string | 文件夹路径 |
| deleted | string | 文件夹是否被删除 |
| sequence | string | 文件夹顺序 |
| transformFolderName | string | 文件夹名称是否国际化 |
| departmentId | string | 文件夹所属机构 |
| permissionFromChild | boolean | 是否继承下级文件夹的权限 |
| sourceType | string | 资源类型 |
| deleteType | string | 是否删除 |
| createTime | string | 创建时间 |
