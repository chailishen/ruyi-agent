# 文档失效

- **文档 ID**: `908313857330462721`
- **业务模块**: 知识文档
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/doc/document/v2/invalidate`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| docId | 是 | string | 文档id |
| userid | 是 | string | 用户id 获取用户ID |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| message | object | 提示信息 |
| errcode | string | 错误编码 |
| errmsg | string | 错误提示 |
