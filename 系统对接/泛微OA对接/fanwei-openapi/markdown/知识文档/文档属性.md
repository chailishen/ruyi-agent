# 文档属性

- **文档 ID**: `908308291006128128`
- **业务模块**: 知识文档
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/doc/document/v2/property`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| id | 是 | string | 文档id |
| userid | 是 | string | 用户id 获取用户ID |

| --- | --- | --- |

| validity | string | 密级有效期 |

| companyFolder | object | 公共文件夹对象 |
| sysFolder | object | 系统文件夹对象 |
| privyFolder | array | 个人文件夹集合 |
