# 文档详情-文档内容

- **文档 ID**: `908307389101326337`
- **业务模块**: 知识文档
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/doc/document/v2/info`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| id | 是 | string | 文档id |
| userid | 是 | string | 用户id 获取用户ID |
