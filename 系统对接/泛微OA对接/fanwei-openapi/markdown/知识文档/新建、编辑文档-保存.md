# 新建、编辑文档-保存

- **文档 ID**: `908312512988921857`
- **业务模块**: 知识文档
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/doc/document/v2/saveDoc`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | string | 用户id 获取用户ID |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| message | object | 返回结果信息 |
| errcode | string | 0-成功，其他-失败 |
| errmsg | string | 错误消息 |
| data | object | 文档数据 |
| id | string | 文档id |
| name | string | 文档名称 |
| creator | object | 创建人 |
| createTime | string | 创建时间 |
| lastUpdateTime | string | 最后修改时间 |
| module | string | 所属模块 |
| summary | string | HTML文档内容 |
| type | string | 类型 |
| docFile | object | 文档附件 |
| docFile.id | string | 附件id |
| docFile.refId | string | 附件所属文档id |
| docFile.name | string | 附件名称 |
| docFile.fileid | string | 附件id |
| author | object | 文档负责人对象 |
| author.id | string | 文档负责人id |
| author.username | string | 文档负责人姓名 |
| docStatus | string | 文档状态 |
| downloadCount | string | 下载次数 |
| readCount | string | 阅读次数 |
| folder | object | 所属文档 |
| folder.id | string | 所属文档id |
| contentType | string | 正文类型 |
| documentCode | string | 文档编号 |
