# 查询文件信息

- **文档 ID**: `968043207346634753`
- **业务模块**: 知识文档
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/file/v2/common/file/queryFileInfo`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |

| uploadUser | String | 上传人id |
| uploadUserName | String | 上传人姓名 |
| docId | String | 文档id |
| uploadTime | date | 上传时间 |
| smallImg | long | 压缩图下载地址 |
