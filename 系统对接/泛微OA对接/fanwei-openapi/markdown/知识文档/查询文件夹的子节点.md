# 查询文件夹的子节点

- **文档 ID**: `908315966226513921`
- **业务模块**: 知识文档
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/doc/folder/tree/subNodes`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | string | 用户id 获取用户ID |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| message | object | 提示信息 |
| errcode | string | 错误编码 |
| errmsg | string | 错误提示 |
| data | object | 返回数据 |
| nodes | array | 文件夹节点集合 |
| nodes.id | string | 文件夹id |
| nodes.content | string | 文件夹名称 |
| nodes.title | string | 文件夹名称 |
| nodes.isLeaf | string | true:无下级文件夹，false：有下级文件夹 |
| nodes.encoded | boolean | 文件夹名称是否编码 |
| nodes.type | string | 文件夹类型 |
| nodes.virtual | boolean | 是否虚拟目录 |
| nodes.empty | boolean | 是否关注目录 |
| nodes.sequence | string | 文件夹顺序 |
| nodes.virtualRootNode | boolean | 是否虚拟根目录 |
| nodes.failed | boolean | 是否查询失败 |
| nodes.leaf | boolean | true:无下级文件夹，false：有下级文件夹 |
