# 获取指定目录下的文档列表

- **文档 ID**: `908311950301487104`
- **业务模块**: 知识文档
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/doc/document/v2/folderDocList`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| message | object | 提示信息 |
| errcode | string | 错误编码(0-成功；其他:失败) |
| errmsg | string | 错误提示 |
| data | object | 返回数据 |
| docList | array | 文档列表 |
| docList.id | string | 文档id |
| docList.name | string | 文档名称 |
| docList.createTime | string | 创建时间 |
| docList.lastUpdateTime | string | 更新时间 |
| docList.orderTime | string | 排序时间 |
| docList.module | string | 所属模块 |
| docList.commentCount | string | 评论数 |
| docList.summary | string | 文档内容 |
| docList.type | string | 文档类型 |
| docList.deleted | string | 是否删除 |
| docList.docStatus | string | 文档状态 |
| docList.downloadCount | string | 下载次数 |
| docList.readCount | string | 文档阅读数 |
| docList.folder | object | 所属文件夹 |
| docList.folder.id | string | 所属文件夹id |
| docList.folder.transformFolderName | string | 所属文件夹国际化名称 |
| docList.contentType | string | 内容类型 |
| docList.praise | string | 点赞数 |
| docList.watched | boolean | 是否关注 |
| docList.unread | boolean | 是否未读（true:未读；false:已读） |
| docList.openClassifiedProtection | string | 是否开启分级保护功能 |
| docList.secLevel | string | 密级 |
| docList.validity | string | 保密期限 |
| docList.alreadySetToDoMatter | string | 已设为待办事项 |
| docList.versionId | string | 版本id |
| docList.isHistory | string | 是否历史版本 |
