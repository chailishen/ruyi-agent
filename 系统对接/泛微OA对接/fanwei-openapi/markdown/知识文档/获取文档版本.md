# 获取文档版本

- **文档 ID**: `908310258151481345`
- **业务模块**: 知识文档
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/doc/document/v2/versions`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| id | 是 | string | 文档id |
| userid | 是 | string | 用户id 获取用户ID |
| pageNo | 否 | string | 当前页，默认第1页 |
| pageSize | 否 | string | 每页显示数量，默认10条 |
| startDate | 否 | string | 支持按照时间搜索，起始日期(yyyy-MM-dd) |
| endDate | 否 | string | 支持按照时间搜索，结束日期(yyyy-MM-dd) |
| creatorId | 否 | string | 支持按人员id搜索 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| message | object | 接口信息 |
| errcode | string | 接口状态码 |
| errmsg | string | 接口描述 |
| data | object | 接口返回数据 |
| result | array | 版本结果集 |
| result.creator | string | 创建人id |
| result.versionDesc | string | 文档版本描述 |
| result.creatorName | string | 创建人名称 |
| result.restoreDocument | string | 是否能被还原 |
| result.versionNumber | string | 版本号 |
| result.currentVersion | string | 当前版本 |
| result.viewDocument | string | 是否可查看 |
| result.docStatusSpan | string | 文档状态显示名 |
| result.createTime | string | 创建时间 |
| result.doc_status | string | 文档状态 |
| result.name | string | 文档名称 |
| result.id | string | 文档id |
| result.lastUpdateTime | string | 最后一次更新时间 |
| prePage | string | 上一页页码 |
| nextPage | string | 下一页页码 |
| totalPages | string | 总页数 |
| hasNext | string | 是否有下一页 |
| totalCount | string | 总数 |
| hasPre | string | 是否有上一页 |
| first | string | 当前页起始行号 |
