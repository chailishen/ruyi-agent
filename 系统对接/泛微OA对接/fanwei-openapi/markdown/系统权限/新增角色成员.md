# 新增角色成员

- **文档 ID**: `398301605755092992`
- **业务模块**: 系统权限 / 角色成员同步
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/auth/role/user/v1/batchSave`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| operator | 必填 | Long | 操作者 |
| roleQueryRule | 必填 | AuthRoleQueryRule | 角色查询规则 |
| userRoleQueryRule | 必填 | AuthUserRoleQueryRule | 角色成员查询规则 |
| conversionRule | 必填 | ConversionRule | 人员/部门/分部/岗位/群组转换规则-群组不支持第三方主键 |
| data | 必填 | List<BatchAuthUserRoleDetail> | 角色成员数据 |
