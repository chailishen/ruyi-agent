# 查询角色

- **文档 ID**: `405519450171768832`
- **业务模块**: 系统权限 / 角色同步
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/auth/role/v1/getRoleByCondition`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| roleIdList |  | array[integer] | 角色ID列表 |
| roleCodeList |  | array[string] | 角色编码列表 |
| outKeyList |  | array[string] | 第三方外键列表 |
| filterAdmin |  | Boolean | 是否过滤管理员（包含系统管理员、分权管理员、三员管理员） |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| roleId | integer | 角色id |
| tenantKey | string | 租户key |
| roleName | string | 角色名称 |
| roleCode | string | 角色编码 |
| parentId | integer | 父级角色id |
| isDefault | string | 是否系统管理员 |
| remark | string | 备注 |
| operatorId | integer | 操作人员工id |
