# 查询角色成员

- **文档 ID**: `405523275800641536`
- **业务模块**: 系统权限 / 角色成员同步
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/auth/role/user/v1/getUserRoleByCondition`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| idList |  | array[integer] | ID列表 |
| roleIdList |  | array[string] | 角色ID列表 |
| outKeyList |  | array[string] | 第三方外键列表 |

| 参数名 | 类型 | 说明 |

| tenantKey | string | 租户key |

| userId | integer | 对象id |
| memberLevel | string | 成员级别（1-总部，2-分部，3-部门） |

| secLevelTo | integer | 最大安全级别 |
| includeFlag | Boolean | 是否含下级 |
| postFlag | Boolean | 是否含兼职人员 |
| positionLevel | integer | 岗位级别1-全部2-指定分部3-指定部门 |
| outKey | string | 第三方外键 |
| postionOrgIdList | array | 指定机构id列表 |
| userOrg | object | 组织架构权限 |
| operatorId | integer | 操作人员工id |
