# 接收流程数据

- **文档 ID**: `228363128109268992`
- **业务模块**: 系统集成 / 统一待办
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/open_intunifytodo/server_engine/receiveRequestInfo`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| syscode | 是 | String | 应用系统标识，在泛微后台【统一待办中心集成】注册（需要购买该模块），然后分配给推送方（固定值） |
| flowid | 是 | String | 第三方的流程id，相同流程需要使用相同流程id，即： 张三创建的流程提交给李四审批，这两个人的数据flowid是一致的 |
| requestname | 是 | String | 流程标题，长度不超过2000，且不允许出现： 单引号：'您有一个新的待审批事项，请及时处理'html编码字符（ |<|>等） |
| workflowname | 是 | String | 流程类型名称，正确示例：请假单 错误示例：张三2021-12-12请假单 还要注意： 长度不允许超过2000，且不允许出现：单引号：'请假单' html编码字符（ |\<|>等） |
| receivernodename | 否 | String | 接收人所属节点，长度不允许超过2000，且不允许出现：单引号：'审批节点' html编码字符（ \\<\>等） |
| nodename | 是 | String | 节点名称，长度不允许超过2000，且不允许出现：单引号：'审批节点' html编码字符（ |\\<|\>等） |
| pcurl | 否 | String | PC端地址，示例：/testPCurl/111 注意，提供的地址不允许http或者https开头，只要传相对路径即可 |
| appurl | 否 | String | APP端地址，示例：/testAppurl/222 注意，提供的地址不允许http或者https开头，只要传相对路径即可 |
| creator | 否 | String | 创建人，根据泛微后台配置（人员转换规则），可以支持： 泛微OA的人员主键 泛微OA的人员昵称 泛微OA的人员工号 泛微OA的人员身份证 泛微OA的人员邮箱 注意：没有创建人可以不传，创建人就会不显示数据 |
| createdatetime | 是 | String | 创建时间，示例：”2018-12-04 17:56:00” |
| receiver | 是 | String | 接收人，根据泛微后台配置（人员转换规则），可以支持： 泛微OA的人员主键 泛微OA的人员账号 泛微OA的人员工号 泛微OA的人员身份证 泛微OA的人员邮箱 泛微OA的手机号 注意：多个接收人可以“,”分隔，一次接收人不能超过20个 |
| receivedatetime | 是 | String | 接收时间，示例：”2018-12-04 17:56:00” |
| isremark | 是 | String | 待办处理状态，流程处理状态 0：待办 2：已办 4：办结 8：抄送（待阅） -1：删除 |
| viewtype | 是 | String | 已读状态，流程查看状态0：未读 （注：isremark = 0 且 viewtype = 0会给OA消息中心推送消息，对接钉钉、企业微信） 1：已读; |
| receivets | 是 | String | 时间戳，时间戳字段： 客户端使用异步线程调用接口的时候，根据此字段判断是否需要更新数据。（防止后发的请求数据被之前的覆盖）示例：1602817491990（毫秒级时间戳） |
| workflowcode | 是 | String | 流程类型ID，流程类型ID，与workflowname（流程类型名称）是一一对应的关系。即相同的流程类型，流程类型ID也必须相同。 |
| custom | 否 | String | 自定义字段，"custom":{ "aa":"11", "bb":"22" } aa:自定义字段名称 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| data | object | 接口调用的详细说明 |
| message.errcode | string | 状态码： 200：正常 500：系统内部错误 3000：配置异常或者调用接口参数异常，导致无法接收数据 |
| message.errmsg | string | 接口执行说明 |
| syscode | string | 调用接口时候传过来的系统标识 |
| flowid | string | 调用接口时候传过来的流程id |
| receiver | string | 调用接口时候传过来的接收人 |
| operResult | string | 1：成功 0：失败 |
| message | string | 接口执行结果描述，示例：流程数据【测试流程001】检测接收人【fyj】存在，接收待办成功 |
