# 档案集成归档同步

- **文档 ID**: `908324659109715968`
- **业务模块**: 系统集成 / 数据同步
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/intiascore/v1/doSync`
- **请求方式**: `POST`
- **Content-Type**: `application/json`

## 备注

- 备注：
- 满足三方系统（包括不限于文书定）触发E10档案集成归档同步逻辑。该请求为异步请求，在校验完所有参数信息后将会开启子线程执行同步。线程由当前服务的线程池提供，当计算资源不足无法分配线程时会返回失败（queue: 256）Content-Type类型：application/json

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| channelIds | 是 | List<String> | 归档方案ID |
| requestIds | 是 | List<String> | 流程请求ID，单次请求限制50个 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| status | Boolean | 请求状态，仅标识是否通过参数校验，并开启了子线程进行同步 |
