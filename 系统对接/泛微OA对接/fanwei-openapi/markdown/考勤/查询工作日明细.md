# 查询工作日明细

- **文档 ID**: `840692285756243969`
- **业务模块**: 考勤
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/attend/v2/getWorkDay`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userIds | 是 | List | 用户ID集合 获取用户ID |
| startDate | 是 | Date | 开始日期 (格式：YYYY-MM-DD) |
| endDate | 是 | Date | 结束日期 (格式：YYYY-MM-DD) |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| userId | Long | 用户ID |
| nextDay | String | 是否次日签退 |
| userName | String | 用户名 |
| planDays | List | 应出勤日 |
| workDays | String | 工作日 |
| normalWorkDays | String | 正常工作日（排除节假日） |
| planWorkTimes | String | 应出勤工时 |
| date | Long | 日期（时间戳） |
| period | String | 考勤时间段 |
| total | String | 应出勤时长 |
