# 查询旷工日期

- **文档 ID**: `840691766291693569`
- **业务模块**: 考勤
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/attend/v2/getAbsenteeism`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userIds | 是 | List | 用户ID集合 获取用户ID |
| startDate | 是 | Date | 开始日期 (格式：YYYY-MM-DD) |
| endDate | 是 | Date | 结束日期 (格式：YYYY-MM-DD) |
| onlyNormal | 否 | Boolean | 是否过滤申诉成功、审批通过的数据（默认false） |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| userId | Long | 用户ID |
| userName | String | 用户名 |
| dates | List | 旷工日期 |
