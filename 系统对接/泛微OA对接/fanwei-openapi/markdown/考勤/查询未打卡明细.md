| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |

| startDate | 是 | Date | 开始日期 (格式：YYYY-MM-DD) |
| endDate | 是 | Date | 结束日期 (格式：YYYY-MM-DD) |
| onlyNormal | 否 | Boolean | 是否过滤申诉成功、审批通过的数据（默认false） |
