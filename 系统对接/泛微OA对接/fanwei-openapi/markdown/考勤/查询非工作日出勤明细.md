# 查询非工作日出勤明细

- **文档 ID**: `840692466345320448`
- **业务模块**: 考勤
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/attend/v2/getPlayWork`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userIds | 是 | List | 用户ID集合 获取用户ID |
| startDate | 是 | Date | 开始日期 (格式：YYYY-MM-DD) |
| endDate | 是 | Date | 结束日期 (格式：YYYY-MM-DD) |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| userId | Long | 用户ID |
| userName | String | 用户名 |
| days | List | 日期 |
| workItems | List | 出勤明细 |
| time | String | 出勤时长 |
| date | Long | 出勤日 |
| signIn | Long | 签到时间 |
| signOut | Long | 签退时间 |
