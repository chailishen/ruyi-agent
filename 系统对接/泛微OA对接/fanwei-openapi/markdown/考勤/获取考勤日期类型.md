# 获取考勤日期类型

- **文档 ID**: `347855715148234752`
- **业务模块**: 考勤
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/attend/web/open/getDayTypeByAttendDate`
- **请求方式**: `POST`
- **Content-Type**: `application/json`

## 备注

- **备注：**body传参格式为application/json

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| attendDate | 是 | String | 考勤日期yyyy-MM-dd |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | String | 日期类型 |
