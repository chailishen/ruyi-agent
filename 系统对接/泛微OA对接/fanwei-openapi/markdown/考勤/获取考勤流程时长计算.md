# 获取考勤流程时长计算

- **文档 ID**: `263841872810606592`
- **业务模块**: 考勤
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/attend/web/open/getFlowDuration`
- **请求方式**: `POST`
- **Content-Type**: `application/json`

## 备注

- 备注：body传参格式为application/json
- 备注：body传参格式为application/json

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| appealType | String | 类型 |
| applicant | String | 需计算时长的人员id |
| type | String | appealType是请假或者销假时对应请假类型id |
| beginTime | String | 开始日期时间 |
| endTime | String | 结束日期时间 |
| errcode | String | 接⼝响应状态码 |
| errmsg | String | 接⼝响应描述 |
| duration | String | 时长(根据请假类型时长动态匹配) |
| duration_hour | String | 时长(固定单位小时) |
| duration_day | String | 时长(固定单位天) |
