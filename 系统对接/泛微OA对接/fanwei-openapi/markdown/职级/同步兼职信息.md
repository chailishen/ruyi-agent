# 同步兼职信息

- **文档 ID**: `949484876885180417`
- **业务模块**: 职级
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/hrm/restful/syncExtra`
- **请求方式**: `POST`
- **Content-Type**: `application/json`

## 备注

- 备注:
- Body 参数格式(application/json)

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| data | 是 | Array[Object] | 岗位对象 |
| externalSyncType | 否 | String | 同步类型（客户可能会集成多种同步类型；内容可以自定义，但是相同来源的externalSyncId要保证唯一） |
| externalSyncId | 否 | String | 同步外键id（同步的时候，外键id与employeeid唯一确认一条数据；外键id保证租户内唯一） |
| departmentId | 否 | String | 兼职部门 |
| deleted | 是 | Integer | 是否删除（1 删除；0 否） |
| positionId | 是 | String | 兼职岗位 |
| id | 是 | String | 所属人员 |
| superiorId | 是 | String | 兼职上级 |
| remark | 是 | String | 备注 |
| dataRule | 是 | Object | 同步规则 |
| employee | 是 | String | 岗位规则（id:按照岗位id来检查；name:按照岗位名称来检查；code:按照岗位编号来检查） |
| department | 是 | String | 部门检测规则（id:按照部门id来检查；name:按照组织名称来检查；code:按照部门编号来检查） |
| dataInited | 是 | boolean |  |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | Integer | 200 成功 |
| msg | String | 描述 |
| data | Array[Object] | 人员id |
| keyValue | String | 数据唯一字段值 |
| status | String | 状态（SUCCESS 成功；ERROR 失败） |
| errcode | String | 失败原因 |
| needRepush | boolean | 是否重推 |
