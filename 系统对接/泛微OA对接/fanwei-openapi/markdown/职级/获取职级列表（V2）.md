# 获取职级列表（V2）

- **文档 ID**: `840674517703032833`
- **业务模块**: 职级
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/grade/v2/list`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| gradeId | 否 | Long | 职级ID（不传时，获取企业整个职级列表） |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| grade | List | 职级信息 |
| name | String | 职级名称 |
| disporder | Int | 序号 |
| code | String | 编码 |
| createTime | Date | 创建时间 |
| ts | Date | 最后更新时间 |
| id | String | 职级ID |
| delete | Boolean | 是否已删除，true表示已经被删除，false表示未被删除 |
