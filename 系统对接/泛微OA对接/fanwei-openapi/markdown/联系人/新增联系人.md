# 新增联系人

- **文档 ID**: `840675604078100481`
- **业务模块**: 联系人
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/crm/v2/create`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| module | 是 | String | 模块固定为：contact |
| entity | 是 | Object | 联系人信息 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| name | String | 名称 |
| manager | String | 负责人 |
| contactBelongCustomer | String | 联系人所属客户 |
| contactTitle | String | 联系人头衔 |
| contactCall | String | 联系人称呼 |
| contactTelephone | String | 联系人电话 |
| contactPhoneNumber | String | 联系人手机 |
| contactEmail | String | 联系人邮箱 |
| contactSex | String | 联系人性别，1男、2女、3未知 |
| contactInterest | String | 联系人兴趣 |
| contactDescription | String | 联系人备注 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | String | 联系人信息（JSON格式） |
