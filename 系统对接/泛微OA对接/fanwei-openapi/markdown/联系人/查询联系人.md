# 查询联系人

- **文档 ID**: `840675715789193217`
- **业务模块**: 联系人
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/crm/v2/get`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| module | 是 | String | 模块固定取值：contact |
| id | 是 | Long | 联系人ID 获取联系人ID |
