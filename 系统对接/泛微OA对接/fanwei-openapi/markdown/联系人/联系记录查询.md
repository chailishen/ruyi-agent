# 联系记录查询

- **文档 ID**: `213108361086894080`
- **业务模块**: 联系人
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/crm/v2/employeeComment`
- **请求方式**: `POST`

## 备注

- 备注：传参格式为 'Content-Type': 'application/x-www-form-urlencoded'
- 备注：commentFilter参数信息（id,type,operate按照以下内容固定传值，id目前仅支持content|commentor|commentorName|add_time，value根据需求情况填写，orderBy仅支持content|commentor|add_time，orderWay仅支持desc | asc）

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | String | 用户ID 获取用户ID |
| module | 是 | String | 模块，可多传用逗号隔开，例如目前仅已支持customer,saleChance,contract,clue,production,competitor |
| permissionType | 是 | String | 权限类型，固定值mineMgrAndSubMgr |
| pageNo | 否 | String | 默认值1，小于1按1查询 |
| pageSize | 否 | String | 默认值100,超过3000按3000查询 |
| commentFilter | 否 | String | 条件参数，json格式，详细如下 |
