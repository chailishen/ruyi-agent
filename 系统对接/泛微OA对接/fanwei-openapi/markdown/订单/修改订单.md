# 修改订单

- **文档 ID**: `840717724830760961`
- **业务模块**: 订单
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/crm/v2/update`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| module | 是 | String | 模块固定为：orderform |
| entity | 是 | Object | 订单信息 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| id | String | 订单ID 获取订单ID |
| name | String | 订单名称 |
| manager | String | 负责人 |
| orderformCustomer | String | 客户 |
| orderformContract | String | 订单合同 |
| orderformStatus | String | 状态 |
| orderformType | String | 类型 |
| orderformUnit | String | 单位 |
| orderformPayMethod | String | 支付方式 |
| orderformNumber | String | 编号 |
| orderformTotalMoney | Double | 总金额 |
| orderformStartTime | Date | 下单日期 |
| orderformEndTime | Date | 结单日期 |
| orderformDescription | String | 备注 |
| dataMap | Object | 通用自定义字段 获取自定义表单字段 传值说明 |
| typeDataMap | Object | 专用自定义字段 获取自定义表单字段 传值说明 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | Object | 订单信息（JSON格式） |
