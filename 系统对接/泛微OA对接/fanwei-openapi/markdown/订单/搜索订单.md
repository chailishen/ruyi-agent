# 搜索订单

- **文档 ID**: `840717943881605121`
- **业务模块**: 订单
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/crm/v2/search`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| module | 是 | String | 模块固定取值：orderform |
| query | 是 | Object | 查询参数对象 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| pageNo | Int | 页码 |
| pageSize | Int | 每页显示条数 |
| orderPropertyName | String | 排序字段name |
| asc | String | true升序，false降序 |
| conditions | List | 查询条件集 |
| propertyName | String | 属性名 |
| compareType | String | 比较类型 |
| propertyValue | String | 属性值 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | Object | 订单信息（JSON格式） |
