# 获取增删改的订单

- **文档 ID**: `840718141517209600`
- **业务模块**: 订单
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/crm/v2/getChanged`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | string | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| module | 是 | string | 模块（固定为orderform） |
| query | 是 | Object | 查询参数对象 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| pageNo | Int | 页码，默认1 |
| pageSize | Int | 每页显示条数，默认15 |
| type | string | 新增 create、修改update、删除delete、作废invalid |
| startTime | string | 开始日期，例如：2020-05-06 |
| endTime | string | 截止日期，例如：2020-05-07 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | Object | 订单信息（JSON格式） |
