# 订单搜索期次、回款、付款、开票等

- **文档 ID**: `840718519633715200`
- **业务模块**: 订单
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/crm/v2/searchPayment`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | String | 是 | 调用接口凭证 |
| userid | String | 是 | 用户ID |
| module | String | 是 | 模块。暂时只支持订单模块（orderform） |
| query | Object | 是 | 查询参数对象 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| paymentType | String | 查询类型，固定值：回款receive、付款pay |
| paymentEntityType | String | 查询对象的类型，固定值： 期次stage、回款/付款paid、开票invoice、抵扣deduction 、扣款chargeback、预回款/预付款prepaid |
| entityId | Long | 实体ID，如订单ID |
| entityName | String | 实体名称，如订单名称，模糊查询 |
| stageId | Long | 期次ID |
| pageNo | Int | 页码 |
| pageSize | Int | 每页条数 |
| orderPropertyName | String | 排序字段名称 |
| asc | String | true升序，false降序 |
| conditions | List | 查询条件集 |
| propertyName | String | 属性名 |
| compareType | String | 比较类型 |
| propertyValue | String | 属性值 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | Object | 期次等信息（JSON格式） |
