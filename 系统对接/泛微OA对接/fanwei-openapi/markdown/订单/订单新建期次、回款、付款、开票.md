# 订单新建期次、回款、付款、开票

- **文档 ID**: `840718218994393089`
- **业务模块**: 订单
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/crm/v2/addPayment`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | String | 是 | 调用接口凭证 |
| userid | String | 是 | 用户ID |
| module | String | 是 | 模块。暂时只支持订单模块（orderform） |
| entity | String | 是 | 期次等信息 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| paymentEntityType | 是 | 创建对象的类型，固定值： 期次stage、回款/付款paid、开票invoice、抵扣deduction、扣款chargeback、预回款/预付款prepaid |
| entityId | 是 | 实体ID，如订单ID |
| plannedMoney | 否 | 期次计划金额 |
| plannedTime | 否 | 期次计划时间，默认创建时间 |
| description | 否 | 备注 |
| stageId | 是 | 期次ID |
| paidMoney | 是 | 回（付）款金额 |
| paidTime | 否 | 回（付）款时间，默认创建时间 |
| exchangeRate | 否 | 汇率 |
| defaultUnit | 否 | 换算单位 |
| chargebackMoney | 否 | 扣款金额 |
| chargebackTime | 否 | 扣款时间，默认创建时间 |
| chargebackItems | 是 | 扣款条目、capitalAccount 扣款账户、amount 扣款金额 |
| capitalAccount | 是 | 扣款账户 |
| amount | 是 | 扣款金额 |
| deductionMoney | 是 | 抵扣金额 |
| deductionTime | 否 | 抵扣时间，默认创建时间 |
| deductionItem | 是 | 抵扣项目 |
| invoiceMoney | 是 | 开票金额 |
| invoiceTime | 否 | 开票时间，默认创建时间 |
| invoiceType | 是 | 开票类型 |
| invoiceNumber | 是 | 发票号码 |
| taxNumber | 否 | 税号 |
| content | 否 | 开票内容 |
| prepaidMoney | 是 | 预回（付）款金额 |
| prepaidTime | 否 | 预回（付）款时间，默认创建时间 |
| prepaidAccount | 是 | 资金账户 |
| prepaidMethod | 否 | 预回（付）款方式 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | Object | 期次等信息（JSON格式） |
