# 订单查询期次、回款、付款、开票等

- **文档 ID**: `840718455092641792`
- **业务模块**: 订单
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/crm/v2/getPayment`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | String | 是 | 调用接口凭证 |
| userid | String | 是 | 用户id |
| module | String | 是 | 模块。暂时只支持订单模块（orderform） |
| id | Long | 是 | 期次等信息ID |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
