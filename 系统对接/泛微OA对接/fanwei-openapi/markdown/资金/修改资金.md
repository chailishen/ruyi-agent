# 修改资金

- **文档 ID**: `840676214030565376`
- **业务模块**: 资金
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/crm/v2/update`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| module | 是 | String | 模块固定为：capital |
| entity | 是 | Object | 资金信息 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| id | Long | 资金ID 获取资金ID |
| name | String | 名称 |
| userid | String | 用户ID |
| module | String | 模块（固定为capital） |
| entity | Object | 资金信息 |
| name | String | 资金名称 |
| manager | String | 负责人 |
| capitalStatus | String | 状态 |
| capitalCustomer | String | 客户 |
| capitalUnit | String | 货币单位 |
| capitalDescription | String | 备注 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | Object | 资金信息（JSON格式） |
