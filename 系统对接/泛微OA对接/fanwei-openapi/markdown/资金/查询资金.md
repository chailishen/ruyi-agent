# 查询资金

- **文档 ID**: `840676252625674241`
- **业务模块**: 资金
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/crm/v2/get`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| module | 是 | String | 模块固定取值：capital |
| id | 是 | Long | 资金ID 获取资金ID |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| data | Object | 资金信息（JSON格式） |
