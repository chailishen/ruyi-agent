# 资金充值

- **文档 ID**: `840677653011505153`
- **业务模块**: 资金
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/crm/v2/rechargeCapital`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| entity | 是 | Object | 充值信息 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| capital | Object | 充值资金 |
| capitalCustomer | Object | 充值客户（用于获取充值资金） |
| capitalAccount | Object | 充值账户 |
| accountAmount | Double | 充值金额 |
| accountOperTime | Date | 充值时间 |
| accountRecMethod | Object | 收款方式 |
| accountDescription | String | 备注 |
| accountExchangeRate | Double | 汇率 |
| accountDefaultUnit | Object | 换算单位 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
