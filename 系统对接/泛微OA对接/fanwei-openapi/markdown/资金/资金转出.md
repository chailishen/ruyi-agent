# 资金转出

- **文档 ID**: `840677695952789505`
- **业务模块**: 资金
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/crm/v2/divertCapital`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | true | String | 调用接口凭证 获取accessToken信息 |
| userid | true | Long | 用户ID 获取用户ID |
| entity | true | Object | 转出信息 |
| capital | false | Object | 资金 |
| capitalCustomer | false | Object | 客户（用于获取资金数据） |
| capitalAccount | true | Object | 转出账户 |
| accountAmount | true | Double | 转出金额 |
| accountOperTime | false | Date | 转出时间 |
| accountDescription | false | String | 备注 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
