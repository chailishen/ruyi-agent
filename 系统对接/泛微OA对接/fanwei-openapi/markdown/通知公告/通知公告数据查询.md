# 通知公告数据查询

- **文档 ID**: `908325054167597056`
- **业务模块**: 通知公告
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/placard/v1/allDatas`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| pageNo | 否 | int | 当前页数 |
| pageSize | 否 | int | 每页条数 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 状态码 |
| msg | String | 提示信息 |
| status | String | 数据保存状态 |
| fail | boolean | 是否失败 |
| data | JSON | 分页数据 |
| placards | array | 公告明细 |
| pageNo | int | 当前页数 |
| pageSize | int | 每页行数 |
| totalCount | int | 公告总数 |
