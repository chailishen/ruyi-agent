# 发送内部邮件

- **文档 ID**: `231135372178882560`
- **业务模块**: 邮件
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/mail/send/v1/sendInternalMail`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| fromid | 是 | String | 发送人工号 |
| toids | 是 | String | 收件人工号列表串 |
| ccids | 否 | String | 抄送人工号列表串 |
| bccids | 否 | String | 密送人工号列表串 |
| subject | 是 | String | 邮件主题（纯文本） |
| content | 是 | String | 邮件内容（纯文本） |
| paths | 否 | String | 附件存放路径地址列表串 |
| fileIds | 否 | String | 附件ID，多个附件英文逗号分隔 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | String | 返回码 |
| msg | String | 返回信息 |
| status | String | 接口状态 |
| data | int | 发件结果0：失败，1：成功 |
