# 同步分部

- **文档 ID**: `949479748799578113`
- **业务模块**: 部门
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/api/hrm/restful/syncSubcompany`
- **请求方式**: `POST`
- **Content-Type**: `application/json`

## 备注

- 备注:
- Body 参数格式(application/json)

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| data | 是 | Array[Object] | 分部对象 |
| name | 是 | String | 分部名称 |
| fullname | 否 | String | 分部全称 |
| code | 否 | String | 分部编号 |
| parent | 是 | String | 上级分部（只能是分部；与【字段校验规则-组织规则】相关；例如：规则是编号，内容提供编号） |
| disporder | 否 | Integer | 显示顺序 |
| coadjutant | 否 | String | 协办人（与【字段校验规则-人员规则】相关；例如：规则是编号，内容提供编号） |
| status | 否 | String | 是否启用（1:启用；0: 禁用） |
| id | 否 | String | 主键（当【字段校验规则-组织规则】为id的时候；修改分部需要提供，其他不需要） |
| description | 否 | String | 备注 |
| subcompanyExtend | 否 | Object | 分部自定义 |
| {fieldId} | 否 | [k,v] | 分部信息自定义字段 |
| multiObj | 否 | Object | 多语言 |
| name | 否 | [k,v] | 数据示例格式：{“7”:"张三","8":"zhangshan"};其中 7 表示中文，8 表示英文；其他语言类型需要咨询多语言模块 |
| fullname | 否 | [k,v] | 数据示例格式：{“7”:"张三","8":"zhangshan"};其中 7 表示中文，8 表示英文；其他语言类型需要咨询多语言模块 |
| dataRule | 是 | Object | 数据规则（字段校验规则；比如指定人员规则是名称，就按照名称规则检查唯一，如果查询到则更新；否则新增） |
| department | 是 | String | 组织（含分部、部门）规则（id:按照组织id来检查；name:按照组织名称来检查；code:按照组织编号来检查） |
| employee | 否 | String | 人员规则（id: 按照人员id来检查;username：按照名称检查；job_num: 按照编号来检查；） |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| code | Integer | 200 成功 |
| msg | String | 描述 |
| data | Array[Object] | 人员id |
| keyValue | String | 数据唯一字段值 |
| operate | String | add 新增、update 修改 |
| status | String | 状态（SUCCESS 成功；ERROR 失败） |
| errcode | String | 失败原因 |
| needRepush | boolean | 是否重推 |
| status | boolean | false 失败；true 成功 |
