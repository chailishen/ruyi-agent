# 按更新时间查询部门信息

- **文档 ID**: `840674221332635649`
- **业务模块**: 部门
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/department/v2/findUpdateDepartment`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| beginDate | 是 | Date | 开始时间，格式(yyyy-MM-dd HH:mm:ss) |
| endDate | 是 | Date | 结束时间，格式(yyyy-MM-dd HH:mm:ss) |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| department | List | 部门信息 |
| name | String | 部门名称 |
| rank | Int | 层级 |
| description | String | 部门备注信息 |
| id | String | 部门ID |
| code | String | 部门编码 |
| parent | Object | 父部门信息 |
