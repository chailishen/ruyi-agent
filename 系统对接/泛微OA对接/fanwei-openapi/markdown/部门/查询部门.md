# 查询部门

- **文档 ID**: `840674143989669888`
- **业务模块**: 部门
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/department/v2/get`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| depid | 是 | String | 部门ID 获取部门ID |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| department | List | 部门信息 |
| name | String | 部门名称 |
| rank | Int | 层级 |
| parent | Object | 父部门信息 |
| id | String | 部门ID |
