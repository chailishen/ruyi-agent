# 查询部门列表

- **文档 ID**: `840674178265522177`
- **业务模块**: 部门
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/department/v2/list`
- **请求方式**: `GET`

## 备注

- 备注：

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| depid | 否 | Long | 部门ID（不传时，获取企业整个部门列表） |
| status | 否 | String | 启用状态（默认 启用; 0 禁用; all 查询全部） |
| isDelete | 否 | String | 是否删除（默认 未删除; 1 删除; all 查询全部） |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| department | List | 部门信息 |
| name | String | 部门名称 |
| rank | Int | 层级 |
| description | String | 部门备注信息 |
| id | String | 部门ID |
| parent | Object | 父部门信息 |
| delete | Boolean | 是否删除 (false,未删除; true 删除) |
| status | Boolean | 是否禁用 (true,启用 ; false 停用) |
