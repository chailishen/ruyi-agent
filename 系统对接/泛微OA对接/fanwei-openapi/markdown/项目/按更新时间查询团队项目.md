# 按更新时间查询团队项目

- **文档 ID**: `840678301375406081`
- **业务模块**: 项目
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/mainline/v2/queryUpdateMainlines`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| startTime | 是 | Date | 开始时间，格式(yyyy-MM-dd HH:mm:ss) |
| endTime | 是 | Date | 结束时间，格式(yyyy-MM-dd HH:mm:ss) |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| message | Object | 返回信息对象 |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
| mainlines | List<Object> | 项目对象集合 |
| name | String | 项目名称 |
| createTime | Date | 创建时间 |
| startTime | Date | 起始日期 |
| endTime | Date | 到期日期 |
| description | String | 项目描述 |
| percentFinished | String | 进度 |
| icon | String | 项目图标 |
| finished | Boolean | 是否完成 |
| locked | Boolean | 是否锁定 |
| status | String | 状态 |
| module | String | 所属模块 |
| finishTime | Date | 结束时间 |
| manager | Object | 负责人 |
| creator | Object | 创建者 |
| isDelete | Boolean | 是否已删除 |
| groupId | Long | 项目分类ID |
| groupName | String | 项目分类名称 |
| tenantKey | String | 团队key |
| id | Long | 项目ID |
| stage | List | 项目的计划任务分组信息 |
