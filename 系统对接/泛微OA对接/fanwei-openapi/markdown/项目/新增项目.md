# 新增项目

- **文档 ID**: `840677846276644864`
- **业务模块**: 项目
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/mainline/v2/create`
- **请求方式**: `POST`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| userid | 是 | Long | 用户ID 获取用户ID |
| name | 是 | String | 项目名称 |
| description | 否 | String | 项目详情 |
| startTime | 否 | Date | 起始日（yyyy-MM-dd） |
| endTime | 否 | Date | 到期日（yyyy-MM-dd） |
| commonFormData | 否 | String | 通用字段数据 传值说明 |
| formId | 否 | Long | 自定义字段表单ID 查询表单ID |
| mainlineGroupFormData | 否 | String | 自定义字段数据 传值说明 |
| tailNum | 否 | String | 类型开启手动编码时生效 |

## 返回参数

| 参数名 | 类型 | 说明 |
| --- | --- | --- |
| errcode | String | 返回码 |
| errmsg | String | 返回信息 |
