# 查询项目

- **文档 ID**: `840677992221646849`
- **业务模块**: 项目
- **是否 API 接口**: 是
- **请求 URL**: `{OpenApiOrigin}/mainline/v2/info`
- **请求方式**: `GET`

## 请求参数

| 参数名 | 必选 | 类型 | 说明 |
| --- | --- | --- | --- |
| access_token | 是 | String | 调用接口凭证 获取accessToken信息 |
| id | 是 | Long | 项目ID 获取项目ID |
