# 教师端操作手册

## 文档说明

本手册面向使用 X-AI LAB 人工智能实训平台的教师用户，指导教师完成课程建设、班级管理、学员管理、作业与考试发布、实训项目配置、AI 辅助教学和数据查看等日常教学操作。

**适用角色：** 教师、课程运营人员

**访问地址：** 登录平台后，进入教师后台（地址示例：`xailab.com.cn/teacher/dashboard`）

**左侧导航菜单总览：**

| 菜单分组 | 菜单项 |
|---------|--------|
| — | 概览总览 |
| — | 课程研究 |
| — | AI课件 |
| — | 班级管理 |
| 课程管理 | 实训课、专题课、视频课、音频课、图文课、素材库、直播课、直播课表 |
| 实训项目 | Jupyter项目、数据集 |
| 考试管理 | 试卷库、题目库 |
| — | 算力账户 |

## 一、概览总览

### 1.1 功能说明

概览总览是教师进入后台后的首页，集中展示教学相关的核心数据指标、排行榜、店铺信息、常用功能入口和店铺通知，帮助教师快速了解当前教学运营概况。

### 1.2 页面布局

![概览总览](../实训项目截图/教师端/概览总览/概览总览.png)

页面分为以下区域：

**数据统计区（左上）：** 展示在售课程数、课程待审核数、在售班级数、班级待审核数、免费课程数、付费���程数、免费班级数、付费班级数等核心指标。

**排行榜区（左中）：** 展示课程销量排行榜 TOP10 和课程访问排行榜 TOP10，可查看课程名称、销量和访客数。

**店铺信息区（右上）：** 展示当前教师店铺名称、可提现金额、已提现金额和总收益。点击「提现」按钮可发起提现操作。

**常用功能区（右中）：** 提供视频课、班级、素材库、试卷库、题目库等常用功能的快捷入口图标，点击即可跳转到对应功能页面。

**店铺通知区（右下）：** 展示平台发送的系统通知和消息提醒。

### 1.3 操作说明

#### 切换排行榜统计周期

![切换排行榜统计周期](../实训项目截图/教师端/概览总览/概览总览-排行榜-切换统计周期区间.png)

1. 在排行榜区域，点击统计周期下拉框。
2. 可选择「自然天」「自然周」「自然月」「自然年」。
3. 选择后，排行榜数据将按所选周期重新统计展示。

#### 查看交易概况

![交易概况](../实训项目截图/教师端/概览总览/概览总览-交易概况-切换统计周期区间.png)

1. 向下滚动页面，可查看交易概况图表。
2. 图表展示下单人数、支付人数、成交订单数和总订单数的趋势。
3. 可通过下拉框切换统计周期（自然天、自然周、自然月、自然年），并选择具体日期。

#### 发起提现

![提现](../实训项目截图/教师端/概览总览/概览总览-店铺信息-提现.png)

1. 在店铺信息区，查看可提现金额。
2. 点击「提现」按钮，按照提示完成提现操作。

## 二、课程研究

### 2.1 功能说明

课程研究是平台为教师提供的 AI 助教智能体功能。教师可以通过自然语言对话的方式，获取课程设计建议、教学方案、实训任务体系设计、课程大纲生成等辅助内容，帮助教师快速研发新课和迭代教学内容。

### 2.2 页面布局

![课程研究](../实训项目截图/教师端/课程研究/课程研究.png)

页面左侧为对话管理区，包含「新对话」按钮和聊天历史记录列表；右侧为对话交互区，教师在输入框中输入问题，AI 将生成回答。

### 2.3 操作说明

#### 发起新对话

1. 点击左侧「新对话」按钮，开启一个新的对话会话。
2. 在底部输入框中输入您的问题或需求，例如：
   - "针对零基础和有编程基础的混合班级，如何设计分层的实训任务体系？"
   - "如何将 Python 编程课程与人工智能应用结合？"
   - "请为软件工程专业设计一套大模型应用开发课程大纲。"
3. 点击发送按钮（蓝色箭头图标），等待 AI 生成回答。

![课程研究-新对话](../实训项目截图/教师端/课程研究/课程研究-新对话.png)

#### 查看历史对话

1. 在左侧聊天历史列表中，可查看之前的对话记录。
2. 点击任意历史对话，即可在右侧查看完整的对话内容。

#### 使用建议

- 提问时尽量描述清楚教学场景、学生基础、课程方向等背景信息，AI 将给出更有针对性的建议。
- 可将 AI 生成的课程大纲、教学方案等内容复制后用于课程创建。

## 三、AI课件

### 3.1 功能说明

AI课件功能支持教师上传 PDF 课件文件，由 AI 自动为每一页课件生成讲解脚本，并可合成为课程讲解视频。教师可以编辑讲稿内容、设置讲解音色、进行音色克隆，最终生成带有语音讲解的课程视频，大幅降低课件视频制作成本。

### 3.2 课件列表

![AI课件列表](../实训项目截图/教师端/AI课件/AI课件.png)

进入 AI课件页面后，展示当前教师已上传的所有课件列表，包含以下信息：
- **名称：** 课件文件名称
- **视频时长：** 生成视频的时长（未生成时显示"—"）
- **生成状态：** 未生成 / 生成中 / 已生成
- **更新时间：** 最近一次编辑时间
- **操作：** 编辑、删除

### 3.3 操作说明

#### 上传课件

![上传课件-本地上传](../实训项目截图/教师端/AI课件/AI课件-上传文件-本地上传.png)

1. 点击「上传文件」按钮。
2. 选择上传方式：
   - **本地上传：** 从本地电脑选择 PDF 文件上传。
   - **素材库选择：** 从平台素材库中选取已有的课件文件。

![上传课件-素材库选择](../实训项目截图/教师端/AI课件/AI课件-上传文件-素材库选择.png)

3. 上传成功后，课件将出现在列表中，生成状态为「未生成」。

#### 编辑课件讲稿

![编辑课件](../实训项目截图/教师端/AI课件/AI课件-编辑.png)

1. 在课件列表中，点击对应课件的「编辑」按钮。
2. 进入编辑页面后，左侧展示课件各页的缩略图，点击任意页面可切换到对应页面。
3. 右侧展示当前页面的大图预览，下方为讲稿编辑区域。
4. 在讲稿输入框中编写或修改该页的讲解文案。
5. 页面上方提供以下功能按钮：
   - **重新上传：** 替换当前课件文件（支持本地上传和素材库选择）。
   - **重写全局讲稿：** 让 AI 重新为所有页面生成讲稿。
   - **生成视频：** 基于当前讲稿生成讲解视频。
   - **导出视频：** 将已生成的视频导出下载。
   - **播放视频：** 预览已生成的视频。

#### 讲稿润色优化

![润色优化](../实训项目截图/教师端/AI课件/AI课件-编辑-润色优化.png)

1. 在编辑页面，选中某页讲稿后，点击「润色优化」。
2. 可选择以下优化方式：
   - **更加专业化：** 将讲稿调整为更专业的学术风格。
   - **更加口语化：** 将讲稿调整为更通俗易懂的口语风格。
   - **讲稿扩写：** 在现有内容基础上扩展讲解细节。
   - **讲稿缩写：** 精简现有讲稿内容。

![润色优化-确认使用](../实训项目截图/教师端/AI课件/AI-编辑-润色优化-确认使用文案.png)

3. AI 生成优化后的文案后，预览内容，点击「确认使用文案」应用到当前页面。

#### 音色设置

![音色设置](../实训项目截图/教师端/AI课件/AI课件-编辑-音色设置.png)

1. 在编辑页面，点击「音色设置」图标。
2. 从系统预置的音色列表中选择合适的讲解音色。
3. 点击「试听」可预听音色效果。
4. 确认后点击「确定使用」。

#### 音色克隆

![音色克隆](../实训项目截图/教师端/AI课件/AI课件-编辑-音色克隆.png)

教师可以克隆自己的声音用于课件讲解：

**方式一：上传声音文件**

![上传声音](../实训项目截图/教师端/AI课件/AI课件-编辑-音色克隆-上传声音.png)

1. 点击「音色克隆」，选择「上传声音」。
2. 上传一段清晰的语音录音文件。
3. 点击「开始复刻」，系统将基于上传的语音生成个性化音色。
4. 复刻完成后，可试听效果，满意则点击「确认复刻」，不满意可点击「重新复刻」。

**方式二：在线录制**

![在线录制](../实训项目截图/教师端/AI课件/AI课件-编辑-音色克隆-开始录制.png)

1. 点击「音色克隆」，选择「开始录制」。
2. 按照系统提示朗读指定文本内容，录制一段语音。
3. 录制完成后，点击「开始复刻」生成个性化音色。
4. 试听效果后确认或重新复刻。

#### 生成视频

![生成视频](../实训项目截图/教师端/AI课件/AI；课件-编辑-生成视频.png)

1. 确认所有页面的讲稿内容和音色设置无误后，点击页面右上角「生成视频」按钮。
2. 系统将自动合成每页课件 + 讲稿语音的讲解视频。
3. 生成完成后，可通过「播放视频」预览效果，或通过「导出视频」下载到本地。

#### 删除课件

![删除课件](../实训项目截图/教师端/AI课件/AI课件-删除.png)

1. 在课件列表中，点击对应课件的「删除」按钮。
2. 在确认弹窗中点击「确定」完成删除。

> **注意：** 删除操作不可恢复，已生成的视频也将一并删除，请谨慎操作。

## 四、班级管理

### 4.1 功能说明

班级管理是教师组织教学活动的核心模块。教师可以创建班级、关联课程、管理学员和教师成员、发布作业和考试、管理公告和评论、颁发证书等。班级是课程与学员之间的桥梁，所有教学活动都围绕班级展开。

### 4.2 班级列表

![班级管理列表](../实训项目截图/教师端/班级管理/班级管理.png)

班级列表页展示当前教师创建的所有班级，包含以下信息：
- **班级名称：** 班级封面图和名称、价格
- **学员数：** 当前加入班级的学员人数
- **课程数：** 班级关联的课程数量
- **审核类型：** 内容变更等
- **审核状态：** 审核成功、未提交审核、审核失败等
- **发布状态：** 已发布、未发布
- **操作：** 班级管理、编辑、更多操作

页面顶部提供以下筛选和操作功能：
- 按班级名称搜索
- 按发布状态、是否收费、审核类型、审核状态筛选
- 按创建时间区间筛选
- 「新建班级」按钮
- 「提交审核」按钮（批量提交）

### 4.3 新建班级

#### 步骤一：填写基础信息

![新建班级-基础信息](../实训项目截图/教师端/班级管理/班级管理-新建班级-基础信息.png)

1. 点击「新建班级」按钮，进入新建班级页面。
2. 填写以下基础信息：
   - **所属分类（必填）：** 从下拉列表中选择班级所属的课程分类。
   - **班级名称（必填）：** 输入班级名称，不超过 70 个字符。
   - **所属学期：** 选择班级所属学期。
   - **培养方向：** 选择培养方向。
   - **宣传封面（必填）：** 上传班级封面图片，建议尺寸 900×500px，图片小于 2M，支持 JPG、PNG 格式。
   - **班级描述（必填）：** 输入班级简要描述，不超过 240 个字符。
   - **班级介绍：** 使用富文本编辑器编写班级详细介绍，支持插入图片、视频、链接等。

#### 步骤二：配置班级设置

![新建班级-班级设置](../实训项目截图/教师端/班级管理/班级管理-新建班级-班级设置.png)

1. 点击「保存并前往添加内容」或切换到班级设置标签页。
2. 配置以下选项：
   - 班级有效期
   - 加入方式（免费加入、付费加入等）
   - 价格设置
   - 学员人数上限
   - 其他相关设置

#### 步骤三：其他设置

![新建班级-其他设置](../实训项目截图/教师端/班级管理/班级管理-新建班级-其他设置.png)

1. 根据需要配置其他高级设置项。
2. 完成所有设置后，点击「保存」按钮保存班级信息。

> **注意：** 班级创建后处于未发布状态，需要提交审核通过后方可发布。

### 4.4 班级详情管理

点击班级列表中的「班级管理」链接，进入班级详情管理页面。页面顶部展示班级基本信息（封面、名称、描述、有效期、售价等），下方提供以下管理标签页：

![班级详情管理](../实训项目截图/教师端/班级管理/班级管理-操作-班级管理.png)

#### 4.4.1 课程管理

![课程管理](../实训项目截图/教师端/班级管理/班级管理-操作-班级管理-课程管理.png)

1. 在「课程管理」标签页中，查看当前班级已关联的课程列表。
2. 点击「添加课程」按钮，从已创建的课程中选择要关联到班级的课程。
3. 每门课程显示名称、创建时间、发布状态和操作选项。

#### 4.4.2 教师管理

![教师管理](../实训项目截图/教师端/班级管理/班级管理-操作-班级管理-教师管理.png)

1. 在「教师管理」标签页中，查看和管理班级的授课教师。
2. 可添加其他教师到当前班级，支持多教师协同教学。

#### 4.4.3 学员管理

![学员管理](../实训项目截图/教师端/班级管理/班级管理-操作-班级管理-学员管理.png)

学员管理包含三个子标签页：**学员信息、申请记录、退出记录**。

**学员信息：**
- 展示当前班级所有学员的姓名、性别、手机号码、加入类型（主动加入/购买）和加入时间。
- 可查看学员的「学习详情」了解学习进度。
- 可「移除」不需要的学员。
- 支持以下操作：
  - **查询：** 按学员名称搜索。
  - **批量导入：** 通过 Excel 文件批量导入学员。
  - **批量移除：** 勾选多个学员后批量移除。
  - **批量导出：** 导出学员列表。

**批量导入学员：**

![批量导入](../实训项目截图/教师端/班级管理/班级管理-操作-班级管理-学员管理-批量导入.png)

1. 点击「批量导入」按钮。
2. 下载导入模板 Excel 文件。
3. 按模板格式填写学员信息。
4. 上传填写好的 Excel 文件完成批量导入。

#### 4.4.4 作业管理

![作业管理](../实训项目截图/教师端/班级管理/班级管理-操作-班级管理-作业管理.png)

1. 在「作业管理」标签页中，查看已发布的作业列表。
2. 列表展示作业名称、已提交/应提交人数、已点评/待点评人数、作业期限、发布状态和操作。

**添加作业：**

- **普通作业：** 点击「添加作业」后选择「普通作业」，设置作业标题、内容描述、截止时间和发布状态。

![添加普通作业](../实训项目截图/教师端/班级管理/班级管理-操作-班级管理-作业管理-添加普通作业.png)

- **习题作业：** 点击「添加作业」后选择「习题作业」，从题库中选择题目组成习题作业。

![添加习题作业](../实训项目截图/教师端/班级管理/班级管理-操作-班级管理-作业管理-添加习题作业.png)

**查看作业详情：**

![作业详情](../实训项目截图/教师端/班级管理/班级管理-操作-班级管理-作业管理-作业详情.png)

点击「详情」可查看学员的作业提交情况和提交内容，进行批改评阅。

#### 4.4.5 考试管理

![考试管理](../实训项目截图/教师端/班级管理/班级管理-操作-班级管理-考试管理.png)

1. 在「考试管理」标签页中，查看已添加的考试列表。
2. 点击「添加考试」为班级添加新考试。

**添加考试：**

![添加考试](../实训项目截图/教师端/班级管理/班级管理-操作-班级管理-考试管理-添加考试.png)

1. 点击「添加考试」按钮。

![算力账户](../实训项目截图/教师端/考试管理/班级管理-考试管理-算力账户-账单列表.png)

页面顶部展示以下核心信息卡片：
- **当前余额：** 当前可用的算力积分数量。
- **实时使用：** 当日已使用量和上限。
- **本月消耗：** 本月累计消耗的算力积分。
- **历史累计消耗：** 总计消耗的算力积分。

### 8.3 操作说明

#### 查看账单列表

1. 在「账单列表」标签页中，查看算力消耗的账单记录。
2. 每条账单包含流水号、账单ID、交易积分、业务类型、说明和交易时间。
3. 可按月份和星期筛选，默认展示最近 30 天的记录。

#### 查看流水列表

![流水列表](../实训项目截图/教师端/考试管理/班级管理-考试管理-算力账户-流水列表.png)

1. 切换到「流水列表」标签页。
2. 查看每一笔算力积分的收支明细。

### 常见问题

**Q1：课程创建后如何让学员看到？**

A：课程创建后需要将其添加到班级中，班级提交审核并通过后发布，学员才能在学习端看到课程。

**Q2：如何修改已发布的课程？**

A：对于已提交审核的课程，需要先撤销审核，修改内容后重新提交审核。审核通过后更新即可生效。

**Q3：如何将实训项目与课程关联？**

A：在创建实训课后，进入章节管理 > 课程编排，在第三步"实训"中导入已创建的 Jupyter 实训项目。

**Q4：题目导入失败怎么办？**

A：请确认导入文件格式与模板一致，检查必填字段是否完整，题目类型和选项格式是否正确。建议先使用少量题目测试导入，确认无误后再批量导入。

**Q5：算力积分不足如何处理？**

A：请联系平台管理员申请补充算力积分，或等待下一周期的积分自动补充。

**Q6：AI 课件生成视频需要多长时间？**

A：视频生成时间取决于课件页数和讲稿长度，一般几分钟到十几分钟不等。生成过程中可离开页面，完成后可在 AI 课件列表中查看生成状态。

**Q7：学员如何加入我的班级？**

A：学员可以通过以下方式加入班级：
- 在学习端浏览班级列表，找到对应班级后点击加入。
- 教师在学员管理中通过批量导入方式添加学员。
- 通过班级分享链接或二维码加入。
